## Remaining Tech Debt

### profileSkill ExecuteTool Gap (Low Severity)

`switch_mode` and `get_token_budget` tools are registered as catalog-only in the MCP SDK — they appear in `tools/list` but calling them returns an error because no handler is registered via `mcpsdk.AddTool`. The `ExecuteSwitchMode` and `ExecuteGetTokenBudget` methods exist on the profileSkill struct but are not dispatched through an `ExecuteTool` method.

**Fix:** Add `ExecuteTool(name string, params map[string]interface{}) (string, error)` to profileSkill that dispatches to the existing Execute* methods. Straightforward, ~20 lines.

**Affected requirements:** PRF-01 (partial), PRF-04 (partial)
