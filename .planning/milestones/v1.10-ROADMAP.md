## Phase Details

**Goal**: A semantic fact store opens at daemon start when `semantic_index.enabled=true` and persists at `<workspace>/.helix/semantic.duckdb`; auto-quarantines corrupt files; effective-read API returns `committed snapshot ⊕ live overlay − tombstones`; 4-layer config precedence.
**Requirements**: STORE-01..06, DAG-01..04
**Outcome**: 5 plans (including 57-05 gap-closure for SC-1 + CR-01/02 + WR-01/02/03). Schema migrations live in `internal/semantic/store/migrations*.go`; vet-noduckdb singlechecker confines `duckdb-go` imports to `internal/semantic/store/`.

## Milestone Summary

### Key Decisions

- **Live semantic store on DuckDB** (chosen for columnar perf on million-symbol repos)
- **Strangler-fig integration** preserved v1.9 RepoMap bit-for-bit — `source="tree_sitter"` rather than `source="fallback"`
- **Single-mode CGO=1** source tree (Phase 59.1) — dropped CGO=0 stubs; split-runner release.yml
- **Cosign keyless attestation** (not minisign) — uniform across all 6 archives
- **Bleve scorch over DuckDB FTS5** for retrieval (P64-01 BLOCKING-GATE benchmark verdict)
- **LLM judge informational, never gates CI** — EVAL-07 enforced by `forbid judge in CI` grep gate
- **Per-(task, mode) sandbox isolation** (Phase 67) — separate HOME, UDS socket, daemon subprocess per evaluation cell
- **Phase 60 P04 populator: Tier-3 synthetic-marker floor** (F-01 close-out 2026-05-12) — guarantees graph_version advances on every live edit; full per-symbol precision deferred as DEF-67-F01-FULL-DIFF
