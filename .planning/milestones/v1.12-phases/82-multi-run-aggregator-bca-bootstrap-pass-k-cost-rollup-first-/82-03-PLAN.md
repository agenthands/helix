<objective>
Implement the HumanEval UNBIASED pass@k estimator in `bench/aggregator/passk.go` (STATS-03) using
the LOCKED formula `pass@k = 1 - C(n-c,k)/C(n,k)` in Chen et al.'s numerically-stable product form
(D-10/D-11). The naive `1 - (1-p)^k` is FORBIDDEN — it is biased and fails published reference
values at k>=2. The test MUST include a k>=2 reference value (the two forms agree at k=1, so a
k=1-only test would not catch the bug), and MUST cross-check the product form against an independent
lgamma log-binomial form (two derivations agreeing is strong correctness evidence).

Purpose: pass@1 and pass@k are headline leaderboard columns; the per-task pass@k scalar is the
input vector for the BCa CI in Plan 06. TDD because there are published + hand-computed closed-form
anchors.
Output: `bench/aggregator/passk.go` (PassAtK + logBinom) and `passk_test.go`.

unit. The phase executes sequentially on the current feature branch, so the wave-1 siblings that
