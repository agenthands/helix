<objective>
Expose the aggregator via a `helix-bench aggregate <run_dir>` cobra subcommand (D-02): a thin
wrapper that constructs `aggregator.Config` from flags (`--runs` default 3, `--seed`,
`--iterations` default/floor 10000, `--ci-level` default 0.95), injects `today = time.Now().UTC()`
for the cost freshness gate, calls `aggregator.Aggregate(runDir, cfg)`, and propagates the error
via RunE so the process exits NON-ZERO and writes no reports on a deficiency (fail-closed,
single-exit semantics matching the rest of cmd/helix-bench). The subcommand is the primary,
re-runnable entry point (D-02).

Purpose: makes STATS-01/COST-03 operator-invocable; closes the user-facing surface for the phase.
Output: `cmd/helix-bench/aggregate.go`, an in-process subcommand test, and the registration in main.go.

This plan is NOT autonomous: the final task is a blocking human-verify checkpoint (the optional
end-to-end confidence check over a real daemon-produced multi-run matrix, the one path that needs
HELIX_BIN).
</objective>
