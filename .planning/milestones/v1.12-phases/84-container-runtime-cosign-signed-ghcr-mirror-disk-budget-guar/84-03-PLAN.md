<objective>
Implement the in-process cosign keyless verifier for the GHCR mirror (reusing the
`internal/upgrade/verify.go` sigstore-go pattern) and the verify-then-pull wiring
that resolves a digest + inspects manifest arch daemon-free via go-containerregistry
`crane`, runs the Plan 01 ArchGate, verifies the signature, and only then fills the
Plan 02 cache. This is the runtime half of CONTAINER-03 (the CI publish half is
Plan 04).

Purpose: CONTAINER-03 mandates that the bench harness verify a cosign signature
BEFORE pulling, reject a tampered image, and keep the verify-failure error
single-canonical (no tampered-vs-wrong-identity oracle — Pitfall 4). The verify
MUST gate the cache fill (Pitfall 3 TOCTOU) so no unverified bytes ever reach
`bench-images/<sha>/`. Output: verify.go (canonical-error verifier + pinned
issuer/SAN + test-override seam), a VirtualSigstore fixture generator, pull.go
(crane + ArchGate + verify + Ensure), and hermetic + gated-live test pairs.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GHCR mirror → bench harness | Pulled image bytes are untrusted until the cosign keyless signature verifies |
| verify outcome → error text | Distinguishable failure strings would leak a tampered-vs-wrong-identity oracle |
| verify → cache fill | Unverified bytes must never be published to the cache (TOCTOU) |
| signing identity → SAN/issuer pin | Only the agenthands/helix bench-mirror workflow may sign mirror images |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-84-03-01 | Tampering | verify.go VerifyImage | mitigate | sigstore-go keyless verify (reuse internal/upgrade); reject on any failure; never hand-roll the Fulcio/Rekor/TSA chain |
| T-84-03-02 | Information Disclosure | verify.go error text | mitigate | Single canonical "signature verification FAILED" literal at every branch; error-text-identity regression test (Pitfall 4); comment-stripped grep coverage gate |
| T-84-03-03 | Spoofing | verify.go identity pin | mitigate | Pin OIDC issuer = token.actions.githubusercontent.com + SAN regex to bench-mirror.yml@refs/heads/main; wrong-org/wrong-issuer fixtures rejected |
