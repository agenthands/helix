# Milestone v1.4: Integration Testing v2

**Status:** SHIPPED 2026-04-14
**Phases:** 18-21
**Total Plans:** 11

## Overview

Prove Serena-Go is protocol-correct, contract-stable, runtime-safe, and genuinely usable by LLM clients through a multi-oracle test harness.

## Phases

### Phase 18: Harness Extraction & Foundation

**Goal**: New oracle packages can import shared test infrastructure and run under correct build tags
**Depends on**: Phase 17 (v1.3 complete)
**Requirements**: FOUND-01, FOUND-02
**Plans**: 2/2 plans complete

Plans:
- [x] 18-01: Extract test/harness/ package with evolved API and self-tests
- [x] 18-02: Create oracle directory stubs and smoke test for build tag taxonomy

**Details:**
Extracted importable `test/harness/` package with Runner, GoldenStore, PrepareFixture, CallTool, and ListSessionTools. Oracle directory structure created under `test/oracle/` with 5 packages (protocol, contract, scenario, llm, judge). Build tag taxonomy: `integration`, `llm`, `llmjudge` with hierarchy encoding.

### Phase 19: Protocol & Contract Oracles

**Goal**: Every MCP protocol interaction and every exposed tool has deterministic correctness assertions
**Depends on**: Phase 18
**Requirements**: PROTO-01, PROTO-02, PROTO-03, PROTO-04, CONT-01, CONT-02, CONT-03, CONT-04
**Plans**: 3/3 plans complete

Plans:
- [x] 19-01: Protocol oracle — handshake, tools/list, session isolation, reconnect
- [x] 19-02: Contract oracle — schema meta-validation and selectability heuristics
- [x] 19-03: Contract oracle — golden output files and error category contracts

**Details:**
Protocol tests validate MCP handshake, tools/list with schema validation, session isolation, and reconnect resilience. Contract tests: JSON Schema Draft 2020-12 validation for all tool schemas, 23 golden output files, tool selectability heuristics with Jaccard similarity, 3/6 error category contracts (remaining 3 deferred to Phase 20).

### Phase 20: Scenarios & Runtime

**Goal**: Realistic agent workflows pass across diverse repository shapes, and the runtime survives stress and degraded conditions
**Depends on**: Phase 19
**Requirements**: SCEN-01, SCEN-02, SCEN-03, SCEN-04, RUNT-01, RUNT-02, RUNT-03
**Plans**: 4/4 plans complete

Plans:
- [x] 20-01: Create fixture matrix (polyglot, unsupported, collision) and runtime oracle stub
- [x] 20-02: Multi-step agent workflow scenarios (Go, Python, TS, polyglot, unsupported, collision, degraded)
- [x] 20-03: Profile/mode behavior tests and deferred CONT-03 error categories
- [x] 20-04: Runtime stress (pool, shutdown, degraded subsystem injection)

**Details:**
14+ full-cycle agent workflow tests across Go, Python, TypeScript, C++, Swift, Zig, JavaScript, PHP, SQL, Markdown, polyglot, unsupported, collision, and degraded fixtures. Profile/mode behavior: read blocks edits, admin grants all, mode switching updates visibility, concurrent session isolation. Runtime: worker pool stress, clean shutdown drain, goroutine leak detection, degraded subsystem injection. Completed 3 deferred CONT-03 error categories (timeout, circuit_open, unsupported).

### Phase 21: LLM Behavioral & Judge

**Goal**: An LLM client can correctly select, disambiguate, and interpret results from every Serena tool
**Depends on**: Phase 20
**Requirements**: LLM-01, LLM-02, LLM-03, LLM-04
**Plans**: 2/2 plans complete

Plans:
- [x] 21-01: Shared LLM infrastructure + tool selection and disambiguation tests
- [x] 21-02: Output interpretation tests + judge scoring infrastructure

**Details:**
Tool selection tests for all 33 exposed tools, disambiguation tests for 11 similar tool pairs, output interpretation tests using golden files from Phase 19. Judge scoring infrastructure with structured rubrics (5 dimensions), transcript pipeline, retry-once validation, aggregate reporting. Multi-provider support (Anthropic + DeepSeek via OpenAI-compatible API). Build-tag gated, never blocks merge.

## Milestone Summary

**Key Decisions:**

- Multi-oracle test architecture — five oracle layers as separate packages under test/oracle/
- Extend, don't replace — existing test/integration/ stays untouched, new harness extracted to test/harness/
- Only 2 new deps needed (jsonschema/v6, anthropic-sdk-go); later added openai-go for DeepSeek support
- LLM tests are build-tag gated and never block merge
- Golden file pattern with normalized responses for deterministic assertions
- Deferred CONT-03 completion from Phase 19 to Phase 20 for error categories requiring runtime fixtures

**Issues Resolved:**

- LS quirk adapters added for Python/TypeScript (didOpen requirement)
- WaitForLS readiness check fixed for servers that return empty results when ready
- Extension-based language fallback detection for marker-free languages (Markdown)
- Marksman quirk adapter for Markdown LSP support

**Technical Debt Incurred:**

- gopls v0.17.1 incompatibility with Go 1.25 on linux/amd64 may affect CI fixture tests
- Most SUMMARY.md files missing `requirements_completed` frontmatter field
