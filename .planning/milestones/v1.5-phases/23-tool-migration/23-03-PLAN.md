<objective>
Migrate all 6 file operation tools (read_file, write_file, overwrite_file, list_directory, find_files, search_in_files) from raw `fmt.Errorf` to typed `serr` errors. Fileops has the most error sites (~33) and diverse failure semantics.

Purpose: File operations produce the widest range of error kinds -- NotFound, InvalidArgs (path security, size limits, regex), Internal (I/O). Typed errors let agents distinguish "file doesn't exist" from "path is outside workspace."
Output: All ~33 error sites (excluding 2 internal sentinels) use `serr` constructors.
</objective>
