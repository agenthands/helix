Add `serr "github.com/postfix/serena/internal/errors"` import to skill.go.

Read skill.go carefully to identify all error sites. Based on grep results (13 sites):

**Init errors** (3 sites, L45/52/58): These are `fmt.Errorf("loading embedded profiles: %w", err)` etc. -- startup errors that surface as fatal init errors. Per Pitfall 5 rationale, these CAN be migrated since they're in the skill Init() method which is called during daemon bootstrap. Use `serr.Wrap(serr.Internal, "loading embedded profiles", err)` etc. to be consistent. But if they truly never reach MCP, leaving as fmt.Errorf is also acceptable. Read the code to determine: if Init() errors cause the daemon to fail-fast before any MCP tool calls, leave as fmt.Errorf. If they could propagate to an MCP response, migrate.

**Mode validation** (L84): `fmt.Errorf("unknown mode %q; available modes: %s", ...)` -> `serr.New(serr.InvalidArgs, "unknown mode").WithDetail(fmt.Sprintf("%s; available modes: %s", modeName, ...))`

**Profile lookup** (L91): `fmt.Errorf("unknown profile %q", profileName)` -> `serr.New(serr.InvalidArgs, "unknown profile").WithDetail(profileName)`

**Transition validation** (L97): `fmt.Errorf("mode %q has no transitions defined in profile %q", ...)` -> `serr.New(serr.InvalidArgs, "mode has no transitions defined").WithDetail(fmt.Sprintf("mode %s in profile %s", currentMode, profileName))`

**Transition denied** (L106): `fmt.Errorf("transition from %q to %q not allowed in profile %q; allowed targets: %s", ...)` -> `serr.New(serr.InvalidArgs, "mode transition not allowed").WithDetail(fmt.Sprintf("from %s to %s in profile %s; allowed: %s", ...))`

**No session provider** (L121): `fmt.Errorf("no session provider configured")` -> `serr.New(serr.Internal, "no session provider configured")`

**No active session** (L125): `fmt.Errorf("no active session")` -> `serr.New(serr.Internal, "no active session")`

**Profile lookup in tools** (L201): `fmt.Errorf("unknown profile %q", profileName)` -> `serr.New(serr.InvalidArgs, "unknown profile").WithDetail(profileName)`

**Mode lookup in tools** (L206): `fmt.Errorf("unknown mode %q", modeName)` -> `serr.New(serr.InvalidArgs, "unknown mode").WithDetail(modeName)`

**Missing parameter** (L313): `fmt.Errorf("missing required parameter: target_mode")` -> `serr.New(serr.InvalidArgs, "missing required parameter: target_mode").WithTool("switch_mode")`

**Unknown tool** (L334): `fmt.Errorf("unknown tool: %s", name)` -> `serr.New(serr.InvalidArgs, "unknown tool").WithTool(name)`

Per D-04: all messages lowercase, no trailing punctuation. Per D-05: tool name via `.WithTool()`, not in message text.
