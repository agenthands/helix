## Phase Details

### Phase 46: bug-repomap-lua-fixture
**Goal**: `get_repo_map` on Helix's own workspace returns a ranked view of `internal/` Go sources rather than the single deep Lua testdata fixture.
**Requirements**: BUG-01
**Success Criteria**: 4 SC met. Root cause: PageRank starvation on ambiguity-weighted edges; fix in `graph.go:BuildGraph` (F1-B). Regression test in `internal/repomap/`.

### Phase 47: bug-rust-analyzer-rename
**Goal**: `rename_symbol` works on Rust symbols in temp workspaces.
**Requirements**: BUG-02
**Success Criteria**: 4 SC met. Wire experimental/serverStatus readiness signal into `RustAnalyzerAdapter`; `QuirkAdapter.RenameOverride` dispatcher with strategy metric; integration test unskipped.

### Phase 48: bug-jdtls-warm-cache
**Goal**: Java integration tests run in default `go test ./...` via warm jdtls workspace reuse.
**Requirements**: BUG-03
**Success Criteria**: 4 SC met. New `jdtlscache` helper (pure-stdlib hash + ResolveDataDir); env-var override `SERENA_TEST_JDTLS_DATA_DIR`; build tags dropped; Makefile `clean-jdtls-cache` + `bench-jdtls-warm`. Note: BUG-03 verification recorded as resolved after Phase 56 LS dispatch fix.

### Phase 49: bug-grammar-registry-consolidation
**Goal**: One canonical `GrammarRegistry` at daemon bootstrap, shared by all consumers.

## Milestone Summary

### Key Accomplishments

1. **Closed all 4 known bugs** (BUG-01..BUG-04) — repomap PageRank starvation, rust-analyzer rename quirk, jdtls warm cache, GrammarRegistry consolidation
2. **Resolved Go 1.25 / gopls linux/amd64 incompatibility** and converted bench harness to local-only (per the project's local-only bench rule)
3. **Shipped reproducible multi-arch signed release pipeline** via goreleaser (6 archives × darwin/linux/windows × amd64/arm64 with minisign signing; CGO=0 stub for treesitter)
4. **Renamed product serena → helix as a hard-cut breaking change** (binary, module path `github.com/agenthands/helix`, env vars `HELIX_*`, config dir `~/.helix/`, MCP server identity); shipped in-binary self-upgrade (`helix update` / `helix upgrade` with minisign verify + atomic swap + downgrade refusal)
5. **Closed observability gaps** — 5 new Prometheus metric families (cache hit-rate, repomap latency, session lifecycle, edit outcomes), 2 Grafana dashboards (`helix-overview.json`, `helix-engine.json`), 4 runbooks, full per-MCP-tool + per-LS-call trace coverage with hygiene review and real Jaeger smoke capture
6. **Wired LS notification dispatch in production** (Phase 56, emergent) — `jsonrpc.Conn.OnNotification` was never set in production; QuirkAdapter notification handlers were silently dropped. Fixed alongside `JdtlsAdapter.WaitUntilJavaReady(ctx)` gate

### Key Decisions

- **One phase per bug** for BUG-01..BUG-04 (smaller blast radius, easier rollback)
- **TOOL-01 + TOOL-02 clustered** into Phase 50 (Go 1.25/gopls fix is prerequisite for restoring CI gate)
- **PKG-02/03/04 deferred** to PKG-DEFER-03/04/05 — Phase 52 rescoped to self-contained-binary + in-binary self-upgrade (`helix update` / `helix upgrade`); decision recorded in 52-CONTEXT.md
- **OBS-03 (metrics) before OBS-01/02 (dashboards/runbooks)** so dashboards reference metrics that exist
- **CGO=0 build path** preserved via Phase 51.1 stubs (closes DEF-51-01, unblocks goreleaser SC-1)
- **Module path rename** executed via mechanical perl rewrite + `go build` verification gate (gopls rename does not operate on module paths)
- **Phase 56 added emergently** after Phase 55 audit surfaced that LS notification dispatch was never wired in production
