## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| test process → user filesystem | Helper writes directories under `$UserCacheDir/serena-test/jdtls/` during test runs |
| test process → jdtls binary on PATH | Helper reads binary contents (read-only) to compute identity hash |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-48-01-01 | Tampering | hashTree walk — symlink escape from fixtureRoot | accept | Fixture tree is repo-local `testdata/fixtures/java/` under developer control; no untrusted input crosses this boundary. Hash still deterministic for well-formed trees. |
| T-48-01-02 | Information Disclosure | hashBinary reads jdtls binary file contents | accept | Binary content is hashed into 12 hex chars and then discarded (not persisted). SHA-256 prefix is not reversible; no PII or secret material involved. |
| T-48-01-03 | Denial of Service | ResolveDataDir on extremely large fixtureRoot | accept | Fixture is 5 files (`testdata/fixtures/java/`), walk bounded by repo contents. Not exposed to runtime users — test-only path. |
| T-48-01-04 | Elevation of Privilege | os.MkdirAll with 0o755 on user cache dir | mitigate | Use 0o755 (no world-write) and `os.UserCacheDir()` which returns user-owned paths per platform. No setuid surface. |
| T-48-01-05 | Repudiation | N/A | accept | No audit logging in test helpers — local test infra only, not runtime. |

**ASVS L1 relevance:** Test-only helper, no network, no authenticated surface, no user input — ASVS L1 controls (V5 input validation, V7 error handling) apply only at the fixture-root argument which is a controlled test parameter.
