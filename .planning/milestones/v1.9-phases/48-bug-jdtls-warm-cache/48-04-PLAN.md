Makefile targets:
- `make clean-jdtls-cache` — idempotent; succeeds whether the directory exists or not.
- `make bench-jdtls-warm` — depends on `clean-jdtls-cache`; runs `go test -run 'Java' ./test/integration/... -count=1` twice under `time`.

Neither target requires `-tags=integration` because Plan 03 dropped the tag from
`java_test.go`. If Plan 03 is not yet merged in the executor's working tree, the
target will still "run" but `go test` will report "no tests to run" — that's acceptable;
the target itself is correct.

The Makefile uses `$(GO) test -run 'Java' ./test/integration/... -count=1` — this
intentionally targets ONLY the Java suite because running the full test suite twice
would mask the jdtls-specific wall-clock delta.
</interfaces>
