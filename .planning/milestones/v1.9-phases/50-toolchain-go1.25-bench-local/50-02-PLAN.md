## Trust Boundaries

| Boundary | Description |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-50-04 | Information Disclosure | `.gitignore` entry shape | mitigate | Use the EXACT filename `test/bench/baselines/local.txt`, not `test/bench/baselines/` or `test/bench/baselines/*`. Verified by `git check-ignore test/bench/baselines/README.md` returning exit 1 (Task 2 acceptance criterion). Without this guard, a contributor's accidental `local.txt` containing user-identifying timing data could leak alongside the README being lost from git tracking. |
| T-50-05 | Tampering | New `make bench` / `make bench-baseline` targets | accept | Targets only invoke `go test -bench` — no privileged file writes outside `test/bench/baselines/local.txt` (gitignored), no network egress beyond what `go test` already does, no shell injection (no user-controlled variables interpolated into the recipe). |
| T-50-06 | Repudiation | Local baseline file (overwrites on each run, no history) | accept | Per D-08, history-keeping was explicitly traded for minimal Make surface. Future micro-phase can add `NAME=` if needed. |

**Net security impact:** No new attack surface; one mitigated gitignore-correctness threat. `block_on: high` — none reach high severity.
