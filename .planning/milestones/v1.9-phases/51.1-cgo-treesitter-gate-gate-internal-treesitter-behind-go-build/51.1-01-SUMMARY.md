## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Fix Windows cross-build (`SysProcAttr.Setpgid`)**

- **Found during:** Task 3 verification (`make release-snapshot`).
- **Issue:** `internal/forwarder/dial.go:92` referenced `syscall.SysProcAttr{Setpgid: true}`. `Setpgid` does not exist on Windows; cross-compile to `windows_amd64` failed with `unknown field Setpgid in struct literal`. Pre-existing — confirmed by reproducing on `main` at the wave-base commit. Previously masked because the goreleaser build hit the tree-sitter-bindings error first, never reaching the forwarder package.
- **Fix:** Refactored the SysProcAttr line into a build-tagged helper `detachFromProcessGroup(cmd *exec.Cmd)`. New files `internal/forwarder/dial_unix.go` (`//go:build !windows`, sets `Setpgid: true`) and `internal/forwarder/dial_windows.go` (`//go:build windows`, no-op). Removed the now-unused `"syscall"` import from `dial.go`.
- **Files modified:** `internal/forwarder/dial.go`, `internal/forwarder/dial_unix.go` (new), `internal/forwarder/dial_windows.go` (new).
- **Commit:** `200f1ac9`.
- **Justification:** Required for AC-3 (6 archives). Without this, the Windows targets in goreleaser's matrix fail and `dist/` ends up with fewer than 6 archives.
