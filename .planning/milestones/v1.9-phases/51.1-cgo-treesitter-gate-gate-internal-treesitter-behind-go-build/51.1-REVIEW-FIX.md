## Fixed Issues

### WR-01: Windows daemon detach is a silent regression

**Files modified:** `internal/forwarder/dial_windows.go`
**Commit:** 2e92cd21
**Applied fix:** Replaced the no-op `detachFromProcessGroup` with a real implementation that sets `syscall.SysProcAttr{CreationFlags: windows.CREATE_NEW_PROCESS_GROUP | windows.DETACHED_PROCESS}` using `golang.org/x/sys/windows` (already in go.mod). The daemon now starts in its own process group, so a Ctrl-C in the calling shell will not kill it once Windows binaries become real artifacts (DEF-51-02). Verified with `GOOS=windows go build ./internal/forwarder/` and `GOOS=windows go vet`.

### WR-02: `NewTagExtractor` !cgo stub returns `(nil, err)` — asymmetric with sibling stubs

**Files modified:** `internal/repomap/extractor_nocgo.go`
**Commit:** 43bf76f4
**Applied fix:** Changed `NewTagExtractor` under !cgo to return `(&TagExtractor{}, nil)` matching the `NewBodyExtractor` / `NewElisionRenderer` pattern. Method-level error returns on `Extract` retained as defense-in-depth. The existing caller in `internal/skill/repomap/skill.go` works either way (it checks `err == nil`). Updated doc comments to describe the new contract.

### WR-03: cgo and !cgo signatures not compile-asserted to match

**Files modified:** `internal/kernel/edit/sig_assert.go` (new), `internal/repomap/sig_assert.go` (new), `internal/treesitter/sig_assert.go` (new)
**Commit:** 4ea0d468
**Applied fix:** Added non-build-tagged `sig_assert.go` files containing interface-satisfaction assertions for `*BodyExtractor` (`SupportsLanguage`, `ExtractBody`), `*TagExtractor` (`Extract`, `Close`), `*ElisionRenderer` (`RenderFile`), and `*GrammarRegistry` (`SupportsLanguage`, `SupportedLanguages`). These run in BOTH cgo and !cgo builds, so any future signature drift between the cgo file and its `_nocgo.go` stub fails `go build` locally rather than only in CI's nocgo job. `GetLanguage` is intentionally omitted because its return type `*tree_sitter.Language` is cgo-only. Verified: both `go vet ./...` and `CGO_ENABLED=0 go vet ./...` are clean.
