<objective>
Flip the no-arg `helix` behavior: today `runRoot` (`internal/cli/root.go:98-118`) falls
through to `runForwarder` on no args (opening a stdio MCP session). CLI-04 requires no-arg
`helix` to print grouped usage/help and exit 0, opening NO MCP stdio session. Preserve the
explicit `--serve` / `--mode=http` (→ daemon) and explicit `--mode=stdio` (→ forwarder)
paths so Phase 94 (full forwarder-head deletion) is not pre-empted here. Group the visible
commands by capability via cobra `AddGroup` (cobra v1.10.2 supports it) so the help output
is organized rather than a flat list.

Purpose: CLI-04 — the CLI is becoming the agent surface; a bare `helix` must be a
discoverable help screen, not a silent stdio MCP server an agent never asked for.
Output: `runRoot` no-arg branch → grouped help + exit 0; cobra command groups; a unit test
asserting exit 0 + no forwarder + preserved explicit modes.
</objective>
