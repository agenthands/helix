| CLI → workspace filesystem (snippet read) | The CLI-side snippet read (OUT-03) opens a source file at the parsed `relpath:line`; the relpath derives from daemon text and must be clamped to the workspace root so it cannot read outside it. |
| renderer stdout → agent | Terse output must not leak absolute host paths unless --abs is explicitly set (workspace-relative default is the OUT-01 contract). |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-92-03 | Information Disclosure | absolute host paths / workspace layout in default output | mitigate | Default render is workspace-relative (filepath.Rel + ToSlash); absolute paths emitted ONLY under explicit --abs — unit test asserts default output contains no leading `/` workspace prefix and --abs reverses it (OUT-01/07) |
| T-92-04 | Information Disclosure | snippet read escaping the workspace root via `../` in relpath | mitigate | readSnippetLine verifies the resolved path stays within workspaceRoot (filepath.Rel + `..`/absolute-escape check) BEFORE opening; an escaping path yields no snippet and no error — unit test feeds a `../escape` relpath and asserts no read outside root (RESEARCH Security Domain path-traversal row) |
