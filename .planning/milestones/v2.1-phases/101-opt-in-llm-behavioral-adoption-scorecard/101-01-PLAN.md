<objective>
Create the build-tag-FREE `test/oracle/adopt` package (package `adopt`): a pure, hermetic
scorer that parses transcripts → first-emitted-command detector → choice/fallback
classification → choice_rate/fallback_rate, plus the `StripDecisionMatrix` sabotage helper,
committed fixture transcripts, and ALL anti-vacuity tests. This is the load-bearing,
default-suite work for ADOPT-02: the sole authoritative non-vacuity proof that runs in
`go test ./...` without a network or API key.

Purpose: The natural home for an LLM scorer is `test/oracle/llm`, but that whole package is
`//go:build llm || llmjudge` and is invisible to `go test ./...` (verified: `go list
./test/oracle/llm/...` → "matched no packages"). Placing the anti-vacuity proof there would
make it NEVER run in CI — the exact meta-vacuity this phase exists to kill (101-RESEARCH
Pitfall 1). The pure scorer therefore lives in a non-tagged package, importing only stdlib +
the tag-free `internal/cli` accessors.

Output: `test/oracle/adopt/scorecard.go` (pure scorer + sabotage helper), `scorecard_test.go`
(5 hermetic tests), and 12 committed fixture transcripts under `testdata/transcripts/`.
</objective>
