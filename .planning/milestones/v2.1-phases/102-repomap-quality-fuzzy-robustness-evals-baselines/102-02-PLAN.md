<objective>
Build the `bench/evaluators/fuzzyrobust` stdlib-only (+ `editsim.ES`) leaf evaluator that measures `internal/fuzzy`'s 4-strategy cascade selection and ambiguity refusal against a multi-language **drift** corpus, plus the `//go:build ignore` HELIX_BIN-gated capture harness that lives OUTSIDE the leaf.

Each drift case is a real vendored fixture code block transformed by a **deterministic per-tier perturbation** (whitespace → `whitespace_normalized`; reindent → `indentation_flexible`; elide-middle → ellipsis; none → `exact`). The transform IS the drift-type derivation — the expected strategy is structural and never read from observed tool behavior (D-05). At least one **known-ambiguous** case is built by duplicate-block-from-fixtures and asserted to yield `ambiguous_match` (a refusal, ErrAmbiguous), NOT `no_match` — the FUZZBENCH anti-vacuity proof (D-06).

Purpose: FUZZBENCH-01 (the leaf measures strategy selection + refusal via `editsim.ES`, stdlib-only + editsim) and FUZZBENCH-02 (broad native drift corpus with strategy derived from drift type + size floor + >=1 must-refuse ambiguous case).

Output: the `fuzzyrobust` package (perturbation transforms, scoring, corpus loader), committed drift + captured testdata for py/go/rust, a `CORPUS.md`, and the capture harness. `internal/fuzzy` is NOT leaf-importable (`match.go:8` imports `internal/errors`), so the leaf consumes CAPTURED strategy/refusal data; the non-leaf harness calls `fuzzy.Match`.

This plan is `type: tdd`. The per-tier transforms and the discriminator (ambiguous-must-refuse) are defined-I/O algorithms; author the drift corpus from ground truth FIRST, then write the failing strategy/refusal tests (RED), then implement to GREEN. **Sequencing matters: the corpus is authored before scoring is wired; the must-refuse case proves the corpus is non-trivial.**
</objective>
