## Per-language tier designs (from salvage + language semantics)

### Java (Phase 130) — 7-tier
- T2 annotation: `@Override`/`@Inject`/`@FunctionalInterface`; T3 constructor: `new Foo()`, diamond `<>`; T4 assignment: `Foo f =`, `var x =`; T5 comment: Javadoc `@param`/`@return`; T6 heuristic: PascalCase, `get*`/`set*`, `*Impl`, `Abstract*`. Generics unwrap (`List<String>`); overload = name+arity+param types.

### C# (Phase 131) — 7-tier
- T2: attributes / `[XmlAttribute]`; T3: `new Foo()`, record primary constructors; T4: `var x =`, property initializers; T5: XML-doc `///`; T6: PascalCase, `I`-prefix interfaces, known suffixes (`Service`, `Controller`).

### C (Phase 132) — thinner tier set (no classes/annotations/constructors)
- T2 annotation: typed decl `struct Foo x`, `Foo x`; (no constructor tier); T4 assignment; T5 comment; T6 heuristic: `struct`/`typedef` name shape. Function-pointer / `typedef` awareness.

### C++ (Phase 133) — 7-tier
- T2: none (no annotations); T3: `new Foo()`, constructor calls; T4: `auto x =`, `Foo x`; T5: comment; T6: PascalCase classes, templates (`Foo<T>`), namespaces (`ns::Foo`).
