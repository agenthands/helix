# Phase 104 Plan 01: Reference Generator Per-Verb Correctness Summary

Per-verb override maps in `cmd/helix-refgen/render.go` (keyed lookup, group-default fallback) so the 10 verbs that cligen's `categoryToGroup` folds into `groupMemory` render Output/Use-this prose matching their real semantics, with two anti-vacuity guards proving the override map is real — fix lives in the generator, reference.md regenerated byte-clean.

## What Was Built

- **`cmd/helix-refgen/render_test.go` (NEW, `package main`):** three in-package tests.
  - `TestRenderOverride` — golden per-verb: each of the 10 overridden verbs carries its corrected Output/Use-this prose in its OWN section and no longer carries the old memory markers (`ranked FTS5 search result`, `durable project/session memory`); the 3 genuine memory query verbs (read/search/list) keep the group default.
  - `TestOverrideKeysAreRealVerbs` (Guard A) — every override key ∈ kebab(`cli.VerbToolNames()`); fabricated-key (`totally-not-a-verb`) discriminator runs the same `nonVerbKeys` helper against a mutated copy and asserts it is flagged.
  - `TestOverrideDiffersFromGroupDefault` (Guard B) — for each overridden verb, `outputShape(verb,"memory") != groupOutputDefault("memory")` and the Use-this analog; a copied-default discriminator asserts a no-op (value == group default) is caught, with exact `require.Len(noOps, 1)` cardinality.
- **`cmd/helix-refgen/render.go` (MODIFY):**
  - `outputShapeOverrides` / `useThisNotThatOverrides` — package-level `map[string]string`, 10 kebab-verb keys each.
  - `groupOutputDefault(group)` / `groupUseDefault(group, verb)` — extracted pure helpers holding the prior `switch` bodies verbatim.
  - `outputShape(verb, group)` / `useThisNotThat(verb, group)` — signatures changed; keyed override lookup, then group-default fallback.
  - `renderVerb` call sites pass `d.Verb` to both selectors.
- **`internal/cli/skills/helix/reference.md` (REGENERATE):** the 10 corrected verb sections, byte-gated by `--check`.
