<objective>
Rewrite the hand-authored `## Decision matrix` in `internal/cli/skills/helix/SKILL.md` so it routes an agent's single intent to a single correct tool: no QUERY/ACTION row mixing (SKILL-01), explicit "Not this" guidance on every row with no `—` placeholders (SKILL-02), and an `index-semantic-graph` prerequisite marker on every indexed-graph reader verb with capability-based grouping (SKILL-03) — consistent with the now-correct Phase 104 reference.md.

The only NEW code is three break-the-invariant (anti-vacuity) guards in `internal/cli/skill_test.go`, modeled on `reference_contract_test.go`'s confirm-and-seal + revert-and-fail architecture, plus a stdlib-only matrix-row parse helper and a QUERY/ACTION classification map keyed to `VerbToolNames()`. The existing anchor (`TestSabotageNonNoop`), size-cap (`TestSkillDescriptionCap`), and drift (`TestSkillVerbMembershipDrift`) guards must stay green.

Purpose: A correct, non-vacuously-gated steering matrix is the agent's idle-tier routing surface — wrong groupings send an agent to a mutating verb when it wanted a reader (and vice versa), and a `—` "Not this" cell loses the displacement argument that drives adoption.
Output: Extended `skill_test.go` (3 guards RED-first), rewritten `SKILL.md` matrix (GREEN), full suite + `go vet` + `helix-refgen --check` byte-clean.
</objective>
