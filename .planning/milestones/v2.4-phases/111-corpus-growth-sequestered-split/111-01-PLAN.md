# Phase 111 — Plan 01: Corpus Materializer + 3-Way Sequestered Split

**Requirements:** CORPUS-01, CORPUS-02
**Approach:** TDD (RED → GREEN). All work dev-time Python under `tools/dspy-tune/` + the existing Go loader. Zero new Go deps.

## Goal

Materialize a ≥101-task Aider-polyglot corpus at `AIDER_TASKS_DIR` (go+python+rust=103) and replace the 2-way train/val split with a 3-way `train / val / test` split whose **test** partition is sequestered (never passed to `compile()`) and gated `> 50` — proven by a hermetic planted-leak → assert-RED test.

## Tasks

- **RED**: `test_corpus.py::test_build_corpus_descriptor_shape` builds 1 descriptor from a committed tiny synthetic exercise fixture (a fake `<lang>/exercises/practice/<ex>/` with `.meta/config.json` + `.docs/instructions.md` + stub + test) and asserts the emitted JSON has exactly `{task, language, task_dir, gold_src, gold_tests}` with `gold_src == task_dir`, `gold_tests == config.files.test`, and `task` == the instructions text. Fails before the materializer exists.
- **GREEN**: write `build_corpus.py`:
  - `clone_or_reuse(sha)` → `git clone --depth 1` into `$HELIX_CACHE_DIR/aider-polyglot/<sha>` (reuse if HEAD==sha); pinned sha imported/duplicated from `pin.go`'s `7e0611e7…` (assert hex-sha40).
  - `enumerate(track)` → `<track>/exercises/practice/*` dirs with a readable `.meta/config.json` (skip + warn on missing solution/test).
  - `descriptor(ex_dir, lang)` → read config + `.docs/instructions.md` (fallback `.docs/introduction.md`); emit the 5-field JSON; `task_dir`/`gold_src` = abs pristine dir; `gold_tests` = `config.files.test`.
  - `main(--tracks go,python,rust --out <dir> --check)`: write one `<lang>__<ex>.json` per exercise to `--out` (default `tools/dspy-tune/corpus/`) + a `corpus_manifest.json` (`{pinned_sha, total, per_language, tracks}`); `--check` exits non-zero if `total < 101` (the requested-build fail-not-skip gate).

### Task 2 — 3-way `split_corpus()` + sequestered-gate move (CORPUS-02)
- **RED**: `test_corpus.py` adds:
  - `test_split_three_way_disjoint`: synthetic 120 examples → `train,val,test = split_corpus(ex)`; assert pairwise disjoint by task id, `len(test) > 50`, and `train ∪ val ∪ test == ex`.
  - `test_planted_leak_goes_red`: inject a `test` example's task into `train`; assert the disjointness predicate (`_assert_disjoint`) raises/returns False — break-the-invariant.
  - `test_compile_never_sees_test`: a fake `compile(trainset, valset)` records its args; assert no `test` example id appears in trainset∪valset.
- **GREEN**: in `optimize.py`:
  - add `split_corpus(examples, test_frac, val_frac)` → deterministic 3-way (test carved FIRST and locked, then train/val from the remainder); default sizes so `len(test) > 50` when `len(examples) >= 101` (e.g. test = max(51, 50% ) … pin: `test = examples[: max(51, n//2)]`? choose test≈51, then split remainder 60/40 train/val). Return `(train, val, test)`.
  - rewire `main()`: `train, val, test = split_corpus(examples)`; gate `if not adoption_allowed(len(test)): no-ship; return 0`; `optimizer.compile(student, trainset=train, valset=val)` (test NEVER passed); stash `test` for attribution (write its ids/descriptors to `output/heldout_test.json`, git-ignored).
