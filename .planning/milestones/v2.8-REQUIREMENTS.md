# Requirements — Milestone v2.8 Graph Intelligence Depth (cbm-mcp parity)

## Overview

**Goal:** Close the two cbm-mcp **depth** gaps the 2026-06-30 HEAD audit isolated.
The edge *schema* reached parity (23/24 kinds emitted); the graph *intelligence*
did not. This milestone delivers the two gaps that change what an agent can answer:

1. **Workstream A — SEMANTICALLY_RELATED** (this milestone, Phases 121–123): the
   one declared-but-**unwired** edge kind. Emit it via **Random Indexing** (RI) —
   cbm-mcp's own mechanism, pure-Go, deterministic, no runtime dep, single-binary
   safe. This is the only single-binary-compatible path and is true parity.
2. **Workstream B — true interprocedural DATA_FLOWS** (gated; NOT in this
   milestone's committed scope): the emitted `DATA_FLOWS` edge is structural-profile
   similarity, not arg-to-param flow. Workstream B opens on an explicit design fork
   (B0: rename the structural edge vs `Source`-discriminate) that the co-driver must
   settle before roadmapping. Tracked in the scope doc; deferred here.

**Why now:** v2.7's benchmark line reached a NO-SHIP decision gate; this is the
product-code track that compounds the semantic graph's real value. Workstream A is
fork-free, self-contained, low-risk, and de-risks the fingerprint-plumbing pattern
Workstream B reuses.

**A0 decision (locked):** embedding engine = **Random Indexing** (sparse random
projection over identifier/comment tokens). Rationale: matches cbm-mcp; pure Go;
deterministic; zero runtime dep. Neural (onnxruntime/nomic) rejected — breaks the
single-binary invariant. External API rejected — no runtime network.

## RELATE — SEMANTICALLY_RELATED emission (Workstream A)

### RELATE-01: Random-Indexing engine (leaf package)

- [ ] **RELATE-01a:** New `internal/semantic/relatedidx/` — leaf package, imports limited to stdlib + tree-sitter + the same xxhash dep `minhash/` already uses (NO `internal/*` beyond shared low-level helpers; mirrors `minhash/` boundary).
- [ ] **RELATE-01b:** `ComputeContextVector(tokens []string) Vector` — sparse random projection. **Determinism is structural, not merely seeded:** accumulation MUST be into an integer (`int32`) vector so token-order and run-order cannot perturb the result (integer add is associative + commutative + exact; a float32 sum is none of these and would flip edge membership at the threshold). NO Go-map-iteration in the token→vector path. Proven by an N-shuffle test (50 permutations of the same multiset → byte-identical), not a same-input re-run. Hash-seed derivation uses explicit binary encoding (`binary.LittleEndian`), never `string(rune(...))` (which folds out-of-range values to U+FFFD and collides seeds).
- [ ] **RELATE-01c:** Dimension pinned as a named const with a code comment stating the rationale (e.g. `D = 256`).
- [ ] **RELATE-01d:** Semantic token extraction keeps **identifier text + docstring/comment tokens** — explicitly NOT the normalized structural codes MinHash discards (that distinction is what makes this edge ≠ SIMILAR_TO).
- [ ] **RELATE-01e:** Cosine helper + unit proofs: `cosine(v,v)==1`; a same-vocabulary fixture pair ranks strictly above an unrelated pair.
- [ ] **RELATE-01f:** Min-token gate (tiny bodies yield no vector → no spurious relatedness), mirroring `minhash.MinNodes`.

### RELATE-02: Fingerprint plumbing (shared seam)

- [ ] **RELATE-02a:** Add `SymbolFact.ContextVec` field (`internal/semantic/extract/fact.go`), value-copy safe to carry after the tree closes (like `MinHash`/`Profile`).
- [ ] **RELATE-02b:** `extract.FingerprintBody` computes `ContextVec` for `IsFingerprintableKind` symbols — the single shared entry point, so all 11 providers inherit it with no per-provider edit.
- [ ] **RELATE-02c:** Carry the vector on the daemon-side `fingerprintedNode` (`semantic_similarity_edges.go`).
- [ ] **RELATE-02d:** A provider e2e test asserts `ContextVec` populated for a function body, nil for a container kind.

### RELATE-03: Emission + read surface

- [ ] **RELATE-03a:** `semanticallyRelatedEdges(nodes)` emits `EdgeKind: "SEMANTICALLY_RELATED"`, `Source: "random_index"`, confidence ~0.45–0.55.
- [ ] **RELATE-03b:** Language-bucketed, cosine ≥ tuned threshold, per-node fan-out cap (reuse `minhash.MaxEdgesPerNode`), dedup on (min,max), deterministic ordering — mirrors `dataFlowsEdges`/`similarToEdges`.
- [ ] **RELATE-03c:** Wired into `factsFromExtracted` batch emission; EdgeID stamping path already covers it.
- [ ] **RELATE-03d:** **Distinctness + selectivity anti-vacuity guard** — on REAL parsed Go bodies: same-structure/disjoint-vocabulary → SIMILAR_TO and NOT SEMANTICALLY_RELATED; different-structure/shared-vocabulary → SEMANTICALLY_RELATED and NOT SIMILAR_TO; and a clearly-unrelated pair → NO edge (selectivity, proving the stop-list defeats boilerplate saturation). Mutation-confirmed (regress engine to structure, or remove the stop-list → test goes RED).
- [ ] **RELATE-03e:** Read surface confirmed via **`helix explain-symbol-deep`** — its incoming/outgoing edge accessors apply NO edge-kind filter and map every stored kind through `MapInternalKind`, so a stored SEMANTICALLY_RELATED edge surfaces verbatim in `edges_incoming`/`edges_outgoing`. **NOT** `get-change-impact-graph` (hardcoded to the `call_graph` projection + rewrites every edge `Kind` to `"calls"` → structurally cannot surface it) and **NOT** `validate-graph-edge` (its `SetEdgeEvidence` is deferred to Phase 75 → returns `evidence_lookup_unavailable` for all kinds in the real binary). Proven by `shapeEdges` unit test (kind passes through unfiltered).

## Success Criteria (Workstream A / this milestone)

1. SEMANTICALLY_RELATED edges are **emitted** on a real Go fixture (the kind goes from 0 producers → ≥1).
2. The distinctness guard is green AND mutation-confirmed RED when the discriminator is broken.
3. RI vectors are deterministic (re-extract → identical edge set).
4. **Zero new Go dependencies** (`go.mod` unchanged — RI uses stdlib + existing xxhash).
5. **No schema migration** (SEMANTICALLY_RELATED already in the surface enum + `validate_graph_edge`).
6. `go build ./...` clean; `go test ./internal/semantic/... ./internal/daemon/... ./internal/skill/semantic/...` green; `make vet` clean.
7. The edge is reachable from a `helix` verb — specifically `helix explain-symbol-deep` (its accessors apply no edge-kind filter); proven by the `shapeEdges` pass-through test. (Not via `get-change-impact-graph`/`validate-graph-edge` — see RELATE-03e for why.)
