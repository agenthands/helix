  <action>
    Create `internal/kernel/symbols/` package. Each function takes a Kernel (or WorkerLease) and returns structured results. The tools layer (Task 2) handles MCP formatting.

    **Common pattern:** Each function resolves a WorkerLease from the Kernel for the given workspace+session, makes one or more LSP requests, and formats results into a domain struct.

    **`retrieval.go` (SYM-01, SYM-02, SYM-05, SYM-06):**

    ```go
    type SymbolLocation struct {
        URI       string
        Range     Range  // line/col
        Preview   string // the line of code at this location
    }

    type HoverResult struct {
        Content  string // markdown content
        Language string // language ID for code blocks
    }
    ```

    - `GoToDefinition(ctx context.Context, lease *lspool.WorkerLease, uri string, line, col int) ([]SymbolLocation, error)` — SYM-01: Send textDocument/definition with TextDocumentPositionParams. Return locations with code preview (read line from file).
    - `FindReferences(ctx context.Context, lease *lspool.WorkerLease, uri string, line, col int, includeDecl bool) ([]SymbolLocation, error)` — SYM-02: Send textDocument/references with ReferenceParams. Return all reference locations.
    - `GetHover(ctx context.Context, lease *lspool.WorkerLease, uri string, line, col int) (*HoverResult, error)` — SYM-05: Send textDocument/hover. Extract markdown content from Hover.Contents.
    - `FindImplementations(ctx context.Context, lease *lspool.WorkerLease, uri string, line, col int) ([]SymbolLocation, error)` — SYM-06: Send textDocument/implementation. Return implementation locations.

    **`hierarchy.go` (SYM-07, SYM-08):**

    ```go
    type HierarchyNode struct {
        Name     string
        Kind     string
        URI      string
        Range    Range
        Children []HierarchyNode
    }
    ```

    - `GetCallHierarchy(ctx context.Context, lease *lspool.WorkerLease, uri string, line, col int, direction string) ([]HierarchyNode, error)` — SYM-07: Three-step protocol: (1) textDocument/prepareCallHierarchy to get CallHierarchyItem, (2) callHierarchy/incomingCalls or callHierarchy/outgoingCalls based on direction ("incoming", "outgoing", "both"), (3) Recurse up to 3 levels deep to build tree.
    - `GetTypeHierarchy(ctx context.Context, lease *lspool.WorkerLease, uri string, line, col int, direction string) ([]HierarchyNode, error)` — SYM-08: Three-step protocol: (1) textDocument/prepareTypeHierarchy, (2) typeHierarchy/subtypes or typeHierarchy/supertypes, (3) Recurse up to 3 levels.

    **`overview.go` (SYM-03):**

    ```go
    type SymbolOutline struct {
        Name     string
        Kind     string
        Range    Range
        Children []SymbolOutline
    }
    ```

    - `GetSymbolOverview(ctx context.Context, lease *lspool.WorkerLease, uri string) ([]SymbolOutline, error)` — SYM-03: Send textDocument/documentSymbol. Map DocumentSymbol[] response to SymbolOutline tree. Preserve hierarchy (classes containing methods, etc.).

    **`search.go` (SYM-04):**

    - `SearchSymbols(ctx context.Context, lease *lspool.WorkerLease, query string) ([]SymbolLocation, error)` — SYM-04: Send workspace/symbol with WorkspaceSymbolParams{query}. Map SymbolInformation[] to SymbolLocation[].

    **`blast.go` (SYM-09):**

    - `AnalyzeBlastRadius(ctx context.Context, lease *lspool.WorkerLease, uri string, line, col int) (*BlastRadius, error)` — SYM-09: Combined analysis:
      1. FindReferences to get all reference locations
      2. GetCallHierarchy (incoming) to find callers
      3. GetTypeHierarchy (subtypes) to find implementations
      4. Deduplicate locations across results
      5. Group by file for summary

    ```go
    type BlastRadius struct {
        DirectRefs     []SymbolLocation
        Callers        []HierarchyNode
        Implementations []SymbolLocation
        AffectedFiles  []string   // unique files
        TotalImpact    int        // total unique locations
    }
    ```

    - Test GetSymbolOverview preserves hierarchy (nested children).

    - Test hierarchy recursion stops at depth limit.
