    **`subscriber.go` (DGN-01) — Diagnostics subscription and storage:**

    ```go
    type DiagnosticStore struct {
        mu    sync.RWMutex
        byURI map[string][]Diagnostic  // keyed by document URI
    }
    ```

    - `NewDiagnosticStore() *DiagnosticStore`
    - `HandlePublishDiagnostics(params PublishDiagnosticsParams)` — Update stored diagnostics for URI. This is called when the worker receives a textDocument/publishDiagnostics notification from the LS.
    - `GetDiagnostics(uri string) []Diagnostic` — Return current diagnostics for a file.
    - `GetAllDiagnostics() map[string][]Diagnostic` — Return all diagnostics.
    - `WaitForDiagnostics(ctx context.Context, uri string, timeout time.Duration) ([]Diagnostic, error)` — Block until diagnostics arrive for URI or timeout. Use a condition variable or channel. This is essential for post-edit verification (EDT-06).
    - `Clear(uri string)` — Clear diagnostics for a URI (used before re-check).

    The DiagnosticStore must be registered as a notification handler on the Worker (or its JSON-RPC Conn). When the Conn receives a textDocument/publishDiagnostics notification, it should call HandlePublishDiagnostics.

    **`actions.go` (DGN-02) — Code actions / quick fixes:**

    - `GetCodeActions(ctx context.Context, lease *lspool.WorkerLease, uri string, startLine, startCol, endLine, endCol int) ([]CodeActionResult, error)` — Send textDocument/codeAction with CodeActionParams. The range can be a single position (same start/end) or a selection.
    - `ApplyCodeAction(ctx context.Context, lease *lspool.WorkerLease, action CodeActionResult) error` — If the action has an Edit (WorkspaceEdit), apply it via textDocument/applyEdit or by writing files directly.

    ```go
    type CodeActionResult struct {
        Title       string
        Kind        string
        IsPreferred bool
        Edit        *WorkspaceEdit  // nil if action requires a command
    }
    ```

    **`format.go` (DGN-03) — Format code via LSP:**

    - `FormatDocument(ctx context.Context, lease *lspool.WorkerLease, uri string, opts FormatOptions) ([]TextEditResult, error)` — Send textDocument/formatting. Return list of text edits.
    - `ApplyFormatEdits(path string, edits []TextEditResult) error` — Apply edits to file in reverse order (bottom-up to preserve line numbers). Atomic write.

    ```go
    type FormatOptions struct {
        TabSize      int
        InsertSpaces bool
    }
    type TextEditResult struct {
        StartLine int
        StartCol  int
        EndLine   int
        EndCol    int
        NewText   string
    }
    ```
