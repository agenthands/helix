    **Replace LanguageQuirks struct with QuirkAdapter interface:**
    ```go
    // QuirkAdapter provides per-language behavioral hooks for LS workers.
    // Languages with no special behavior use DefaultQuirkAdapter.
    type QuirkAdapter interface {
        // InitOptions returns language-specific initialization options.
        // workDir is the workspace root for workspace-dependent options.
        InitOptions(workDir string) map[string]any
        // NotificationHandlers returns handlers for LS-specific notifications.
        NotificationHandlers() map[string]func(params json.RawMessage)
        // NormalizeSymbolName adjusts symbol names for language conventions.
        NormalizeSymbolName(name string) string
        // PostInitialize is called after successful LSP initialize handshake.
        PostInitialize(ctx context.Context, adapter *LSAdapter) error
    }
    ```

    **DefaultQuirkAdapter** -- no-op implementation for LOW-quirk languages (30+ languages):
    ```go
    type DefaultQuirkAdapter struct{ entry langregistry.LSEntry }
    func (d *DefaultQuirkAdapter) InitOptions(workDir string) map[string]any { return d.entry.InitOptions }
    func (d *DefaultQuirkAdapter) NotificationHandlers() map[string]func(params json.RawMessage) { return nil }
    func (d *DefaultQuirkAdapter) NormalizeSymbolName(name string) string { return name }
    func (d *DefaultQuirkAdapter) PostInitialize(ctx context.Context, a *LSAdapter) error { return nil }
    ```

    **Language-specific adapters** for MEDIUM and HIGH quirk languages:
    - **GoplsAdapter**: custom InitOptions with experimentalWorkspaceModule, NormalizeSymbolName strips package prefix ("pkg.Foo" -> "Foo")
    - **RustAnalyzerAdapter**: cargo buildScripts enable in InitOptions
    - **ClangdAdapter**: looks for compile_commands.json in workDir
    - **JdtlsAdapter** (HIGH): creates workspace data dir, configures launcher args, handles jdtls-specific init
    - **VueAdapter** (HIGH): manages companion TypeScript server process internally

    **GetQuirkAdapter function:**
    ```go
    func GetQuirkAdapter(entry langregistry.LSEntry) QuirkAdapter
    ```
    Returns language-specific adapter if one exists, otherwise DefaultQuirkAdapter wrapping the entry.

    **Remove DefaultQuirks var** -- no longer needed; pool will use registry directly.

    **quirks_test.go:**
    - DefaultQuirkAdapter returns entry's InitOptions unchanged
    - GoplsAdapter.NormalizeSymbolName strips package prefix
    - GetQuirkAdapter returns specific adapter for "go", default for "bash"
    - JdtlsAdapter.PostInitialize creates workspace data dir (in tempdir)
