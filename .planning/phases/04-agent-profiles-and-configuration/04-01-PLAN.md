    ```go
    // Profile extends ContextSpec with agent-specific fields (per D-01, D-03).

        skill.ContextSpec     `yaml:",inline"`
        Prompt                string                       `yaml:"prompt"`                  // system prompt fragment
        ToolDescriptionOverrides map[string]string          `yaml:"tool_description_overrides"` // per-tool description rewrites (PRF-03)

        SingleProject         bool                         `yaml:"single_project"`          // restrict to one project
        AllowedModeTransitions map[string][]string          `yaml:"allowed_mode_transitions"` // state machine: mode -> allowed targets
    }

    // Mode extends ModeSpec with behavioral policies (per D-06).
    type Mode struct {
        skill.ModeSpec `yaml:",inline"`
        Prompt         string `yaml:"prompt"` // mode-specific prompt fragment (if not in ModeSpec.Prompts)
    }

    // ProfileStore holds loaded profiles and modes, keyed by name.
    type ProfileStore struct {
        profiles map[string]*Profile
        modes    map[string]*Mode
    }
    ```

    Profile specifics (per D-01, D-02):
    - **claude-code.yaml**: Exclude file tools Claude Code has natively (read_file, create_text_file, replace_content). Default mode: edit. Single project: true. Prompt emphasizes symbolic tools over file reads.
    - **codex.yaml**: Similar exclusions to claude-code. Default mode: edit. Prompt tuned for Codex's sandbox model.
    - **ide-assistant.yaml**: Exclude shell tools. Default mode: read. Single project: true. Prompt emphasizes quick lookups over deep analysis.
    - **ci-bot.yaml**: Read-only tools only (symbol retrieval, diagnostics, search). Default mode: review. Exclude ALL editing tools. Prompt emphasizes reporting not fixing.
    - **full.yaml**: All skills, no exclusions. Default mode: edit. Prompt is minimal/neutral. This is the escape hatch (per D-02).

    Create 4 mode YAML files in `internal/profile/modes/` (per D-05):
    - **read.yaml**: Include symbol retrieval, file read, search, memory read. Exclude all editing/mutation tools. Prompt: "Read-only exploration mode."
    - **edit.yaml**: Include all tools. Prompt: editing guidance from legacy editing.yml (symbolic editing instructions).
    - **review.yaml**: Include symbol retrieval, diagnostics, blast radius, memory tools. Exclude editing tools. Prompt: "Code review mode — analyze, don't modify."
    - **admin.yaml**: Include all tools plus config tools. Prompt: "Full administrative access."

    Allowed mode transitions (per D-05 state machine):
    - read -> [edit, review]
    - edit -> [read, review]
    - review -> [edit, read]
    - admin -> [read, edit, review] (admin can go anywhere)
    - No profile allows transition TO admin except from admin itself (safety).
