    1. Add fields to Daemon struct:
       - `kernel *kernel.Kernel`
       - `langRegistry *langregistry.Registry`
       - `profileStore *profile.ProfileStore`
       - `activeProfile *profile.Profile`
       - `diagStore *diag.DiagnosticStore`
       - `bodyExtractor *edit.BodyExtractor`

    2. Rewrite `New()` per D-06 (fail-fast for core subsystems) and D-08 startup order:
       a. Create langregistry: `langReg, err := langregistry.NewRegistry()` -- fail-fast on error
       b. Create installer: `installer := langregistry.NewInstaller(langregistry.InstallerConfig{AutoInstall: true, BinDir: filepath.Join(homeDir, ".serena", "bin")}, logger)`
       c. Create memory pressure: use build-tag-appropriate pressure (NewDarwinMemoryPressure on darwin, nil otherwise -- or use a helper)
       d. Convert WorkerPoolConfig to lspool.PoolConfig:
          ```go
          poolCfg := lspool.PoolConfig{
              BaseTTL: cfg.WorkerPool.BaseTTL,
              CeilingTTL: cfg.WorkerPool.CeilingTTL,
              MaxWorkers: cfg.WorkerPool.MaxWorkers,
              RSSHardCapMB: cfg.WorkerPool.RSSHardCapMB,
              PressureCheckInterval: cfg.WorkerPool.PressureCheckInterval,
          }
          if poolCfg.BaseTTL == 0 { poolCfg = lspool.DefaultPoolConfig() }
          ```
       e. Create kernel: `k := kernel.NewKernel(workspaces, langReg, installer, kernel.KernelConfig{Pool: poolCfg}, pressure, logger)`
       f. Create diagStore: `diagStore := diag.NewDiagnosticStore()`
       g. Create bodyExtractor: `bodyExtractor := edit.NewBodyExtractor()`
       h. Create MCP server (keep existing call): `mcpServer := serenaMCP.NewSerenaMCPServer(workspaces, logger)`
       i. Resolve profile per D-08: determine globalDir (`~/.serena`), call `config.ResolveProfile(cfg, globalDir)` -- fail-fast on error. Store profileStore and activeProfile.
       j. Initialize skills per D-07 (degraded mode for optional providers):
          ```go
          skillDeps := skill.SkillDeps{
              ProjectDir: filepath.Join(cfg.Daemon.SocketPath, ".."), // or appropriate project dir
              GlobalDir:  globalDir,
              Logger:     logger,
          }
          if err := skill.InitAll(skillDeps); err != nil {
              logger.Warn("skill initialization partially failed", "error", err)
              // Continue in degraded mode per D-07
          }
          ```
          NOTE: For ProjectDir, use a sensible default like `filepath.Join(globalDir, "default-project")` since the actual project dir is not known until activate_project is called. The skill deps ProjectDir is for global state -- memories will use the active workspace once set.
       k. Register kernel tools with MCP server (these use the actual RegisterTools functions, not the skill ToolDef lists):
          ```go
          // wsKeyFn closure -- returns the active workspace key (will be updated when project activates)
          var activeWSKey workspace.WorkspaceKey
          wsKeyFn := func() workspace.WorkspaceKey { return activeWSKey }
          workspaceRootFn := func() string { return activeWSKey.RepoRoot }

          symbols.RegisterTools(mcpServer, k, wsKeyFn)
          editsym.RegisterTools(mcpServer, k, bodyExtractor, diagStore, wsKeyFn)
          fileops.RegisterTools(mcpServer, workspaceRootFn)

          // Diag lease provider
          leaseFn := func(ctx context.Context, uri string) (*lspool.WorkerLease, error) {
              return k.Pool().AcquireLease(ctx, "diag-"+uri, activeWSKey, false)
          }
          diag.RegisterTools(mcpServer, diagStore, workspaceRootFn, leaseFn)
          ```
       l. Register skill-provided tools with MCP SDK. For each ToolProvider, iterate its Tools() and for tools that have an ExecuteTool method (memory, workflow skills), create MCP tool handlers that parse JSON args and call ExecuteTool:
          ```go
          for _, tp := range skill.ToolProviders() {
              // Skip kernel skill adapters (already registered via RegisterTools above)
              switch tp.Name() {
              case "symbol-retrieval", "symbol-editing", "file-ops", "diagnostics":
                  continue
              }
              registerSkillTools(mcpServer, tp)
          }
          ```
          Create a helper `registerSkillTools` that iterates tp.Tools() and for each ToolDef creates an MCP tool handler. The handler should:
          - Accept a generic `map[string]interface{}` args struct
          - Call the skill's ExecuteTool method (type-assert tp to an interface with `ExecuteTool(name string, args map[string]interface{}) (string, error)`)
          - Return the result as TextContent
       m. Wire profile skill session provider:
          ```go
          if ps := profile.GetProfileSkill(); ps != nil {
              ps.SetSessionProvider(sessionProvider) // need a SessionProvider impl
          }
          ```
       n. Install ProfileFilterMiddleware on the MCP server:
          ```go
          mcpServer.SDK().AddReceivingMiddleware(serenaMCP.ProfileFilterMiddleware(profileStore, getSessionFn, logger))
          ```

    3. Update the `Run()` method to add kernel.Run to the errgroup:
       ```go
       g.Go(func() error {
           return d.kernel.Run(gctx)
       ```
