  a. Calls `t.Helper()`
  b. Creates config via local `defaultTestConfig(t)` (adapts `newE2EConfig` pattern: `t.TempDir()` for socket/dirs, sets `cfg.Daemon.SocketPath`, `cfg.Profile = "full"`, `cfg.WorkerPool.MaxWorkers = 2`, `cfg.WorkerPool.BaseTTL = 30`)

  e. Calls `daemon.New(cfg, logger)` 
  f. Creates `context.WithCancel(context.Background())`
  g. Starts `go d.KernelInstance().Run(ctx)` in background goroutine
  h. Creates in-memory transports: `clientTransport, serverTransport := mcp.NewInMemoryTransports()`
  i. Connects server side FIRST: `d.MCPServer().SDK().Connect(ctx, serverTransport, nil)`
  j. Creates client: `client := mcp.NewClient(&mcp.Implementation{Name: "test-client", Version: "1.0"}, nil)`
  k. Connects client: `session, err := client.Connect(ctx, clientTransport, nil)`
  l. Registers `t.Cleanup(td.Stop)` where `Stop` cancels context (which stops kernel Run goroutine, triggering pool.stopAll)
  m. If `opts.WorkspaceDir != ""`, calls `session.CallTool` with `activate_project` and `repo_path: opts.WorkspaceDir`
  n. If workspace activated and `!opts.SkipLS`, calls `WaitForLS(t, session, opts.LSTimeout)` (default 30s if 0)

- **`(td *TestDaemon) Stop()`** method: calls `td.cancel()` to stop kernel goroutine.

- **`WaitForLS(t *testing.T, session *mcp.ClientSession, timeout time.Duration)`** function that:
  a. Creates `context.WithTimeout` with the given timeout
  b. Polls every 200ms calling `session.CallTool(ctx, &mcp.CallToolParams{Name: "search_symbols", Arguments: map[string]any{"query": "main", "scope": "workspace"}})`
  c. Returns when err == nil and !result.IsError and len(result.Content) > 0
  d. Calls `t.Fatalf("LS readiness timeout after %v", timeout)` on context deadline

- **`requireGopls(t *testing.T)`** function: calls `exec.LookPath("gopls")`, if err calls `t.Skip("gopls not installed, skipping LSP integration test")`

- **`PrepareFixture(t *testing.T, lang string) string`** function: copies `testdata/fixtures/{lang}/` to `t.TempDir()` recursively using `filepath.WalkDir`, returns destination path.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| test harness -> daemon | Tests call daemon.New() in-process -- same trust domain, no external input |
| daemon -> gopls | Daemon spawns gopls subprocess -- trusted local tool, no untrusted input |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | D (Denial of Service) | gopls process leak | mitigate | t.Cleanup(td.Stop) cancels context, triggering pool.stopAll which sends LSP shutdown/exit to all workers |
| T-06-02 | T (Tampering) | fixture files | accept | Fixtures are test-only data in testdata/, not production code. Copy-on-use via t.TempDir() prevents cross-test contamination |
| T-06-03 | D (Denial of Service) | LS readiness timeout | mitigate | WaitForLS uses context.WithTimeout (30s default) and t.Fatalf on deadline -- test fails cleanly, no hang |
</threat_model>
