Fix the Language field bug that prevents LS-backed tools from spawning gopls workers. The root cause is a two-part problem:

**Part A: WorkspaceRuntime.AcquireSession passes empty Language to pool**

In `internal/kernel/workspace.go`, the `AcquireSession` method passes `w.key` to pool, but `w.key.Language` is always "" because `DetectLanguages` sets `w.languages` but never updates `w.key`.

Fix: Modify `AcquireSession` to build a language-specific key from the first detected language before passing to pool. This is the correct place because a workspace may have multiple languages, and the pool needs a specific language per lease:

```go
func (w *WorkspaceRuntime) AcquireSession(ctx context.Context, sessionID string, dirty bool) (*lspool.WorkerLease, error) {
    w.mu.RLock()
    lang := ""
    if len(w.languages) > 0 {
        lang = w.languages[0]
    }
    w.mu.RUnlock()

    key := w.key
    if key.Language == "" && lang != "" {
        key.Language = lang
    }
    return w.pool.AcquireLease(ctx, sessionID, key, dirty)
}
```

**Part B: daemon.go activeWSKey has empty Language**

In `internal/daemon/daemon.go`, line 184, `activeWSKey` is set without Language. The `wsKeyFn` closure returns this key, and symbol tools use it to look up the runtime via `k.GetRuntime(wsKey)`.

IMPORTANT: The runtime is stored in `k.workspaces` with a hash computed from `Language: ""`. If we change `activeWSKey.Language` to "go", the hash won't match and `GetRuntime` will return "workspace runtime not found". Therefore we must NOT change the Language in `activeWSKey` used for runtime lookup.

However, the `leaseFn` closure on line 140-142 ALSO uses `activeWSKey` directly for `pool.AcquireLease`. This diagnostic lease acquisition bypasses `WorkspaceRuntime.AcquireSession` entirely, so Part A doesn't help it.

Fix: Add a separate `activeWSLang` variable next to `activeWSKey`, populated from `rt.Languages()` after workspace activation. Update the `leaseFn` closure to use a key with the language populated:

```go
// After line 131:
var activeWSLang string

// In leaseFn (lines 140-142), replace:
//   return k.Pool().AcquireLease(ctx, "diag-"+uri, activeWSKey, false)
// with:
leaseFn := func(ctx context.Context, uri string) (*lspool.WorkerLease, error) {
    key := activeWSKey
    if key.Language == "" && activeWSLang != "" {
        key.Language = activeWSLang
    }
    return k.Pool().AcquireLease(ctx, "diag-"+uri, key, false)
}

// In activate callback (after line 184), add:
if langs := rt.Languages(); len(langs) > 0 {
    activeWSLang = langs[0]
}
```

Do NOT change `activeWSKey.Language` itself -- that would break `GetRuntime` hash lookups.
