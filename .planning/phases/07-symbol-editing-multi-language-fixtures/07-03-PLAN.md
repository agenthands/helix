```java
public class Main {
    public static String helper() {
        return "hello";
    }

    public static void unusedMethod() {}

    public static String usingHelper() {
        return helper();
    }

    public static void main(String[] args) {
        Greeter g = new SimpleGreeter();
        System.out.println(g.greet("World"));
        System.out.println(helper());
    }
}
```

```java
interface Greeter {
    String greet(String name);
}

class SimpleGreeter implements Greeter {
    @Override
    public String greet(String name) {
        return "Hello, " + name + "!";
    }
}
```

Try bare files first per D-01 (keep it simple). jdtls is the most unpredictable LS -- if it cannot index bare .java files, add the minimum project marker needed and document in the SUMMARY.
