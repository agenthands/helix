<objective>
Refactor the existing integration test harness entry points to accept `testing.TB` instead of `*testing.T`, unblocking benchmark reuse of the same daemon startup, fixture preparation, and tool-call helpers. This is the Wave 0 blocker identified in 09-RESEARCH.md: without this refactor, no benchmark in Phase 9 can compile.

Purpose: BENCH-01 mandates benchmarks in `test/bench/` using `testing.B.Loop`. The harness reuse strategy documented in 09-CONTEXT.md canonical_refs is literally impossible today because every entry point takes `*testing.T`. `*testing.B` does not satisfy that type. `testing.TB` is the interface both satisfy.

Output: `test/integration/harness.go` and `test/integration/helpers.go` accept `testing.TB`; all existing `go test -tags integration ./test/integration/...` tests keep compiling and passing.
</objective>
