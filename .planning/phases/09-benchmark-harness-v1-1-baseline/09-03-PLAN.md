    2. Implement:
       ```go
       func BenchmarkTools(b *testing.B) {
           requireGoplsB(b)
           bd := startBenchDaemon(b)
           fixture := prepareGoFixtureB(b)
           activateWorkspaceB(b, bd, fixture)

           for _, tc := range benchTools {
               tc := tc // capture
               b.Run(tc.name, func(b *testing.B) {
                   // Warmup: 3 calls before measured loop (per phase Q6).
                   // Purpose: prime gopls symbol caches + any lazy init in the
                   // kernel tool dispatcher so the measured window reflects
                   // steady-state latency, not first-touch penalties.
                   for i := 0; i < 3; i++ {
                       _ = callToolB(b, bd.Session, tc.name, tc.args)
                   }
                   b.ReportAllocs()
                   var sink any
                   for b.Loop() {
                       r := callToolB(b, bd.Session, tc.name, tc.args)
                       sink = r
                   }
                   _ = sink
               })
           }
       }
       ```
    3. **Edit tool mutation safety:** The 6 edit tools (`replace_symbol_body`, `insert_before_symbol`, `insert_after_symbol`, `rename_symbol`, `safe_delete_symbol`, `verify_edit`) MUTATE fixture files and CANNOT share the read-only `prepareGoFixtureB` path used above. For these 6 sub-benchmarks, wrap the inner body with `b.StopTimer()` / `b.StartTimer()` around a per-iteration `prepareGoFixtureCopyB(b)` call + `activateWorkspaceB(b, bd, copyDir)` so each iteration operates on a fresh mutable copy. The daemon is still shared across iterations, but the workspace is re-activated to the fresh copy. Example:
       ```go
       isEditTool := map[string]bool{
           "replace_symbol_body": true, "insert_before_symbol": true, "insert_after_symbol": true,
           "rename_symbol": true, "safe_delete_symbol": true, "verify_edit": true,
       }
       // inside b.Run(tc.name, ...):
       if isEditTool[tc.name] {
           for b.Loop() {
               b.StopTimer()
               fresh := prepareGoFixtureCopyB(b)
               activateWorkspaceB(b, bd, fresh)
               b.StartTimer()
               _ = callToolB(b, bd.Session, tc.name, tc.args)
           }
       } else {
           for b.Loop() {
               _ = callToolB(b, bd.Session, tc.name, tc.args)
           }
       }
       ```
       Document inline: "Plan 09-02 revision added prepareGoFixtureCopyB to fix the fixture-mutation hazard the checker flagged (WARNING 1)."
    4. Critical rules (enforced in code review by the verify command):
       - MUST use `for b.Loop()` — never `for i := 0; i < b.N; i++` (Pitfall 3, BENCH-01)
       - MUST call `b.ReportAllocs()` inside the sub-benchmark AFTER warmup but BEFORE the loop
       - MUST `b.Fatal` on tool error (already the behavior of callToolB per Plan 02)
       - MUST assign result to `sink` so the compiler cannot hoist (belt-and-suspenders over b.Loop's own elision prevention)
       - MUST NOT call `b.ResetTimer()` — Anti-Patterns section forbids it with b.Loop
       - MUST NOT start a daemon inside the loop — Pitfall 6 (goroutine leaks)
