<objective>
Add the two thin, build-tag-gated adapters over the pure `adopt` scorer from Plan 01:
(1) a `//go:build llm` live capture leg that interrogates a real model with the intact and
matrix-stripped skill, writes transcripts, and feeds them to the SAME `adopt.Scorecard`;
(2) a `//go:build llmjudge` extension adding an `adoption` dimension to the judge rubric with an
explicit negative exemplar (a `grep -r` response scores 0.0 on adoption) so `ComputeVerdict` can
return a failing verdict.

Purpose: ROADMAP SC#2 requires the judge rubric to include a negative exemplar so the rubric can
demonstrably FAIL; the live leg is the opt-in informational measurement against a real model. Both
legs are tag-gated and excluded from `go test ./...` (verified: `go list ./test/oracle/llm/...`
matches no packages without `-tags`), so neither ever blocks merge — the authoritative non-vacuity
proof remains the hermetic Plan 01 leg.

Output: `test/oracle/llm/adoption_scorecard_test.go` (live), an extended
`test/oracle/judge/rubric.go` + `aggregate.go` (6th dimension), and
`test/oracle/judge/adoption_exemplar_test.go` (the negative-exemplar verdict proof).
</objective>
