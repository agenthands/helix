    Step 2 — Create `internal/kernel/spanwrap.go`:
    ```go
    package kernel

    import (
        "context"
        "go.opentelemetry.io/otel/trace"
        mcpsdk "github.com/modelcontextprotocol/go-sdk/mcp" // match existing import alias
    )

    // WrapToolSpan wraps an MCP tool handler so every invocation creates a
    // kernel.tool.{name} span. The helper is applied at RegisterTools time so
    // the per-handler body stays untouched.
    //
    // Usage:
    //   mcpsdk.AddTool(server.SDK(), &mcpsdk.Tool{Name: "find_references"},
    //       WrapToolSpan(k.Tracer(), "find_references", findReferencesHandler))
    //
    // Type parameter Args matches the typed-args pattern already used by kernel tools.
    func WrapToolSpan[Args any, Result any](
        tracer trace.Tracer,
        toolName string,
        fn func(ctx context.Context, req *mcpsdk.CallToolRequest, args Args) (*mcpsdk.CallToolResult, Result, error),
    ) func(ctx context.Context, req *mcpsdk.CallToolRequest, args Args) (*mcpsdk.CallToolResult, Result, error) {
        spanName := "kernel.tool." + toolName
        return func(ctx context.Context, req *mcpsdk.CallToolRequest, args Args) (*mcpsdk.CallToolResult, Result, error) {
            ctx, span := tracer.Start(ctx, spanName)
            defer span.End()
            result, extra, err := fn(ctx, req, args)
            if err != nil && span.IsRecording() {
                span.RecordError(err)
            }
            return result, extra, err
        }
    }
    ```
    Per D-07: NO attributes on kernel spans — the middleware span carries tool_name/profile/mode/language/outcome. The kernel sub-span name is sufficient ID. This keeps the tracing-off budget tight (IsRecording false → RecordError skipped).

    Generic signature matches the existing typed-args MCP SDK pattern. Confirm the exact generic shape against an existing `mcpsdk.AddTool` call before finalizing — if the SDK uses a different generic arity (e.g., only `Args`, no `Result` type param), adapt to match. Discretion: if Go generics cannot cleanly express the handler shape, fall back to a non-generic `func(context.Context, any, any) (any, error)` wrapper applied inside each tool package (still ONE helper definition, just slightly more verbose).

    ```go
    import "go.opentelemetry.io/otel/trace"
    import "go.opentelemetry.io/otel/attribute"

    // Measure duration around the existing JSON-RPC call.
    start := time.Now()
    resp, err := /* existing JSON-RPC call */
    duration := time.Since(start)

    if span := trace.SpanFromContext(ctx); span.IsRecording() {
        span.AddEvent("ls.request", trace.WithAttributes(
            attribute.String("lsp.method", method),
            attribute.String("lsp.language", w.language), // or whichever field holds the LS language
            attribute.Int64("lsp.duration_ms", duration.Milliseconds()),
        ))
    }
    return resp, err
    ```

    CRITICAL — D-17 budget: the `span.IsRecording()` gate is mandatory. Without it, every LS request allocates the attribute slice even when tracing is off. `trace.SpanFromContext` returns a noop span (not nil) when no span is active — noop spans always report IsRecording()==false.

    CRITICAL — D-06: this is a span EVENT, not a child span. Do NOT call `tracer.Start` here — that would double the span count and blow PITFALLS #7 budget. `span.AddEvent` on the ambient kernel tool span is the contract.

    CRITICAL — PITFALLS #12 (sensitive data): only `method`, `language`, `duration_ms` go on the event. NEVER `params`, `uri`, `file.path`, `symbol.name`, or any field-content data — those would leak workspace contents to the exporter.
