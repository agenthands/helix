<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| forwarder → daemon (gRPC) | Traceparent metadata crosses a process boundary; the daemon trusts the forwarder-supplied trace IDs |
| daemon → OTLP collector | Span batch crosses the loopback network; operator-trusted collector in v1.2 |
| kernel → language server | JSON-RPC; LS is in-process child — no trust boundary for tracing |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-01 | Information Disclosure | Span attributes on kernel.tool.* spans | mitigate | D-07 contract: NO attributes on kernel sub-spans; enforced by Plan 04 acceptance criterion `SetAttributes ZERO matches in spanwrap.go` |
| T-12-02 | Information Disclosure | ls.request span events in lspool worker | mitigate | Allowlist only lsp.method, lsp.language, lsp.duration_ms; enforced by Plan 04 acceptance criterion `file.path\|symbol.name\|uri` zero new matches |
| T-12-03 | Denial of Service (collector) | Unbounded cardinality from tool_name or profile values | mitigate | Bounded by the Phase 11 metrics label allowlist already enforced by CI lint; span attributes reuse the same bounded values |
| T-12-04 | Information Disclosure in transit | OTLP/gRPC with WithInsecure() pointed at non-loopback host | accept | v1.2 documents loopback-default in USAGE.md (Phase 14); TLS configuration deferred to v1.3 |
| T-12-05 | Availability of observability | Shutdown race drops in-flight spans on SIGTERM | mitigate | Plan 02 Task 1 + Plan 05 Task 2: dedicated 5s flush context; TestTraceFlushOnShutdown pins it |
| T-12-06 | Tampering | Malicious forwarder supplies forged traceparent IDs | accept | Forwarder runs in the user's own process tree; no multi-tenant scenario in v1.2; traceparent forgery has no security impact locally |
| T-12-07 | Elevation of Privilege | otel.SetTracerProvider global abuse poisons all providers | mitigate | D-01 + acceptance criteria in Plans 01/02/03/04: `grep otel.SetTracerProvider` returns zero matches across internal/ |
</threat_model>
