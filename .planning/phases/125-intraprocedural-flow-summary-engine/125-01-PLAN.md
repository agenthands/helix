# PLAN 125-01 — Intraprocedural flow-summary engine

## What (the deliverable)

A pure-Go leaf package `internal/semantic/dataflow/` that computes a **case-1
param→{return, call-arg} flow summary** over a function body, plumbed through the
existing `FingerprintBody` seam so all 11 providers inherit it with no per-provider
edit.

## Steps (build order)

1. **`internal/semantic/dataflow/summary.go`** — types + `AnalyzeFlow`:
   - `Summary{ Params []ParamFlow }`; `ParamFlow{ Name string; Index int; Returns bool; CallArgs []CallArgTarget }`; `CallArgTarget{ Callee string; ArgPos int }`.
   - `AnalyzeFlow(node, source) *Summary`:
     - Resolve the function-declaration node (if `node` is a body/block, ascend to parent; else use `node`).
     - Collect ordered param names from the parameter-list child (kind union: `formal_parameters|parameter_list|function_value_parameters`; param idents: `identifier|variable_name|simple_identifier|field_identifier`).
     - Seed taint `map[varname]map[int]bool` with each param → {its index}.
     - Forward walk over the body in source order:
       - **Assignment** (`assignment_expression|short_var_declaration|assignment_statement|variable_declaration|let_declaration|const_declaration|init_declaration|variable_declarator`): if RHS contains a tainted ident, union RHS origins → LHS ident.
       - **Return** (`return_statement|return_expression`): for each tainted ident in the returned expr, mark `Returns` on its origin params.
       - **Call** (`call_expression|method_invocation|function_call_expression|invocation_expression`): callee name = the function child text; for each arg at position i (from `argument_list|argument_list|arguments`), if the arg is a tainted ident, record `CallArgTarget{Callee, i}` on its origin params.
     - Build `Summary` (skip params with no targets — anti-vacuity).
   - Determinism: no Go-map iteration in any ordered output; sort CallArgs by (Callee, ArgPos); Params in index order.

2. **`internal/semantic/dataflow/dataflow_test.go`** — the 4 fixtures (return / call / transitive / empty) via a tiny Go tree-sitter parse helper, + determinism. Fixtures parsed from Go source strings through the registered Go provider's tree (reuse `testutil` if it exposes a parser; else parse via `tree_sitter.Parser` + the go grammar already vendored).

3. **`internal/semantic/extract/fact.go`** — add `FlowSummary *dataflow.Summary` to `SymbolFact` (next to `MinHash`/`Profile`/`ContextVec`); fix the now-stale fingerprint doc comment (`DATA_FLOWS (ASTProfile)` → `STRUCTURAL_TWIN (ASTProfile)`; add `DATA_FLOWS (FlowSummary)` note).

4. **`internal/semantic/extract/fingerprint.go`** — `FingerprintBody` calls `dataflow.AnalyzeFlow(body, source)` and stamps `sf.FlowSummary` (gate: body != nil; nil Summary stays when nothing reaches).

5. **`internal/daemon/semantic_similarity_edges.go`** — add `flow *dataflow.Summary` field to `fingerprintedNode` (Phase 126 reads it).

6. **`internal/daemon/semantic_wiring.go`** — populate `flow` in the `fpNodes` collection (~:2023) from `es.FlowSummary`.

7. **`internal/semantic/extract/golang/provider_contextvec_test.go`** sibling — a `provider_flowsummary_test.go` asserting `FlowSummary` populated for a Go function body, nil for a container kind (mirrors the ContextVec e2e proof).
