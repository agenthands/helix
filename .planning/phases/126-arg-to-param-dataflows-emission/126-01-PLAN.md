# PLAN 126-01 — Arg→param DATA_FLOWS emission + read surface + reachability

## What (the deliverable)

Emit real `DATA_FLOWS` edges (caller.param → callee.param) from Phase 125's
FlowSummaries; prove the edges are a distinct flow signal, reachable from
`helix explain-symbol-deep`, and that multi-hop source→sink reachability holds.
This phase IS the feature (Phase 127 collapsed — reachability = graph walk).

## Steps

1. **Callee-param index (emit-order adjacency, D1b)** — in `factsFromExtracted`'s
   per-file loop, build a batch-wide `nodeToParams map[uint64][]uint64`: for each
   function/method symbol at index k in `single.Symbols`, its params are the
   maximal consecutive `KindParameter` run starting at k+1. Declared before the
   file loop; populated per-file where `single.Symbols` (emit-ordered, NodeIDs
   assigned) is in scope.

2. **Anti-mis-bind multiplicity (D5)** — extend the name-index loop
   (`semantic_wiring.go:2327`) to also build `nameCount map[string]int`. A callee
   name resolves for DATA_FLOWS only when `nameCount == 1` (overloads/duplicates ⇒
   no edge).

3. **`dataFlowEdges(nodes, nodeToParams, nameToNode, nameCount)`** in
   `semantic_similarity_edges.go`:
   - For each `fingerprintedNode` carrying a non-nil `flow`, for each `ParamFlow`
     + its `CallArgs`: resolve the caller's param node (`nodeToParams[caller][pf.Index]`),
     resolve the callee (`nameToNode[ca.Callee]` only if `nameCount==1`), resolve
     the callee's param node (`nodeToParams[callee][ca.ArgPos]`), emit
     `DATA_FLOWS` (Src=caller.param, Dst=callee.param, Source="def_use", conf 0.55).
   - Directed dedup on `(SrcNodeID, DstNodeID)` (D8); skip self/zero/unresolved
     (D2 honesty); process nodes in ascending NodeID for determinism.
   - Bounded by dedup (distinct param pairs), not the similarity cap (D7).

4. **Wire** at `semantic_wiring.go:2402`: `out.Edges = append(out.Edges,
   dataFlowEdges(fpNodes, nodeToParams, nameToNode, nameCount)...)`. EdgeID
   stamping covers it (D9, the dense stamp at :1608 runs over all facts.Edges).

5. **Guards / tests** (`semantic_similarity_edges_test.go` / a new e2e):
   - **Emission + read surface:** a real-Go multi-function fixture emits a
     `DATA_FLOWS` edge; `MapInternalKind("DATA_FLOWS")` maps it; the edge is
     structurally a caller.param → callee.param.
   - **Forwarding guard (anti-vacuity):** tainted-arg-passed emits; a
     non-forwarded param does NOT (revert-and-fail RED).
   - **Distinctness:** a `DATA_FLOWS` edge exists where no `STRUCTURAL_TWIN`/
     `SIMILAR_TO` does on a shared fixture.
   - **Anti-mis-bind:** two same-named callees ⇒ no DATA_FLOWS edge for either.
   - **Reachability (folded Phase 127):** in-repo `src → f(x) → g(x) → sink`
     chain is reachable end-to-end by walking emitted DATA_FLOWS edges; breaking
     a hop breaks reachability (revert-and-fail).
