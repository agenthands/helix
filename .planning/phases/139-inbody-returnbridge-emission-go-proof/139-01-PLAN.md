## Steps (build order)

### 1. `inBodyDataFlowEdges` (`semantic_similarity_edges.go`, mirror `dataFlowEdges`)
```
func inBodyDataFlowEdges(nodes []fingerprintedNode, nodeToParams map[uint64][]uint64,
    nameToNode map[string]uint64, nameCount map[string]int) []semanticstore.EdgeFact
```
- Build the SAME sorted `withFlow` list, but gate on `n.flow != nil && len(n.flow.InBodyFlows) > 0`.
- For each node, for each `ib := range n.flow.InBodyFlows` (already dedup-sorted by Phase 138):
  - Resolve producer FUNCTION node: `if nameCount[ib.Producer] != 1 { continue }`;
    `prodNode := nameToNode[ib.Producer]`; `if prodNode == 0 { continue }`.
  - Resolve consumer FUNCTION node: `if nameCount[ib.Consumer] != 1 { continue }`;
    `consNode := nameToNode[ib.Consumer]`; `if consNode == 0 { continue }`.
  - Resolve consumer PARAM node: `cp := nodeToParams[consNode]`;
    `if ib.ArgPos < 0 || ib.ArgPos >= len(cp) { continue }`; `dstParam := cp[ib.ArgPos]`;
    `if dstParam == 0 { continue }`. Also `if prodNode == dstParam { continue }` (self-guard).
  - Directed dedup on `[2]uint64{prodNode, dstParam}`.
  - Emit `EdgeFact{ SrcNodeID: prodNode, DstNodeID: dstParam, SrcKind:"function",
    DstKind:"parameter", EdgeKind:"DATA_FLOWS", Source:"def_use_inbody", Confidence:0.50,
    Weight:0.5, Reason: fmt.Sprintf("return of %s -> %s param%d", ib.Producer, ib.Consumer, ib.ArgPos) }`.

### 2. Return-bridge pass (M4 determinism) — same file
- Add `returnBridgeEdges(nodes []fingerprintedNode, nodeToParams map[uint64][]uint64) []EdgeFact`.
- Build the SAME sorted `withFlow` list (gate `n.flow != nil && len(n.flow.Params) > 0`).
- For each node in sorted order: `fnParams := nodeToParams[n.nodeID]` (LOOKUP only — never range
  the map); for each `pf := range n.flow.Params` with `pf.Returns`:
  - `if pf.Index < 0 || pf.Index >= len(fnParams) { continue }`; `srcParam := fnParams[pf.Index]`;
    `if srcParam == 0 || srcParam == n.nodeID { continue }`.
  - Directed dedup on `[2]uint64{srcParam, n.nodeID}`.
  - Emit `EdgeFact{ SrcNodeID: srcParam, DstNodeID: n.nodeID, SrcKind:"parameter",
    DstKind:"function", EdgeKind:"DATA_FLOWS", Source:"def_use_return", Confidence:0.55,
    Weight:0.5, Reason: fmt.Sprintf("param%d -> return", pf.Index) }`.
- NOTE: iterating `withFlow` (sorted) + `nodeToParams` LOOKUP keeps emission order deterministic
  (M4). Do NOT `for k := range nodeToParams` — that is the map-iteration landmine.
