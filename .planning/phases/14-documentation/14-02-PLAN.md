    ## Troubleshooting

    ### Language Server Not Starting
    - Check: is the LS binary in PATH? Run `which <command>` (e.g. `which gopls`)
    - Three-tier resolution: 1) PATH lookup, 2) managed download (npm/pip/cargo/binary), 3) helpful error with install hint
    - Fix: install using the hint from `InstallHint()` (show examples: `npm install -g pyright`, `go install golang.org/x/tools/gopls@latest`)

    ### Cache Issues / Stale Results
    - Symptom: symbol definitions point to old locations after refactoring
    - Fix: the worker pool uses share-until-dirty semantics; editing through Serena automatically invalidates
    - If editing outside Serena: restart the session or use the workspace reload mechanism

    ### Mode Restrictions
    - Symptom: "tool not available in current mode" error
    - Fix: check current mode with `get_token_budget`, switch with `switch_mode` to a mode that includes the needed tool
    - Document which tools are mode-restricted

    ### Circuit Breaker Open
    - Symptom: `ErrCircuitOpen` error from lspool
    - Cause: language server crashed repeatedly (exceeding restart_budget)
    - Fix: check LS logs, fix the underlying LS issue, circuit auto-recovers via half-open probe with decorrelated jitter

    ### Memory Pressure
    - Symptom: workers evicted, performance degrades
    - Fix: increase `memory_limit_mb` or reduce concurrent workspaces
    - Monitoring: check `/metrics` on admin listener for `serena_lspool_evictions_total`

    ## Observability Quickstart

    ### Enable the Admin Listener
    ```yaml
    # ~/.serena/serena_config.yml
    observability:
      admin_addr: "127.0.0.1:9100"
    ```
    Or via CLI: `serena --admin-addr=127.0.0.1:9100`

    ### Health Checks
    - `curl http://127.0.0.1:9100/healthz` -- liveness (always 200 if daemon is up)
    - `curl http://127.0.0.1:9100/readyz` -- readiness (200 when daemon is fully initialized)

    ### Prometheus Metrics
    - Scrape `http://127.0.0.1:9100/metrics`
    - Key metrics:
      - `serena_tool_duration_seconds{tool_name, outcome}` -- RED histograms per tool
      - `serena_lspool_workers` -- current worker count
      - `serena_lspool_evictions_total` -- eviction counter
      - `serena_lspool_circuit_state` -- circuit breaker state gauge

    ### Enable Tracing
    ```yaml
    observability:
      tracing_endpoint: "localhost:4317"  # OTLP/gRPC collector
      tracing_sample_ratio: 0.1          # 10% sampling
    ```

    ### Enable pprof
    ```yaml
    observability:
      admin_addr: "127.0.0.1:9100"
      enable_pprof: true  # requires admin mode
    ```
    Access at `http://127.0.0.1:9100/debug/pprof/`
