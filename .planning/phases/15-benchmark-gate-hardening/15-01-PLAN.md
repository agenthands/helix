**Create `.github/workflows/capture-baseline.yml`** (per D-01, D-02):

A `workflow_dispatch`-only workflow that captures benchmark numbers on ubuntu-latest and auto-commits them. Must mirror bench.yml environment exactly:

```yaml
name: capture-baseline

on:
  workflow_dispatch:
    inputs:
      milestone:
        description: 'Milestone tag for baseline file (e.g., v1.1)'
        required: true
        default: 'v1.1'

permissions:
  contents: write

jobs:
  capture:
    name: Capture baseline (ubuntu-latest)
    runs-on: ubuntu-latest
    timeout-minutes: 30
    env:
      GOMAXPROCS: "4"
      GOPLS_VERSION: v0.17.1
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-go@v5
        with:
          go-version: '1.25.x'
          cache: true

      - name: Install pinned gopls
        run: go install golang.org/x/tools/gopls@${GOPLS_VERSION}

      - name: Install benchstat
        run: go install golang.org/x/perf/cmd/benchstat@latest

      - name: Run benchmark suite
        run: |
          set -euo pipefail
          go test -short -bench=. -benchmem -count=10 -run=^$ \
            ./test/bench/... | tee test/bench/baselines/${{ inputs.milestone }}-github-hosted.txt

      - name: Verify capture
        run: |
          LINES=$(grep -c "^Benchmark" test/bench/baselines/${{ inputs.milestone }}-github-hosted.txt || true)
          echo "Captured ${LINES} benchmark lines"
          if [ "${LINES}" -lt 5 ]; then
            echo "ERROR: Expected at least 5 benchmark lines, got ${LINES}"
            exit 1
          fi

      - name: Commit baseline
        uses: stefanzweifel/git-auto-commit-action@v5
        with:
          commit_message: "bench: capture ${{ inputs.milestone }} baseline from ubuntu-latest CI"
          file_pattern: 'test/bench/baselines/*.txt'
```

Key design points:
- `workflow_dispatch` only — manual trigger for re-baselining (per D-01)
- `contents: write` permission for auto-commit (per D-02)
- `GOMAXPROCS: "4"`, `GOPLS_VERSION: v0.17.1`, `go-version: '1.25.x'` — exactly mirrors bench.yml (Pitfall 1)
- `-short -bench=. -benchmem -count=10 -run=^$` — exactly mirrors bench.yml flags (Pitfall 1)
- Verification step checks at least 5 `^Benchmark` lines exist (Pitfall 2)
- Uses `stefanzweifel/git-auto-commit-action@v5` for auto-commit (per D-02)
- `milestone` input defaults to `v1.1` — parameterized for future milestones (per D-04)
