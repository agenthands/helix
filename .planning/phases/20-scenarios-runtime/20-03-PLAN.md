    6. Assert `IsError` is true, no misleading success phrases

    **TestDeferred_ErrorCategories_Timeout:**
    1. Use Go fixture with `harness.RequireGopls(t)`
    2. Start runner normally
    3. Create a context with 1-nanosecond timeout: `ctx, cancel := context.WithTimeout(context.Background(), time.Nanosecond)`
    4. `time.Sleep(time.Millisecond)` to ensure deadline passed
    5. Call tool directly via `session.CallTool(ctx, ...)` (bypass harness.CallTool which has its own timeout)
    6. Assert error is context.DeadlineExceeded or contains "deadline" / "timeout"
    7. NOTE: This tests the context-layer timeout. The exact error format may differ from LS-layer timeout. Capture and assert the error is clean and non-empty.

    **TestDeferred_ErrorCategories_CircuitOpen:**
    1. This is harder to trigger end-to-end. Two approaches:
       - **Preferred (unit-level):** Test `CircuitBreaker` directly — call `RecordFailure()` enough times to exhaust the restart budget, then assert `CanAttempt()` returns false. This is already partially covered by existing pool tests but needs the error message format validated.
       - **Integration approach:** If the circuit breaker error surfaces through the MCP tool layer, trigger by using a tool with a crashy LS. Since we cannot easily make gopls crash, focus on the unit-level validation.
    2. Import `internal/kernel/lspool` and test `CircuitBreaker` directly:
       - Create breaker with small budget (e.g., 3 restarts)
       - Call `RecordFailure()` 4 times
       - Assert `CanAttempt()` returns false
       - Assert `Failures()` returns 4
       - Log the circuit open state for golden reference
    3. If the MCP layer wraps circuit open into a tool error, capture that format too.

    NOTE: For timeout and circuit_open, golden files are harder because the exact error text depends on the layer. Focus on asserting the error structure is clean (IsError=true, non-empty message, no success phrases) rather than strict golden matching for these two. The unsupported category gets a proper golden file since it's deterministic.
