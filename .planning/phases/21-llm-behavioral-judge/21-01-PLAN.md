**Step 1: Create `test/oracle/llm/selection_test.go`** with build tag `//go:build llm`:

Implement `TestSelection(t *testing.T)` per D-01/D-02:
1. Call `SkipWithoutAPIKey(t)`.
2. Start a runner with `harness.StartRunner(t, harness.RunnerOptions{SkipLS: true})`.
3. Get tools via `runner.Session.ListTools(ctx, &mcp.ListToolsParams{})`.
4. Create client via `NewClient()`, get model via `SubjectModel()`.
5. Build tool list string via `FormatToolList(tools)`.
6. Loop over each tool sequentially (no `t.Parallel()`). For each tool:
   a. `InterCallDelay()` (skip on first iteration per D-19).
   b. `t.Run(tool.Name, func(t *testing.T) { ... })`.
   c. Build system prompt: `SelectionSystemPrompt(toolListStr)`.
   d. Build user prompt: `SelectionUserPrompt(ToolTaskDescription(tool.Name))`.
   e. Call `AskSingleTurn(ctx, client, model, system, user)`.
   f. Assert response contains `tool.Name` using `strings.Contains(strings.ToLower(response), strings.ToLower(tool.Name))`. Use `require.True` with message showing expected tool, got response.
   g. Write transcript: `WriteTranscript(t, &Transcript{ScenarioID: "select-"+tool.Name, Category: "selection", Model: model, System: system, UserPrompt: user, Response: response, StopReason: stopReason})`.
