  <action>
Add `serr "github.com/postfix/serena/internal/errors"` import. The edit/tools.go has a different pattern than symbols -- it does NOT use a shared `acquireLease`. Instead, each handler calls `k.GetRuntime(wsKey)` directly, then `rt.AcquireSession()`.

For each of the 6 handlers, update:
```go
// workspace not activated:
return errorResult(fmt.Sprintf("workspace not activated: %v", err)), nil, nil
// becomes:
return errorResult(serr.Wrap(serr.NoWorkspace, "workspace not activated", err).Error()), nil, nil

// acquire session (read or dirty):
return errorResult(fmt.Sprintf("acquire read session: %v", err)), nil, nil
// becomes:
return errorResult(serr.Wrap(serr.Internal, "acquire read session", err).Error()), nil, nil

return errorResult(fmt.Sprintf("acquire session: %v", err)), nil, nil
// becomes:
return errorResult(serr.Wrap(serr.Internal, "acquire session", err).Error()), nil, nil

// operation result errors (plan edit, replace body, insert before/after, safe delete, rename, verify):
// These now return *serr.Error from Task 1, so:
return errorResult(fmt.Sprintf("plan edit: %v", err)), nil, nil
// becomes:
return errorResult(err.Error()), nil, nil

return errorResult(fmt.Sprintf("replace body: %v", err)), nil, nil
// becomes:
return errorResult(err.Error()), nil, nil
```

Similarly for insert_before, insert_after, rename, safe_delete, verify_edit handlers. The verify_edit handler's error (`fmt.Sprintf("verify: %v", err)`) also becomes `err.Error()` since VerifyEdit will return typed errors.

Remove `"fmt"` from imports ONLY if no other fmt usage remains. tools.go uses fmt.Sprintf in `appendVerifyInfo` and `formatLocations`-like helpers, so "fmt" likely stays.
