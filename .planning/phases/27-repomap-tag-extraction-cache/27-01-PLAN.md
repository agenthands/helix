Create 4 `.scm` query files in `internal/repomap/queries/` using upstream tree-sitter `tags.scm` convention. Capture names: `@name` for identifier, `@definition.*` for defs, `@reference.*` for refs.

**go_tags.scm:**
```scheme
; Definitions
(function_declaration
  name: (identifier) @name) @definition.function

(method_declaration
  name: (field_identifier) @name) @definition.method

(type_spec
  name: (type_identifier) @name) @definition.type

; References
(call_expression
  function: [
    (identifier) @name
    (selector_expression field: (field_identifier) @name)
  ]) @reference.call

(type_identifier) @name @reference.type
```

**python_tags.scm:**
```scheme
; Definitions
(function_definition
  name: (identifier) @name) @definition.function

(class_definition
  name: (identifier) @name) @definition.class

; References
(call
  function: [
    (identifier) @name
    (attribute attribute: (identifier) @name)
  ]) @reference.call
```

**typescript_tags.scm:**
```scheme
; Definitions
(function_declaration
  name: (identifier) @name) @definition.function

(class_declaration
  name: (type_identifier) @name) @definition.class

(method_definition
  name: (property_identifier) @name) @definition.method

(interface_declaration
  name: (type_identifier) @name) @definition.type

; References
(call_expression
  function: [
    (identifier) @name
    (member_expression property: (property_identifier) @name)
  ]) @reference.call
```

**rust_tags.scm:**
```scheme
; Definitions
(function_item
  name: (identifier) @name) @definition.function

(struct_item
  name: (type_identifier) @name) @definition.type

(enum_item
  name: (type_identifier) @name) @definition.type

(trait_item
  name: (type_identifier) @name) @definition.type

(impl_item
  type: (type_identifier) @name) @definition.type

; References
(call_expression
  function: [
    (identifier) @name
    (scoped_identifier name: (identifier) @name)
    (field_expression field: (field_identifier) @name)
  ]) @reference.call
```

Create `extractor.go` with `TagExtractor`:
```go
package repomap

import (
    _ "embed"
    "strings"

    tree_sitter "github.com/tree-sitter/go-tree-sitter"
    serr "github.com/postfix/serena/internal/errors"
    "github.com/postfix/serena/internal/treesitter"
)

//go:embed queries/go_tags.scm
var goTagsQuery string
//go:embed queries/python_tags.scm
var pythonTagsQuery string
//go:embed queries/typescript_tags.scm
var typescriptTagsQuery string
//go:embed queries/rust_tags.scm
var rustTagsQuery string
```

`TagExtractor` struct holds:
- `registry *treesitter.GrammarRegistry`
- `queries map[string]*tree_sitter.Query` — compiled queries, keyed by language. Compile once in constructor.

Constructor `NewTagExtractor(registry *treesitter.GrammarRegistry) (*TagExtractor, error)`:
- Build query map: `{"go": goTagsQuery, "python": pythonTagsQuery, "typescript": typescriptTagsQuery, "tsx": typescriptTagsQuery, "rust": rustTagsQuery}`
- For each entry, get language from registry via `registry.GetLanguage(lang)`, compile query with `tree_sitter.NewQuery(lang, queryStr)`. If `qerr != nil`, return error with `qerr.Message` (Pitfall 1: QueryError is not Go error).
- Store compiled `*tree_sitter.Query` in map. These are reused across files.

Method `Extract(source []byte, filePath string, lang string) ([]Tag, error)`:
1. Look up compiled query for lang. If not found, return `serr.New(serr.Unsupported, "no tag query for language").WithDetail(lang)`.
2. Get language from registry: `registry.GetLanguage(lang)`.
3. Create parser, set language, parse source (follow BodyExtractor lifecycle: `defer parser.Close()`, `defer tree.Close()`, check `tree == nil`).
4. Create `tree_sitter.NewQueryCursor()`, `defer cursor.Close()`.
5. Get `captureNames := query.CaptureNames()` (from the compiled query in the map).
6. Iterate `cursor.Matches(query, tree.RootNode(), source)` with `for m := matches.Next(); m != nil; m = matches.Next()`.
7. For each match, iterate `m.Captures`:
   - If `captureNames[capture.Index] == "name"` -> extract name text via `capture.Node.Utf8Text(source)`, record nameNode
   - If `strings.HasPrefix(captureNames[capture.Index], "definition.")` -> set kind=TagDef, record defNode, record captureName for qualified name logic
   - If `strings.HasPrefix(captureNames[capture.Index], "reference.")` -> set kind=TagRef, record defNode
8. Build Tag with qualified name per D-03: for `"definition.method"` captures, walk nameNode's parent chain to find the method_declaration, extract receiver type for Go (`parent.ChildByFieldName("receiver")`), class name for Python (`parent to class_definition, extract name field`), class name for TypeScript (`parent to class_declaration, extract name field`), impl type for Rust (`parent to impl_item, extract type field`). Format as `TypeName.methodName`.
9. Tag fields: `Name` (possibly qualified), `Kind`, `File: filePath`, `Line: int(nameNode.StartPosition().Row)`, `Column: int(nameNode.StartPosition().Column)`, `StartByte: defNode.StartByte()`, `EndByte: defNode.EndByte()`.

Add `Close()` method that closes all compiled queries.
