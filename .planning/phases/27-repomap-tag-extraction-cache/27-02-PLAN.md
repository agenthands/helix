
Method `Extract(ctx context.Context, requester SymbolRequester, filePath string, uri string) ([]Tag, error)`:
1. Build params: `gen.DocumentSymbolParams{TextDocument: gen.TextDocumentIdentifier{URI: uri}}`
2. Call `requester.Request(ctx, "textDocument/documentSymbol", params, &result)` where result is `[]gen.DocumentSymbol`
3. If error, return `serr.Wrap(serr.Internal, "fallback documentSymbol", err)`
4. Flatten the hierarchical `DocumentSymbol` tree recursively into a flat `[]Tag` slice
5. Per D-07: ALL symbols mapped as `TagDef` only. No refs from LSP fallback.
6. For each DocumentSymbol:
   - `Name`: symbol name. For children, qualify with parent name (e.g. `ClassName.methodName`) per D-03
   - `Kind`: `TagDef` (always)
   - `File`: `filePath` parameter
   - `Line`: `int(sym.SelectionRange.Start.Line)`
   - `Column`: `int(sym.SelectionRange.Start.Character)`
   - `StartByte`: 0 (LSP does not provide byte offsets — set to 0, elision will use line-based fallback)
   - `EndByte`: 0
7. Recurse into `sym.Children` to flatten nested symbols, passing parent name for qualification.

Note: `WorkerLease` from `lspool` satisfies the `SymbolRequester` interface since it has the matching `Request` method signature. The interface allows unit testing without a real LSP server.
