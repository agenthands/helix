func NewIndex(dbPath string) (*Index, error) {
    if err := os.MkdirAll(filepath.Dir(dbPath), 0o755); err != nil {
        return nil, fmt.Errorf("creating index dir: %w", err)
    }
    db, err := sql.Open("sqlite", dbPath)
    if err != nil {
        return nil, fmt.Errorf("opening index db: %w", err)
    }
    for _, pragma := range []string{
        "PRAGMA journal_mode=WAL",
        "PRAGMA busy_timeout=5000",
    } {
        if _, err := db.Exec(pragma); err != nil {
            db.Close()
            return nil, fmt.Errorf("setting pragma %q: %w", pragma, err)
        }
    }
    if _, err := db.Exec(createSchema); err != nil {
        db.Close()
        return nil, fmt.Errorf("creating schema: %w", err)
    }
    return &Index{db: db}, nil
}

Constructor `NewTagCache(dbPath string) (*TagCache, error)`:
Follow the exact pattern from `internal/memory/index.go`:
1. `os.MkdirAll(filepath.Dir(dbPath), 0o755)` — create parent directory
2. `sql.Open("sqlite", dbPath)` — open database
3. Set pragmas: `PRAGMA journal_mode=WAL` and `PRAGMA busy_timeout=5000`
4. Execute `createSchema`
5. On any error, `db.Close()` before returning
6. Return `&TagCache{db: db}`

Method `GetOrExtract(filePath string, extractFn func() ([]Tag, error)) ([]Tag, error)`:
1. `os.Stat(filePath)` to get current mtime. If error (file deleted), return error.
2. `mtime := info.ModTime().UnixNano()` — store as int64 per Pitfall 4.
3. Lock mutex.
4. Query: `SELECT mtime_ns FROM file_tags WHERE file_path = ? LIMIT 1` to get cached mtime.
5. If cached mtime matches current mtime, load all tags: `SELECT name, kind, line, col, start_byte, end_byte FROM file_tags WHERE file_path = ? ORDER BY line, col`.
6. Map rows to `[]Tag` with `File: filePath`.
7. If cache miss or mtime mismatch, unlock, call `extractFn()`, re-lock, delete old: `DELETE FROM file_tags WHERE file_path = ?`, batch insert new tags.
8. For batch insert, use a transaction: `tx, _ := db.Begin()`, prepare statement `INSERT INTO file_tags (file_path, mtime_ns, name, kind, line, col, start_byte, end_byte) VALUES (?, ?, ?, ?, ?, ?, ?, ?)`, execute for each tag, `tx.Commit()`.
9. Return the tags.

Method `InvalidateFile(filePath string) error`:
- Lock, `DELETE FROM file_tags WHERE file_path = ?`, unlock.

Method `Clear() error`:
- Lock, `DELETE FROM file_tags`, unlock.

Method `Close() error`:
- `return c.db.Close()`

All SQL uses parameterized queries only (no string interpolation) per security threat T-27-05.
