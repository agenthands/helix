`ElisionRenderer` struct:
```go
type ElisionRenderer struct {
    registry *treesitter.GrammarRegistry
}

func NewElisionRenderer(registry *treesitter.GrammarRegistry) *ElisionRenderer {
    return &ElisionRenderer{registry: registry}
}
```

Main method `RenderFile(source []byte, lang string, tags []Tag) string`:
This renders a compact view of a file showing only the def tags with bodies elided.

Algorithm:
1. Filter tags to def-only (refs are not rendered in elided output).
2. Sort tags by StartByte ascending.
3. If the language is supported by the grammar registry, parse the source with tree-sitter to find body nodes for each def tag. Otherwise, fall back to line-based rendering.
4. For tree-sitter path:
   a. Parse source with the language grammar.
   b. For each def tag, find the AST node at `tag.StartByte` using `tree.RootNode().DescendantForByteRange(tag.StartByte, tag.EndByte)`.
   c. Walk up to find a declaration-type parent node (function_declaration, method_declaration, function_definition, class_definition, function_item, struct_item, etc.).
   d. Look for a "body" or "block" field child on the declaration node via `node.ChildByFieldName("body")` or `node.ChildByFieldName("block")`.
   e. If body found: extract the source from `tag.StartByte` to `body.StartByte()`, append ` { ... }` (for brace languages) or `: ...` (for Python).
   f. For struct/class types (D-14): find the body, iterate its named children. Include field declarations (short_var_declaration, field_declaration, etc.) but elide method bodies within the struct. For Go structs, the body IS the field list, so show it fully. For classes, show fields, elide method bodies.
   g. If no body found (e.g., type alias, interface): show the full declaration text from `tag.StartByte` to `tag.EndByte`.

5. For line-based fallback (no tree-sitter grammar):
   a. For each def tag, extract the line at `tag.Line` from source. Show that line only.

6. Build output as a string with one elided declaration per block, separated by blank lines. Include line numbers as comments: `// L{line}:` prefix for context.

Format per D-13: `func (s *Server) Run(ctx context.Context) error { ... }`

Handle edge cases:
- Tags with StartByte == 0 and EndByte == 0 (LSP fallback tags): use line-based rendering.
- Empty source: return empty string.
- No def tags: return empty string.

Also provide a simpler helper `ElideSingle(source []byte, tag Tag, bodyStart, bodyEnd uint) string` that takes pre-computed body range and returns the elided text for a single tag. This is useful for Phase 28 which may render individual tags.
