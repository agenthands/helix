**Create pagerank.go:**

```go
package repomap

import (
    "math"
    "sort"
)
```

Method on FileGraph:
- `func (g *FileGraph) PageRank(damping float64, epsilon float64, maxIter int, personalization map[string]float64) map[string]float64`
  - Parameters: damping=0.85 typical, epsilon=1e-6, maxIter=100
  - If `g.Files` is empty, return nil
  - Build file list from g.Files
  - Initialize teleport vector:
    - If personalization is non-nil and non-empty: normalize weights, fill remaining nodes with small baseline `(1.0/n)*0.01`, re-normalize so sum=1.0
    - If personalization is nil/empty: uniform `1.0/n`
  - Initialize rank = copy of teleport
  - Power iteration loop (up to maxIter):
    - Compute dangling rank: sum rank[f] for all f with no outgoing edges in g.Edges
    - New rank: `(1-damping) * teleport[f] + damping * danglingRank/n` for all f (dangling redistribution)
    - For each src with outgoing edges: compute totalWeight, distribute `damping * rank[src] * (weight/totalWeight)` to each dst
    - Check convergence: sum of abs differences < epsilon
    - If converged, break
  - Return rank map

Convenience method:
- `func (g *FileGraph) RankFiles(damping float64, personalization map[string]float64) []RankedFile`
  - Calls PageRank with damping, epsilon=1e-6, maxIter=100, personalization
  - Converts map to []RankedFile sorted descending by Score
  - Returns the sorted slice
