Types:
- `TreeRenderer struct` with fields:
  - `elider *ElisionRenderer` -- for rendering elided symbol views
  - `cache  *TagCache` -- for loading tags per file
  - `rootDir string` -- workspace root for relative path computation

Constructor:
- `func NewTreeRenderer(elider *ElisionRenderer, cache *TagCache, rootDir string) *TreeRenderer`

Methods:
- `func EstimateTokens(s string) int` -- package-level function, returns `len(s) / 4` per D-12

- `func (r *TreeRenderer) RenderBudgeted(ranked []RankedFile, budget int) string` -- per D-13:
  1. If `len(ranked) == 0`, return `""`
  2. Always include at least 1 file
  3. Binary search on file count (lower=1, upper=len(ranked)):
     - `mid = (lower + upper) / 2`
     - `output = r.renderTree(ranked[:mid])`
     - `tokens = EstimateTokens(output)`
     - Track best result: if `tokens <= budget && tokens > bestTokens`, update bestOutput/bestTokens
     - Also accept if percentage error `math.Abs(float64(tokens-budget))/float64(budget) < 0.15` (15% tolerance per aider)
     - If tokens < budget: lower = mid + 1; else: upper = mid - 1
  4. If no result found within budget (all files exceed budget), render just the first file
  5. Return bestOutput

- `func (r *TreeRenderer) renderTree(ranked []RankedFile) string` -- renders files as a tree:
  1. For each RankedFile, compute relative path from rootDir
  2. Build a tree structure: group files by directory prefix
  3. Render as indented tree with directory names as branches:
     ```
     internal/
       repomap/
         cache.go
           // L25:
           func NewTagCache(dbPath string) (*TagCache, error) { ... }
         graph.go
           // L15:
           func BuildGraph(cache *TagCache) (*FileGraph, error) { ... }
     ```
  4. For each file: read source from disk via `os.ReadFile`, load tags from cache via `cache.GetOrExtract` (if available) or just `cache.AllFiles` data, render elided view via `elider.RenderFile(source, lang, tags)`
  5. Indent elided output by 4 additional spaces under the filename
  6. Language detection: use file extension mapping (`.go`->"go", `.py`->"python", `.ts`->"typescript", `.rs`->"rust", `.tsx`->"tsx", `.js`->"javascript", `.java`->"java", `.rb`->"ruby", `.php`->"php", `.c`->"c", `.cpp`->"cpp")

- `func (r *TreeRenderer) renderFileEntry(relPath string, ranked RankedFile) string` -- helper for single file rendering with elided symbols

- `func langFromExt(path string) string` -- maps file extension to language string

Tree format details:
- Use 2-space indentation per directory level
- Compress common path prefixes (if all files share `internal/repomap/`, show it as one level)
- File names shown as leaf nodes
- Elided symbol output indented 4 spaces under the file name, each prefixed with `// L{line}:\n{elided_text}`
