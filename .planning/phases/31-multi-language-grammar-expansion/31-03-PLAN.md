**PART A: Create 5 tag query files**

Apply same adaptation rules: `@name.definition.X` -> `@name`, strip predicates, strip `@doc`.

**`internal/repomap/queries/lua_tags.scm`** -- Adapted from tree-sitter-language-pack lua-tags.scm:
```scheme
(function_declaration
  name: [(identifier) @name
         (dot_index_expression field: (identifier) @name)]) @definition.function

(function_declaration
  name: (method_index_expression
    method: (identifier) @name)) @definition.method

(assignment_statement
  (variable_list
    name: [(identifier) @name
           (dot_index_expression field: (identifier) @name)])
  (expression_list
    value: (function_definition))) @definition.function

(function_call
  name: [(identifier) @name
         (dot_index_expression field: (identifier) @name)
         (method_index_expression method: (identifier) @name)]) @reference.call
```
Note: Strip `table_constructor` field function pattern -- may cause issues with tree-sitter query compilation.

**`internal/repomap/queries/zig_tags.scm`** -- PRIORITY: ERROR TOLERANCE REQUIRED.

The aider zig query uses `(FnProto)` which is unusual (PascalCase node names). The Zig tree-sitter grammar from `tree-sitter-grammars/tree-sitter-zig` uses PascalCase node types throughout (e.g., `FnProto`, `VarDecl`, `ContainerDecl`).

Try this query first:
```scheme
(FnProto
  (IDENTIFIER) @name) @definition.function
```

If that fails to compile (PascalCase field names may differ), try these fallback variants IN ORDER:
```scheme
; Fallback 1: field-less capture
(FnProto (IDENTIFIER) @name) @definition.function

; Fallback 2: lowercase node types (some grammar versions)
(function_declaration
  name: (identifier) @name) @definition.function

; Fallback 3: bare minimum
(IDENTIFIER) @name
```

CRITICAL: If the Zig query fails to compile via `tree_sitter.NewQuery()`, the entire `NewTagExtractor` will fail and break ALL languages. Before wiring the Zig query into `querySources`, test compilation in isolation. If it fails, use an empty/minimal query that compiles, and document the limitation. Alternatively, if this is the last language being wired, consider adding per-language error tolerance to `NewTagExtractor` -- log a warning for failed query compilations and skip that language rather than failing the entire extractor. This is the recommended approach:

```go
// In NewTagExtractor, replace the fail-fast query compilation loop with:
for lang, queryStr := range querySources {
    q, err := tree_sitter.NewQuery(grammar, queryStr)
    if err != nil {
        log.Printf("WARNING: tag query for %s failed to compile: %v (skipping)", lang, err)
        continue  // skip this language, don't fail all extraction
    }
    te.queries[lang] = q
}
```

**`internal/repomap/queries/hcl_tags.scm`** -- Adapted from aider hcl-tags.scm:
```scheme
(block
  (identifier) @name) @definition.module
```
Note: The aider query uses `#eq?` predicates to filter block types (resource, module, variable, etc.). Start with this minimal version that captures all block identifiers. If `#eq?` IS supported by go-tree-sitter, enhance with filtered variants later.

**`internal/repomap/queries/swift_tags.scm`** -- Adapted from tree-sitter-language-pack swift-tags.scm:
```scheme
(class_declaration
  name: (type_identifier) @name) @definition.class

(protocol_declaration
  name: (type_identifier) @name) @definition.interface

(function_declaration
  name: (simple_identifier) @name) @definition.function
```
Note: Strip the complex nested method extraction patterns (class_body -> function_declaration etc.) as they create `@definition.method` on the outer class node which is semantically wrong for Serena's extractor. Keep only top-level patterns.

**`internal/repomap/queries/r_tags.scm`** -- Adapted from tree-sitter-language-pack r-tags.scm:
```scheme
(binary_operator
  lhs: (identifier) @name
  operator: "<-"
  rhs: (function_definition)) @definition.function

(binary_operator
  lhs: (identifier) @name
  operator: "="
  rhs: (function_definition)) @definition.function

(call
  function: (identifier) @name) @reference.call
```
