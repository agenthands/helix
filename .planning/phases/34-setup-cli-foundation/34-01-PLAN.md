**Implement all 6 registrar Register/Unregister methods in `setup_clients.go`:**

Add a shared helper `func mergeJSONConfig(path, key, serverName string, serverConfig map[string]any) error`:
- Read existing file via `os.ReadFile` (if not found, start with empty `map[string]any{}`)
- Unmarshal into `map[string]any`
- Get or create nested map at `key`
- Set `serverName` entry to `serverConfig`
- Marshal with `json.MarshalIndent("", "  ")` and write via `os.WriteFile(path, data, 0644)`
- Create parent directories with `os.MkdirAll` before writing

Add a shared helper `func removeFromJSONConfig(path, key, serverName string) error`:
- Read file, unmarshal, delete `serverName` from nested map at `key`, write back
- If file doesn't exist, return nil (nothing to remove)

Add a helper `func serverConfigJSON(binaryPath string) map[string]any`:
- Returns `map[string]any{"command": binaryPath, "args": []string{"--mode=stdio"}}`

Add a helper for platform-specific config dir: `func userConfigDir() string` wrapping `os.UserConfigDir()`.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI args -> config paths | User-supplied client name selects filesystem paths for config writes |
| Serena -> client CLI | Subprocess calls to `claude` and `gemini` CLIs |
| Config file merge | Read-modify-write cycle on user's existing config files |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-34-01 | Tampering | setup_clients.go mergeJSONConfig | mitigate | Use `encoding/json` Marshal/Unmarshal (never string concatenation). Validate JSON structure before writing. Create parent dirs with 0755. Write files with 0644. |
| T-34-02 | Spoofing | setup_clients.go exec.Command | accept | PATH hijacking of `claude`/`gemini` CLIs is user-environment risk. exec.LookPath is standard practice; user's PATH is trusted. |
| T-34-03 | Information Disclosure | setup_clients.go config paths | mitigate | Config files written with 0644 (owner read-write, group/other read-only). No secrets stored in MCP config -- only binary path and args. |
| T-34-04 | Denial of Service | setup.go resolveBinaryPath | accept | filepath.EvalSymlinks could follow deep symlink chains. OS-level symlink depth limits apply. Low risk for CLI tool. |
| T-34-05 | Tampering | setup_clients.go removeFromJSONConfig | mitigate | Read-modify-write preserves all other keys. Only deletes the `"serena"` entry under the MCP servers key. |
| T-34-06 | Elevation | setup.go client name validation | mitigate | Client name validated against hardcoded allowlist of 6 known clients in clientRegistry(). No path traversal possible since names map to fixed config paths. |
</threat_model>
