  <action>
**`setup_detect.go`** -- Language detection and LS pre-installation.

Create `func detectLanguages(dir string, reg *langregistry.Registry, printer *SetupPrinter) ([]langregistry.LSEntry, error)`:
- Walk the project directory using `filepath.WalkDir`
- Skip hidden directories (names starting with `.`), `node_modules`, `vendor`, `__pycache__`, `.git`
- For each file, get extension via `filepath.Ext(d.Name())`
- Look up via `reg.ByExtension(ext)` -- returns `[]LSEntry`
- Deduplicate by `LSEntry.Language` using a `map[string]bool` seen set
- Return unique entries sorted alphabetically by Language
- Print detected languages via `printer.Info("Detected languages: %s", joined)` where joined is comma-separated language names

Create `func preInstallLanguageServers(ctx context.Context, entries []langregistry.LSEntry, installer *langregistry.Installer, printer *SetupPrinter, dryRun bool) []langregistry.LSEntry`:
- For each entry, call `installer.Resolve(ctx, entry)`
- If Resolve succeeds: `printer.Success("%s (%s) ready", entry.Language, command)` and add to successList
- If Resolve fails: `printer.Failure("%s: %v", entry.Language, err)` and add to failedList
- If dryRun: `printer.DryRunAction("would install %s (%s)", entry.Language, entry.Command)` for each entry, skip actual resolution
- Return the list of successfully resolved entries (for health check)

**`setup_health.go`** -- Post-registration health check.

Create `func runHealthCheck(ctx context.Context, entries []langregistry.LSEntry, projectDir string, printer *SetupPrinter, dryRun bool) error`:
- If dryRun: `printer.DryRunAction("would verify %d language server(s)", len(entries))` and return nil
- If no entries: `printer.Info("No language servers to verify")` and return nil
- For each successfully installed LS entry:
  - Use `exec.CommandContext` with a 10-second timeout context to run the LS command with a version/probe flag if known, or simply check `exec.LookPath(entry.Command)` confirms the binary exists
  - Print `printer.Success("%s (%s) responding", entry.Language, entry.Command)` on success
  - Print `printer.Failure("%s (%s) not responding: %v", entry.Language, entry.Command, err)` on failure
- Note: Full daemon-based health check (starting daemon, sending LSP initialize) is complex and deferred to Phase 35 (HLTH-01 through HLTH-04). For Phase 34, health check validates that LS binaries are available and callable, which is the minimum useful verification per D-10.
- Return nil (health check is informational, not blocking)

**Update `setup.go`** -- Wire detect, pre-install, and health into `runSetup`:

After the client registration step (and before returning), add:
1. Create registry: `reg, err := langregistry.NewRegistry()` -- if error, print warning and skip (non-fatal)
2. Detect languages: `entries, _ := detectLanguages(cfg.ProjectDir, reg, printer)`
3. If `--skip-install` flag is false (per D-09): create installer `inst := langregistry.NewInstaller(langregistry.InstallerConfig{AutoInstall: true}, logger)` and call `installed := preInstallLanguageServers(cmd.Context(), entries, inst, printer, cfg.DryRun)`
4. If entries found: call `runHealthCheck(cmd.Context(), installed, cfg.ProjectDir, printer, cfg.DryRun)`

Add a logger construction in runSetup: `logger := slog.New(slog.NewTextHandler(os.Stderr, &slog.HandlerOptions{Level: slog.LevelWarn}))` -- setup uses warn-level logging to avoid noise, user-facing output goes through SetupPrinter.

Import `langregistry` in setup.go: `"github.com/postfix/serena/internal/langregistry"`

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| File system -> langregistry | Walking arbitrary directories for language detection |
| langregistry -> network | LS installer may download packages from npm/pip/cargo registries |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-34-07 | Denial of Service | setup_detect.go filepath.WalkDir | mitigate | Skip hidden dirs, node_modules, vendor, __pycache__ to avoid walking massive dependency trees. No symlink following (WalkDir does not follow symlinks by default). |
| T-34-08 | Tampering | setup_detect.go LS installation | accept | LS installation uses existing three-tier installer which downloads from official package registries (npm, pip, cargo). Supply chain risk is inherent to package managers and managed by the installer package, not setup. |
| T-34-09 | Information Disclosure | setup_health.go exec output | mitigate | Health check output goes to stderr via SetupPrinter, not stdout. No secrets in LS probe commands. |
</threat_model>
