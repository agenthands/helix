**Create `internal/cli/setup_hooks.go`** with these functions:

1. `hookSettingsPath(projectDir string, global bool) string` -- Returns `.claude/settings.json` path. If `global`, use `~/.claude/settings.json`. If project-scoped, use `filepath.Join(projectDir, ".claude", "settings.json")`.

2. `serenaHookConfig(binaryPath string) map[string][]any` -- Returns the hook config map with three event types. The exact JSON structure per Claude Code docs (RESEARCH Pattern 1):
   - Key `"SessionStart"`: array with one matcher object `{"matcher": "startup", "hooks": [{"type": "command", "command": "<binaryPath> activate --workspace \"$CLAUDE_PROJECT_DIR\"", "timeout": 30, "statusMessage": "Activating Serena workspace..."}]}`
   - Key `"PreToolUse"`: array with one matcher object `{"matcher": "Grep|Read|Bash", "hooks": [{"type": "command", "command": "<binaryPath> nudge", "timeout": 5}]}`
   - Key `"Stop"`: array with one matcher object `{"hooks": [{"type": "command", "command": "<binaryPath> deactivate --workspace \"$CLAUDE_PROJECT_DIR\"", "timeout": 10}]}`
   - Each hook command object MUST have a `"serena_managed": true` field to identify Serena-owned entries for idempotent add/remove.

3. `mergeHooksIntoSettings(path string, binaryPath string) error` -- Reads existing settings.json (or creates empty), gets `serenaHookConfig(binaryPath)`, for each event type: gets existing array from `hooks[eventType]`, filters out entries where any hook command object has `"serena_managed": true`, appends new Serena entries, writes back with `json.MarshalIndent`. Uses `os.MkdirAll` for directory creation. Uses `os.WriteFile` with 0644.

4. `removeHooksFromSettings(path string) error` -- Reads settings.json, for each event type in `hooks`, filters out matcher objects where any hook command has `"serena_managed": true`. If no matchers remain for an event type, remove the event type key. If hooks object is empty, remove it. Write back. If file doesn't exist, return nil.

**Create `internal/cli/nudge.go`** with:

1. `hookInput` struct: `SessionID string`, `TranscriptPath string`, `CWD string`, `HookEventName string`, `ToolName string`, `ToolInput map[string]any` -- all with json tags matching Claude Code's stdin format (see RESEARCH Pattern 2).

2. `sessionStats` struct: `SessionID string`, `GrepReadCount int`, `SerenaToolCount int`, `LastUpdated string` -- with json tags.

3. `newNudgeCommand() *cobra.Command` -- Use "nudge", Short "Nudge agent toward symbolic tools", with `--tool` string flag as fallback. `SilenceUsage: true, SilenceErrors: true`.

4. `runNudge(cmd *cobra.Command, _ []string) error`:
   - Read stdin JSON into `hookInput` via `json.NewDecoder(os.Stdin).Decode`. If stdin fails (manual invocation), return nil.
   - Get `toolName` from `input.ToolName`. If empty, fall back to `--tool` flag.
   - Get `wsDir` from `input.CWD`. If empty, use `os.Getwd()`.
   - `statsPath` = `filepath.Join(wsDir, ".serena", "session-stats.json")`
   - Load stats via `loadSessionStats(statsPath, input.SessionID)`.
   - If `isSerenaSymbolicTool(toolName)` returns true: increment `SerenaToolCount`, reset `GrepReadCount` to 0, save, return nil.
   - If `isGrepReadTool(toolName, input.ToolInput)` returns true: increment `GrepReadCount`, save. If `GrepReadCount >= 5 && SerenaToolCount == 0`, print nudge to stdout: `"Tip: Serena provides find_symbol and get_symbols_overview for code navigation. These give you precise symbol locations, references, and type hierarchies instead of text pattern matching with grep."`. Return nil.
   - Otherwise save and return nil. Always exit 0.

5. `loadSessionStats(path string, sessionID string) sessionStats`:
   - Read file, unmarshal. If file missing or different sessionID, return fresh stats with the new sessionID.

6. `saveSessionStats(path string, stats sessionStats) error`:
   - Set `LastUpdated` to `time.Now().UTC().Format(time.RFC3339)`.
   - `os.MkdirAll` for parent dir. Write to temp file first (`path + ".tmp"`), then `os.Rename` for atomic write (per RESEARCH Pitfall 3).

7. `isSerenaSymbolicTool(name string) bool` -- Returns true if name is one of: `"mcp__serena__find_symbol"`, `"mcp__serena__get_symbol_details"`, `"mcp__serena__get_symbols_overview"`, `"mcp__serena__find_references"`, `"mcp__serena__get_hover_info"`, `"mcp__serena__find_implementations"`, `"mcp__serena__get_call_hierarchy"`, `"mcp__serena__get_type_hierarchy"`, `"mcp__serena__get_blast_radius"`. Also match without the `mcp__serena__` prefix for flexibility.

8. `isGrepReadTool(name string, input map[string]any) bool`:
   - Return true if name is `"Grep"`, `"Read"`, or `"Bash"` where `input["command"]` string contains "grep" or "find" or "rg" or "ag".

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Claude Code stdin -> nudge | Untrusted JSON piped from Claude Code hook system to `serena nudge` |
| settings.json read/write | User-controlled JSON file that Serena merges into |
| --workspace flag | User-supplied filesystem path |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-36-01 | Tampering | nudge stdin JSON | mitigate | Use json.Decoder (safe parser), never exec values from stdin, only read ToolName/ToolInput/CWD as data |
| T-36-02 | Tampering | settings.json injection | mitigate | Use encoding/json Marshal (never string concat) for all JSON writes, same as existing mergeJSONConfig pattern |
| T-36-03 | Tampering | --workspace path traversal | mitigate | Resolve to absolute path via filepath.Abs, verify it's a directory with os.Stat |
| T-36-04 | Denial of Service | session-stats.json corruption | accept | Counter corruption is non-fatal; loadSessionStats returns fresh stats on parse error. Atomic write via rename reduces window. |
| T-36-05 | Information Disclosure | nudge stdout leaks | accept | Nudge output is a static suggestion message, contains no user data or secrets |
</threat_model>
