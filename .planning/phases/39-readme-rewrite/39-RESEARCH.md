**Regeneration command:** `go run ./cmd/docgen`

## Common Pitfalls

### Pitfall 1: Stale Tool Count After docgen Fix
**What goes wrong:** docgen is updated to import new skills but the tool table in README is not regenerated, leaving the count stale.
**Why it happens:** The imports and the regeneration are separate steps.
**How to avoid:** Always run `go run ./cmd/docgen` after changing imports in `cmd/docgen/main.go`, then verify with `go run ./cmd/docgen --check`.
**Warning signs:** Tool count in prose doesn't match rows in auto-generated table.

### Pitfall 2: Broken Auto-Gen Markers
**What goes wrong:** Accidentally deleting or modifying the `<!-- BEGIN TOOLS -->` / `<!-- END TOOLS -->` comment markers breaks docgen.
**Why it happens:** Restructuring sections moves content around; markers can be accidentally deleted.
**How to avoid:** Keep markers on their own lines, never modify the exact comment text.
**Warning signs:** `go run ./cmd/docgen` fails with "marker not found" error.

### Pitfall 3: Acknowledgements Section Implying Python Dependency
**What goes wrong:** Current wording "A significant part of Serena, especially support for various languages, was contributed by the open source community" is fine, but any edit that references the Python codebase as foundational violates LEGC-01.
**Why it happens:** Natural tendency to credit origins prominently.
**How to avoid:** Acknowledgements credit the community. Python origin is ONLY mentioned in the one-liner footer per D-04.
**Warning signs:** Words like "port", "rewrite", "based on", "derived from" anywhere in the README.

### Pitfall 4: Quick Start serena setup Not Matching Actual CLI
**What goes wrong:** README documents `serena setup` flags or behavior that doesn't match the actual CLI implementation.
**Why it happens:** Documentation written from memory rather than checking actual CLI.
**How to avoid:** Cross-reference `internal/cli/setup.go` for valid clients: `claude-code`, `vscode`, `jetbrains`, `claude-desktop`, `gemini-cli`, `generic`. Flags: `--global`, `--uninstall`, `--skip-install`, `--dry-run`, `--output`, `--no-hooks`.
**Warning signs:** README shows client names not in `ValidArgs` list.

### Pitfall 5: Missing Tools from docgen Imports
**What goes wrong:** The auto-generated tool table omits tools because their skill packages aren't imported in `cmd/docgen/main.go`.
**Why it happens:** New skills added without updating docgen imports.
**How to avoid:** After adding any new skill package, add a blank import to `cmd/docgen/main.go`.
