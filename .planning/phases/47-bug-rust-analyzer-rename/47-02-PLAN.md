package edit

import (
    "context"

    serr "github.com/postfix/serena/internal/errors"
    "github.com/postfix/serena/internal/kernel/lspool"
    "github.com/postfix/serena/internal/kernel/symbols"
    gen "github.com/postfix/serena/protocol/gen"
)

// RenameStrategy enumerates the path a successful rename took.
// String values are a public contract: they appear in rename_symbol tool
// responses AND in the serena_rename_strategy_total metric label set.
// MUST NOT change without a coordinated telemetry-schema update.
type RenameStrategy string

const (
    // StrategyLSPNative indicates textDocument/rename succeeded via the LS.
    StrategyLSPNative RenameStrategy = "lsp-native"
    // StrategyRustClientSide indicates the rust-analyzer quirk override was
    // used: references were gathered via textDocument/references and text
    // edits were applied client-side. See BUG-DEFER-02 for semantic limits.
    StrategyRustClientSide RenameStrategy = "rust-client-side"
)

// RenameOverrider is an optional interface that lspool.QuirkAdapter
// implementations may satisfy to bypass textDocument/rename. Called by
// edit.RenameSymbol when the native rename attempt fails. Adapters live
// in the lspool package; the cross-package type assertion is legal.
//
// Semantic-accuracy note: overrides are NOT required to match native LSP
// rename fidelity (cross-crate trait-impl discovery, macro expansion).
// Implementations MUST document their limits in their doc comment AND in
// USAGE.md. See BUG-DEFER-02.
//
// On success returns (*RenameResult, nil); the caller sets Strategy.
// On failure returns (nil, serr.*); the caller wraps in serr.Unsupported
// per D-06 if the native path also failed.
type RenameOverrider interface {
    RenameOverride(
        ctx context.Context,
        lease *lspool.WorkerLease,
        uri string,
        line, col int,
        newName string,
    ) (*RenameResult, error)
}

// RustClientSideRename implements the references-driven fallback used by
// RustAnalyzerAdapter.RenameOverride. Kept in package edit to avoid the
// lspool -> edit import cycle (applyTextEdits is package-private here).
//
// Contract assumptions (rust-analyzer only — DO NOT generalize):
//   1. textDocument/references (includeDeclaration=true) returns ranges
//      that exactly span the identifier to be renamed.
//   2. The symbol has at least one reference (including the declaration).
//
// Failure modes:
//   - zero references        -> serr.NotFound
//   - references RPC error   -> serr.Internal (wrap)
//   - text-edit apply error  -> serr.Internal (wrap, with file URI detail)
func RustClientSideRename(
    ctx context.Context,
    lease *lspool.WorkerLease,
    uri string,
    line, col int,
    newName string,
) (*RenameResult, error) {
    locs, err := symbols.FindReferences(ctx, lease, uri, line, col, true)
    if err != nil {
        return nil, serr.Wrap(serr.Internal, "rust-client-side rename: find references", err)
    }
    if len(locs) == 0 {
        return nil, serr.New(serr.NotFound, "rust-client-side rename: no references at position")
    }
    byFile := make(map[string][]gen.TextEdit)
    for _, loc := range locs {
        byFile[loc.URI] = append(byFile[loc.URI], gen.TextEdit{Range: loc.Range, NewText: newName})
    }
    res := &RenameResult{}
    for fileURI, edits := range byFile {
        if err := applyTextEdits(fileURI, edits); err != nil {
            return nil, serr.Wrap(serr.Internal, "rust-client-side rename: apply edits", err).WithDetail(fileURI)
        }
        res.FilesChanged++
        res.EditsApplied += len(edits)
        res.Files = append(res.Files, fileURI)
    }
    sortStrings(res.Files) // reuse sort pattern; or import "sort" and call sort.Strings
    return res, nil
}
```

// RenameSymbol dispatches a rename request. It first attempts the native
// LSP path (textDocument/prepareRename + textDocument/rename); on failure,
// if the underlying LS adapter implements RenameOverrider, it delegates
// to the override. On success the result carries a Strategy tag. If both
// paths fail, returns serr.Unsupported with a message pointing agents at
// fuzzy_edit, replace_symbol_body, or search_in_files (D-06).
func RenameSymbol(ctx context.Context, lease *lspool.WorkerLease, uri string, line, col int, newName string) (*RenameResult, error) {
    adapter := lease.Adapter() // confirm exact accessor; may be lease.Quirks() — read WorkerLease type in lspool/worker.go

    nativeResult, nativeErr := tryNativeRename(ctx, lease, uri, line, col, newName)
    if nativeErr == nil {
        nativeResult.Strategy = StrategyLSPNative
        return nativeResult, nil
    }

    overrider, ok := any(adapter).(RenameOverrider)
    if !ok {
        // No override available — surface the native error verbatim.
        return nil, nativeErr
    }

    overrideResult, overrideErr := overrider.RenameOverride(ctx, lease, uri, line, col, newName)
    if overrideErr != nil {
        return nil, serr.New(serr.Unsupported,
            "rename_symbol cannot proceed for this symbol (native LSP rename failed and the language-specific override also failed); use fuzzy_edit, replace_symbol_body, or search_in_files for a manual rename").
            WithTool("rename_symbol").
            WithDetail(overrideErr.Error())
    }
    overrideResult.Strategy = StrategyRustClientSide
    return overrideResult, nil
}
```

Because `*RenameResult` lives in package edit, the callback returns `any` and `RustAnalyzerAdapter.RenameOverride` returns `any` too — BUT the `RenameOverrider` interface in package `edit` is declared with `*RenameResult` return. Correct resolution (verbatim, use this one):
- Put `RenameOverride` method body ENTIRELY in `package edit`, NOT on `RustAnalyzerAdapter` in `lspool`.
- Declare a tiny shim type `lspool.RustAnalyzerAdapter` that EXPOSES a field/method `Adapter()` returning itself so `edit` can attach an external override.

Actually the simplest clean resolution is a dedicated small package. But to avoid creating a new package in this plan, use the following pattern:

- In `package edit` declare:
  ```go
  // ensureRustAnalyzerOverride registers this package's RustClientSideRename
  // as the implementation lspool's RustAnalyzerAdapter will delegate to.
  func init() {
      lspool.RustAnalyzerRenameOverrideFn = RustClientSideRename
  }
  ```
- In `package lspool` declare:
  ```go
  // RustAnalyzerRenameOverrideFn is set by package edit via init() to
  // break the lspool -> edit import cycle. DO NOT read this field outside
  // RustAnalyzerAdapter.RenameOverride.
  var RustAnalyzerRenameOverrideFn func(
      ctx context.Context,
      lease *WorkerLease,
      uri string,
      line, col int,
      newName string,
  ) (any, error)

  func (r *RustAnalyzerAdapter) RenameOverride(
      ctx context.Context,
      lease *WorkerLease,
      uri string,
      line, col int,
      newName string,
  ) (any, error) {
      // Best-effort: wait for rust-analyzer quiescence before invoking
      // references-driven rename. The fallback works even without
      // quiescence, so ignore the return value beyond logging.
      _ = r.WaitUntilRenameReady(ctx)
      if RustAnalyzerRenameOverrideFn == nil {
          return nil, errors.New("rust-analyzer override: edit package not initialized")
      }
      return RustAnalyzerRenameOverrideFn(ctx, lease, uri, line, col, newName)
  }
  ```

The `any` return type in `lspool.RustAnalyzerAdapter.RenameOverride` does NOT satisfy `edit.RenameOverrider` (which returns `*edit.RenameResult`). That defeats the purpose.

Therefore the final chosen resolution (implement THIS one, do not deviate):

- The `edit.RenameOverrider` interface is matched STRUCTURALLY. Type assertion `any(adapter).(edit.RenameOverrider)` in the dispatcher requires the method on `*RustAnalyzerAdapter` to return `(*edit.RenameResult, error)` literally. That forces `lspool` to import `edit` → cycle.
- Break the cycle by moving the method implementation from `lspool` into `edit`. In `package edit` add a small wrapper type:
  ```go
  // RustAnalyzerRenameOverride wraps a rust-analyzer adapter pointer with
  // a RenameOverrider implementation. Returned by DecorateRustAnalyzer
  // during daemon post-init, and substituted in place of the bare adapter
  // in WorkerLease.Adapter() for language "rust".
  //
  // Lives in package edit so the method can return *RenameResult without
  // forcing lspool -> edit import.
  type RustAnalyzerRenameOverride struct {
      Inner *lspool.RustAnalyzerAdapter
  }

  func (w *RustAnalyzerRenameOverride) RenameOverride(
      ctx context.Context,
      lease *lspool.WorkerLease,
      uri string,
      line, col int,
      newName string,
  ) (*RenameResult, error) {
      _ = w.Inner.WaitUntilRenameReady(ctx)
      return RustClientSideRename(ctx, lease, uri, line, col, newName)
  }
  ```
