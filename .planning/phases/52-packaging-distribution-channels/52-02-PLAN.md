## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Source tree → release artifacts | Build config (`.goreleaser.yaml`, `Makefile`) determines what binary content reaches users; a misnamed archive or a wrong `main.` path silently produces a broken release that fails the upgrade subcommand's asset-name lookup (RESEARCH.md Pitfall 7). |
| Build-time ldflag → runtime version reporting | The `-X main.version` injection is the only path from a release tag to runtime behavior; if the binding target (`var version` in package main) is missing, every `helix --version` call returns the literal "dev" forever. |
