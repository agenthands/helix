Target shape (after 55-01) — per 55-RESEARCH.md Pattern 3:
```go
func (w *Worker) Request(ctx context.Context, method string, params, result interface{}) error {
    if WorkerState(w.state.Load()) != WorkerReady { return ErrWorkerNotReady }
    ctx, span := w.tracer.Start(ctx, "ls.request")
    defer span.End()
    if span.IsRecording() {
        span.SetAttributes(
            attribute.String("lsp.method", method),
            attribute.String("lsp.language", w.language),
        )
    }
    start := time.Now()
    err := w.process.Conn().Call(ctx, method, params, result)
    duration := time.Since(start)
    if span.IsRecording() {
        span.SetAttributes(attribute.Int64("lsp.duration_ms", duration.Milliseconds()))
    }
    if err != nil {
        if span.IsRecording() {
            span.RecordError(err)
            span.SetStatus(codes.Error, err.Error())
        }
        return err
    }
    w.metrics.OnReuse()
    return nil
}
```

Note: span name is `ls.request` (uniform, low cardinality) per 55-RESEARCH Open Question #2 recommendation, NOT `ls.request.{method}`.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MCP client → daemon | Untrusted JSON tool args cross here; never land on span attributes (only registry-bounded names + executor result text in span events). |
| Worker → external LS process | LS method strings are constants from our codebase, language string from worker config. No client-supplied data ever becomes a span attribute key OR value. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-55-01 | Information Disclosure | `Worker.Request` span attributes | mitigate | Only emit `lsp.method`, `lsp.language`, `lsp.duration_ms` (closed enum + bounded int). NO request params, NO result body, NO file paths. Allowlist test in plan 55-02 enforces this structurally. |
| T-55-02 | Information Disclosure | `AddSkillTool` child span | mitigate | Span name `skill.tool.{name}` where `{name}` is from registry (closed set ≤ ~50). NO attributes set on the child span — parent middleware carries the bounded attribute set. RecordError emits `err.Error()` which may include user input (e.g., file path); accept this risk because (a) error messages already flow into MCP responses to the client, (b) operator chose to enable tracing endpoint, (c) error events are already standard OTel practice. |
| T-55-03 | Denial of Service (cardinality blow-up against trace backend) | LS span name | mitigate | Span name is uniform `"ls.request"` (NOT `"ls.request.{method}"`) per 55-RESEARCH Open Question #2 recommendation. `lsp.method` attribute keeps method visible without inflating span-name cardinality. |
| T-55-04 | Denial of Service (alloc regression on tracing-off path) | `Worker.Request` | mitigate | All `SetAttributes` gated on `span.IsRecording()` (D-17 budget). Benchmark `BenchmarkRequestNoopTracer` in Task 1 enforces ≤ 1 alloc/op on noop path. |
</threat_model>
