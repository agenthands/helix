    ```go
    // buildDispatcher returns a NotificationFunc that routes incoming LS
    // notifications to the per-method handlers registered by the active
    // QuirkAdapter. Unknown methods are debug-logged and dropped (Phase 56 D-04).
    // Handler panics are recovered, logged at Error level, and never crash the
    // Listen goroutine (Phase 56 D-05). The handler map is defensively copied
    // so subsequent mutations of the QuirkAdapter's map cannot affect routing.
    func buildDispatcher(
        handlers map[string]func(json.RawMessage),
        logger *slog.Logger,
        workerID string,
    ) jsonrpc.NotificationFunc {
        routes := make(map[string]func(json.RawMessage), len(handlers))
        for k, v := range handlers {
            routes[k] = v
        }
        return func(method string, params json.RawMessage) {
            h, ok := routes[method]
            if !ok {
                logger.Debug("unhandled LS notification", "method", method, "worker_id", workerID)
                return
            }
            defer func() {
                if r := recover(); r != nil {
                    logger.Error("LS notification handler panicked",
                        "method", method, "worker_id", workerID, "panic", fmt.Sprint(r))
                }
            }()
            h(params)
        }
    }

    // assertDispatcherWired implements the Phase 56 D-11 regression check.
    // Returns a non-nil error if quirks declared handlers but OnNotification was
    // not actually assigned. Logs at Error level so the failure is loud in tests
    // and production.
    func assertDispatcherWired(
        handlers map[string]func(json.RawMessage),
        conn *jsonrpc.Conn,
        logger *slog.Logger,
        workerID string,
    ) error {
        if len(handlers) == 0 {
            return nil
        }
        if conn.OnNotification == nil {
            logger.Error("dispatcher wiring lost between assignment and check",
                "worker_id", workerID, "handler_count", len(handlers))
            return fmt.Errorf("dispatcher wiring failed for worker %s", workerID)
        }
        return nil
    }
    ```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LS subprocess → Worker.Start dispatcher | Trusted local subprocess sends well-formed JSON-RPC notifications. Handlers process payload bytes; malformed JSON in handler-payload is each adapter's concern (jdtls handler unmarshals defensively). |
| Quirk handler → Listen goroutine | Quirk-supplied callback runs synchronously on Listen's goroutine. A buggy/malicious handler could panic. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-56-03 | D (DoS) | Worker dispatcher (buildDispatcher) | mitigate | D-05 panic recovery in dispatcher closure prevents a single buggy handler from killing the Listen goroutine and stalling the worker. Logs at Error so the issue is visible. |
| T-56-04 | T (Tampering) | Wiring step in Worker.Start | mitigate | D-11 regression assertion (`assertDispatcherWired`) fails loudly if a future refactor drops the OnNotification assignment when handlers are non-empty. Worker fails to start rather than running silently broken. |
| T-56-05 | I (Information disclosure) | Debug log of unhandled methods | accept | Debug log includes method name only (no payload). Method names are protocol identifiers, not sensitive. Worker ID is internal. |
| T-56-06 | T (Tampering) | Defensive map copy in buildDispatcher | mitigate | `routes := make(...)` prevents post-construction mutation of the QuirkAdapter's handlers map from racing with dispatch. |
</threat_model>
