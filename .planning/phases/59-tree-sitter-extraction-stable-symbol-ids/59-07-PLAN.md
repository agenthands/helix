**Key conversion notes for the executor:**

- `extract.SymbolKind` (typed string) → `store.SymbolFact.Kind` (string). Cast via `string(s.Kind)`.
- `extract.SymbolFact.ID` (`semantic.SymbolID`) → `store.SymbolFact.SymbolID` (`uint64`). Cast via `uint64(s.ID)`.
- `extract.SymbolFact.StableKey` (`StableSymbolKey` struct) → `store.SymbolFact.StableKey` (`string`). Use `extract.CanonicalizeStableSymbolKey(s.StableKey)` from `internal/semantic/extract/stable_id.go` if that's the existing canonicalization helper; otherwise serialize via the same NUL-joined field order `RepoID\x00Language\x00PackagePath\x00OwnerPath\x00QualifiedName\x00Kind\x00SignatureHash\x00LSPIdentity\x00FilePathFallback` per CONTEXT.md SPEC §11.1.
- `extract.SymbolFact.Range.Start.Line` (uint32) → `store.SymbolFact.StartLine` (int). Cast via `int(s.Range.Start.Line)`.
- `extract.SymbolFact.Confidence` (float32) → `store.SymbolFact.Confidence` (float64). Cast via `float64(s.Confidence)`.
- Fields not present in the source (e.g. `FileID`, `NodeID`, `ContentHash` for Symbols) are zero-value at this layer — the store assigns IDs at INSERT time. The adapter passes zeros through; store's `WriteSnapshotFacts` handles the assignment.
- `ImportFact`, `TypeFact`, `HeritageFact` from `extract.ExtractedFile` are NOT consumed by the current `store.Facts` shape (which only carries Files/Symbols/References/Edges). They are dropped on the floor for now per the CONTEXT.md scope: "Phase 65's buildFn becomes a thin orchestrator (walk → Extract → ToStoreFacts → WriteSnapshotFacts)" — when Phase 62's type resolver wants to consume Imports/Types/Heritage at the store layer, the adapter expands; until then, dropping them keeps the contract minimal. Document this dropped-on-floor list in the function-level doc comment.
- `ExtractedFile.File.ExtractionStatus` ("partial"/"unsupported"/"failed") for non-ready files: emit a `store.FileFact` row with `Path`/`Language` populated and the partial-extraction columns at default. DO NOT skip non-ready files — store-side semantics rely on a `semantic_files` row existing for every file the scheduler classified, even when no symbols/references emit (per ROADMAP acceptance criterion #10: "For a workspace containing Rust files (or any non-first-class language), `semantic_files` rows exist with `extraction_status='unsupported'` and no `semantic_symbols` rows.").

    // Package extract — adapter from per-language ExtractedFile output to the
    // store-shaped semanticstore.Facts wire format.
    //
    // ToStoreFacts is a pure deterministic function: same input → byte-identical
    // output across repeated calls and across processes. No I/O, no scheduler /
    // store dependency at runtime. The function is the locked Phase 65 unblock
    // adapter (CONTEXT.md D-08, 2026-05-08 update); Phase 65's production
    // buildFn at internal/daemon/semantic_wiring.go composes:
    //
    //   walk → provider.Extract (D-06) → ToStoreFacts (D-08) → store.WriteSnapshotFacts
    //
    // Dropped-on-floor (intentional, documented):
    //   - ExtractedFile.Imports — store.Facts has no imports column today.
    //   - ExtractedFile.Types — Phase 62 territory; not yet consumed at the
    //     store layer.
    //   - ExtractedFile.Heritage — Phase 62 territory; ditto.
    //
    // When Phase 62's type resolver wants to consume these at the store layer,
    // expand both store.Facts and this adapter together; until then the drop
    // is the simplest correct contract.

    package extract

    import (
        semanticstore "github.com/agenthands/helix/internal/semantic/store"
    )

    func ToStoreFacts(files []*ExtractedFile) semanticstore.Facts {
        if len(files) == 0 {
            return semanticstore.Facts{}
        }

        out := semanticstore.Facts{
            Files:      make([]semanticstore.FileFact, 0, len(files)),
            Symbols:    make([]semanticstore.SymbolFact, 0, /* rough cap */ 4*len(files)),
            References: make([]semanticstore.ReferenceFact, 0, /* rough cap */ 4*len(files)),
            // Edges left nil — Phase 62 territory, not in P04 emit path.
        }

        for _, ef := range files {
            if ef == nil { continue } // Test 4 nil-safety
            out.Files = append(out.Files, fileFactToStore(ef.File))
            for _, s := range ef.Symbols {
                out.Symbols = append(out.Symbols, symbolFactToStore(s))
            }
            for _, r := range ef.References {
                out.References = append(out.References, referenceFactToStore(r, ef.File.Path))
            }
            // ef.Imports / ef.Types / ef.Heritage intentionally dropped — see
            // package doc comment.
        }

        return out
    }

    // fileFactToStore maps the extract per-file metadata to the store FileFact
    // wire shape. Defaults the not-yet-populated fields (FileID, ContentHash,
    // SizeBytes, LineCount) — store assigns FileID at INSERT time; the rest
    // are populated by upstream pipeline stages (Phase 60 LIVE-01 + Phase 61
    // enrichment). Path + Language are the only required NOT-NULL columns at
    // this layer.
    func fileFactToStore(f FileFact) semanticstore.FileFact {
        return semanticstore.FileFact{
            Path:     f.Path,
            Language: f.Language,
            // Other fields: zero-value; populated downstream.
        }
    }

    func symbolFactToStore(s SymbolFact) semanticstore.SymbolFact {
        return semanticstore.SymbolFact{
            SymbolID:      uint64(s.ID),
            Language:      s.Language,
            Kind:          string(s.Kind),
            Name:          s.Name,
            QualifiedName: s.QualifiedName,
            StableKey:     CanonicalizeStableSymbolKey(s.StableKey),
            // Container resolves to OwnerSymbolID via the Phase 62 resolver
            // pipeline; for now zero-value (store schema permits NULL → 0
            // fallback for unresolved owners).
            StartLine:  int(s.Range.Start.Line),
            StartCol:   int(s.Range.Start.Column),
            EndLine:    int(s.Range.End.Line),
            EndCol:     int(s.Range.End.Column),
            Signature:  s.Signature,
            SignatureHash: s.SignatureHash,
            Visibility: s.Visibility,
            Exported:   s.Visibility == "exported", // mirror SPEC §11.1 closed-enum
            Confidence: float64(s.Confidence),
            // ContentHash, LSPIdentity left zero-value: enrichment fills them.
        }
    }

    func referenceFactToStore(r ReferenceFact, filePath string) semanticstore.ReferenceFact {
        return semanticstore.ReferenceFact{
            // RefID, FileID, NodeID assigned by store at INSERT time.
            Name:           r.Name,
            RefKind:        string(r.Kind), // extract.ReferenceFact.Kind is `ReferenceKind` (a typed string per fact.go:28); store-side field is named RefKind. Cast to string is safe.
            // Range mapping mirrors symbolFactToStore.
            StartLine:      int(r.Range.Start.Line),
            StartCol:       int(r.Range.Start.Column),
            EndLine:        int(r.Range.End.Line),
            EndCol:         int(r.Range.End.Column),
            // ScopeSymbolID, ResolvedSymbolID, ResolutionSource: zero-value
            // until Phase 62 resolver layer populates them.
        }
    }
