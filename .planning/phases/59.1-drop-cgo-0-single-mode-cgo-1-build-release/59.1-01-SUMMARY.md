# Phase 59.1 Plan 01: cgo-stub-flatten-and-delete Summary

INT-BLOCKER-01 closed at the compile boundary by removing the entire CGO=0
build path: 13 `_nocgo*` stubs deleted, 24 `//go:build cgo` tags stripped,
4 file renames (3 _cgo.go -> .go + the daemon compound-tag hand-edit),
the daemon's step-6a refusal block deleted, and the new D-14 Path-3
platform stub `internal/semantic/store/duckdb_winarm64.go` in place — so
`CGO_ENABLED=0 go build ./cmd/helix` cannot succeed on any target while
the windows/arm64 archive remains buildable via a platform (NOT cgo)
build constraint that pairs with a `//go:build !(windows && arm64)` tag
on the flattened `duckdb.go`.

  `//go:build windows && arm64`, returns `serr.ErrUnsupported` from all
  Store entry points; `(*Store).Available()` returns false. Method-set
  matches the (now-deleted) `duckdb_nocgo.go` template verbatim, so the
  package compiles cleanly on every target.

  `duckdb_nocgo_test.go` + the orphaned `treesitter/available_cgo.go`
  (the constant retired entirely per D-07).

  (`cgo && integration` -> `integration`) per Pitfall 5; never regex.
- **3 renames via `git mv`:** `registry_cgo.go -> registry.go`,
  `migrations_registry_cgo.go -> migrations_registry.go`,
  `extract_cgo.go -> extract.go`. History preserved.
- **One in-place edit on `internal/treesitter/sig_assert.go`:** retired
  the obsolete `GetLanguage intentionally NOT declared` comment that
  referred to the now-deleted `registry_nocgo.go`. The signature
  assertion (`var _ interface{ SupportsLanguage; SupportedLanguages } =
  (*GrammarRegistry)(nil)`) is preserved as the sole compile-time
  check on the package public API.
- **`internal/daemon/daemon.go`:**
  - Step-6a refusal block (10 lines including comment header) deleted.
  - Step-6b leading comment trimmed of the trailing
    "Under CGO=0, step 6a already returned…" sentence.

    `errors.Is(err, serr.ErrUnsupported)` (D-14): logs a warning,
    leaves `semanticStore = nil`, daemon proceeds. Other Open errors
    still hard-fail per Phase 57 STORE-01.
  - New import alias added: `serr "github.com/agenthands/helix/internal/errors"`.
  - `Daemon.semanticStore` field doc comment updated to reflect the
    new windows/arm64 platform-stub posture (replaces the dead
