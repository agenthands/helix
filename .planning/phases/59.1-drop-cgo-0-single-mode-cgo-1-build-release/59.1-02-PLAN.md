  per-archive `metadata.json` files. Cosign signing runs uniformly across the merged
  set (Wave 3 merge job).

  update both `release.yml` job pins to the new SHA + `# v<x.y.z>` comment).

  `id:` per-runner filtering (linux runner runs `goreleaser build --id helix-non-darwin`;
  macos-14 runner runs `--id helix-darwin`; merge job runs `goreleaser release --skip-build`
  to assemble archives + checksums + signatures from the pre-built binaries).
