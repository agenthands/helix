**Per-runner Pass-1≡Pass-2 gate logic shape** (preserved verbatim in spirit from current release.yml lines 41-119):

The reproducibility gate is the existing logic, forked once per runner:
1. Run `goreleaser build … --id <id> --output dist-pass-1/` (Pass-1).
2. Capture per-target sha256s into `/tmp/pass1-<runner>.sha256` (sorted, deterministic order).
3. Run `goreleaser build … --id <id> --output dist-pass-2/` (Pass-2).
4. Capture per-target sha256s into `/tmp/pass2-<runner>.sha256`.
5. `diff -u /tmp/pass1-<runner>.sha256 /tmp/pass2-<runner>.sha256` — exit 0 = gate PASS; non-zero = forensic dump + exit 1.
6. On divergence: extract first divergent binary, dump per-file sha256 + tar-entry metadata (`tar -tvf` for the eventual archive) + gzip header bytes (xxd) + `go version -m` diff; exit 1.

**Note on the "final pass" before upload:** since `goreleaser build` is deterministic when pinned (zig 0.14.1 hermetic on linux; macos-14 host clang on darwin), and Pass-1≡Pass-2 has just been asserted, the artifacts uploaded to the merge job MAY be either `dist-pass-2/` directly OR a third invocation `goreleaser build --snapshot --clean --id <id>` writing to `dist/`. **Choice: re-use `dist-pass-2/` by `mv dist-pass-2 dist`** to avoid a third unnecessary build. This is the same pattern the current release.yml uses at lines 122-128 (`mv dist dist-pass-1` after Pass-1, then re-run for Pass-2 → final `dist/`). The Pass-2 `dist-pass-2/` becomes the upload artifact via rename.

**Merge-job dist layout** (from `59.1-02-SPLIT-PROBE-NOTES.md` line 200): goreleaser writes its expected layout `dist/helix-<id>_<os>_<arch>/helix[.exe]` during `goreleaser build`; this layout is what `goreleaser release --skip=build` needs to see. The merge job downloads both `dist-partial-linux/` and `dist-partial-darwin/` artifacts via `actions/download-artifact`, then merges them into a single `dist/` tree (e.g. `mv dist-partial-linux/* dist/ && mv dist-partial-darwin/* dist/`). The merge layout shape will be confirmed in Wave 5 via the first workflow_dispatch run; if `goreleaser release --skip=build` complains about the layout, Wave 5 amends the merge step.
