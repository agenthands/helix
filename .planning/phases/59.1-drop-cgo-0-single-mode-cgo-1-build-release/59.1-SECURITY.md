# Phase 59.1 — Security

> Per-phase security contract for the source-tree CGO=1 single-mode flip and the split-runner release pipeline. Threat register consolidated from `59.1-{00..05}-PLAN.md` `<threat_model>` blocks plus the `Threat Flags` section of `59.1-05-SUMMARY.md`. Verified inline against the implementation that shipped in tag `v1.10.7` (2026-05-05).

---

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| GitHub Actions runner ↔ goreleaser binary | OSS goreleaser v2.15.4, SHA-pinned via `goreleaser-action`. A malicious action update could substitute a different binary — mitigated by SHA pin. | Build artifacts |
| goreleaser ↔ host gcc + apt cross-toolchain (linux runner) | ubuntu-22.04 ships `gcc/g++` (linux/amd64); `gcc-aarch64-linux-gnu`/`g++-aarch64-linux-gnu` installed via apt-get for linux/arm64. **Note:** zig was removed during the v1.10.1→v1.10.7 hot-fix iteration; the apt + host-gcc path is canonical. | Compilation symbols |
| goreleaser ↔ Apple clang (darwin runner) | macos-14 explicit pin (NOT macos-latest) per D-18; Xcode 15.x selected via `xcode-select`. | Compilation symbols |
| Cosign keyless signing ↔ Sigstore Fulcio + Rekor | release-merge job runs `cosign sign-blob --new-bundle-format` against public-good infra; `id-token: write` granted ONLY on this job. | Build artifact signatures, Fulcio short-lived certs |
| Daemon runtime ↔ semantic store (windows/arm64) | D-14 platform stub returns `serr.ErrUnsupported`; daemon soft-degrades (`semantic_index disabled`) without refusing to start. | Index queries (suppressed) |
