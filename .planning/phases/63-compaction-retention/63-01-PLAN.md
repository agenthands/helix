<objective>
Fill the empty `internal/semantic/store/snapshot.go` stub (deferred from Phase 59) with the snapshot-write API the Phase 63 compactor will consume:

- `BeginSnapshot(ctx, SnapshotMeta) (*Snapshot, error)` — opens a DuckDB tx, allocates a pending `semantic_snapshots` row, returns a `*Snapshot` handle bound to the tx.
- `(*Snapshot).WriteFacts(ctx, Facts) error` (alias `WriteSnapshotFacts`) — typed inserts for files/symbols/references/edges through the same tx using `database/sql` parameterized inserts (NEVER `duckdb-go` Appender — RESEARCH.md Landmine 6).
- `(*Snapshot).Commit(ctx, SnapshotSummary) error` (alias `CommitSnapshot`) — flips `status='committed'`, writes the summary row, commits the tx.
- `(*Snapshot).Abort(ctx, reason string) error` (alias `AbortSnapshot`) — rolls back the tx (the pending row vanishes via DuckDB ACID — no explicit DELETE needed).
- `(*Snapshot).DeleteSnapshotsBeyond(ctx, retain int) error` for retention — runs DELETE inside the SAME *Snapshot tx so retention is atomic with snapshot creation (COMPACT-04 single-tx requirement).
- `(*Snapshot).ClearOverlayLE(ctx, repoID, capturedEpoch uint64) error` — issues `DELETE FROM semantic_live_overlay_* WHERE repo_id=? AND write_epoch <= ?` on the snapshot's underlying tx. Encapsulates `*sql.Tx` so callers (P63-02 compactor) never need an exported `Tx()` accessor; the snapshot handle owns its tx end-to-end (Phase 63 plan-checker review fix).

Purpose: The snapshot-write API is reviewable as a clean foundation PR before any compaction logic enters the picture (CONTEXT.md D-02 rationale). Risk reduction — the compactor PR (P63-02) is then purely about state-machine logic, not about insert correctness.

Output: `internal/semantic/store/snapshot.go` filled (~200+ LOC), unit tests covering Begin→Write→Commit, Begin→Abort, retention-delete-inside-tx patterns, plus a synthetic "fake compactor" test fixture that exercises the API end-to-end without depending on real overlay merge logic. type OverlayTx struct {
    tx         *sql.Tx

}

func (t *OverlayTx) Epoch() uint64

func (s *Store) BeginOverlayTx(ctx context.Context, repoID string) (*OverlayTx, error) {
    if s == nil || s.db == nil {
        return nil, fmt.Errorf("BeginOverlayTx: nil store")
    }
    if repoID == "" {
        return nil, fmt.Errorf("BeginOverlayTx: empty repoID")
    }
    // ... ensure meta row → bump epoch → BeginTx ...
    tx, err := s.db.BeginTx(ctx, nil)
    if err != nil {
        mu.Unlock()
        return nil, fmt.Errorf("BeginOverlayTx: open tx: %w", err)
    }
    return &OverlayTx{tx: tx, repoID: repoID, epoch: epoch, unlock: mu.Unlock}, nil
}

func (t *OverlayTx) Commit() error   { defer t.releaseLock(); return t.tx.Commit() }
func (t *OverlayTx) Rollback() error { defer t.releaseLock(); return t.tx.Rollback() }

       - guard `snap.committed` (return error if set — must run inside the open tx)
