<objective>
Ship the Phase 63 compaction worker, retention, and VACUUM-no-op infrastructure on top of the snapshot-write API delivered by P63-01.

**What this plan delivers:**

1. **`internal/semantic/compact/` package** — `compactor.go` (per-workspace goroutine + `time.AfterFunc(compact_after_idle_ms)` reset on flush + `OnFlush()` hook + `runCompaction` body), `gate.go` (`CompactionGate.IsReady` with closed-enum `BlockedReason` deterministic precedence), `accessors.go` (consumer-side interface declarations), `vacuum.go` (config-gated no-op-by-DuckDB VACUUM in its own tx).

2. **Single-tx compaction** (D-01 hard invariant): one DuckDB tx wraps `BeginSnapshot` → `WriteSnapshotFacts(merged base+overlay)` → `snap.DeleteSnapshotsBeyond(retain=5)` → `snap.ClearOverlayLE(write_epoch <= captured_epoch)` → `CommitSnapshot`. The latter two are methods on `*Snapshot` so the underlying `*sql.Tx` stays encapsulated — no exported `snap.Tx()` accessor (warning #6 fix). CHECKPOINT issued on the store handle AFTER tx commits.

3. **Pre-flight overlay-row-count guard**: before opening the compaction tx, `store.OverlayRowCount(ctx, repoID, capturedEpoch)` is checked against `cfg.MaxOverlayRows = max_overlay_files * 4`; if exceeded, emit `outcome=partial` and skip — next idle window retries.

4. **Six new accessor additions on existing components** (small additive — RESEARCH.md Existing Component Accessors):
   - `coalescer.LastFlushAt() time.Time` (atomic.Int64 nanos stamped at flush start)
   - `store.OverlayTxOpenCount(ws) int` (atomic.Int32 incremented in BeginOverlayTx, decremented in releaseLock)
   - `store.OverlayRowCount(ctx, repoID, capturedEpoch) (int, error)` (index-served SELECT COUNT(*) per overlay table)
   - `lspenrich.LaneQueue.LastEnqueueAt() time.Time` + workspace-shim `Depth(ws)` returning `DepthAll()`
   - `graph.RankScheduler.IsQuiescent() bool` (extends with `atomic.Int32 inFlightCount` so set-too-late `pendingChanged` clear inside `runIncrementalRepair` is corrected per RESEARCH.md)
   - `kernel.ActiveEditTxCount(ws) int` (counter wrapper around the 8 edit tools' Handle bodies)

5. **Daemon wiring** — new `internal/daemon/compact_wiring.go` with `compactBundle` (mirror `rankBundle`); `buildCompactBundle` constructed alongside `buildLiveBundle` / `buildRankBundle` in `daemon.go`; SetActivateCallback hook spawns per-workspace compactor; errgroup goroutine joins on shutdown; `Coalescer.SetOnFlush(fn)` post-flush hook calls `compactBundle.OnCoalescerFlush(ws)`.

6. **Config keys** — `semantic_index.maintenance.vacuum_enabled` (default `false`) and `semantic_index.maintenance.vacuum_interval` (default `"168h"`). package compact

import (
    "context"
    "time"

    "github.com/agenthands/helix/internal/workspace"
)

type CoalescerAccessor interface {
    LastFlushAt(ws workspace.WorkspaceKey) time.Time
}

type OverlayTxAccessor interface {
    OverlayTxOpenCount(ws workspace.WorkspaceKey) int
}

type OverlayRowAccessor interface {
    // OverlayHasPendingRows is the in-memory proxy consumed by CompactionGate.IsReady.
    // Backed by an atomic counter incremented at every overlay row write
    // (BeginOverlayTx.UpsertOverlayFile / Mark*Deleted) and reset to 0 when
    // ClearOverlayLE deletes ≥ 1 row. O(1), no I/O — D-04 hard invariant.
    OverlayHasPendingRows(repoID string) bool

    // OverlayRowCount is the I/O path used ONLY by the pre-flight size guard
    // inside runCompaction (never inside IsReady). Consumed via OverlayOps,
    // not via the gate — kept here as a typed contract for the OverlayOps
    // wrapper that the compactor holds.
    OverlayRowCount(ctx context.Context, repoID string, capturedEpoch uint64) (int, error)
}

type LSPQueueAccessor interface {
    Depth(ws workspace.WorkspaceKey) int
    LastEnqueueAt(ws workspace.WorkspaceKey) time.Time
}

type SchedulerAccessor interface {
    IsQuiescent(ws workspace.WorkspaceKey) bool
}

type KernelEditAccessor interface {
    ActiveEditTxCount(ws workspace.WorkspaceKey) int
}

package compact

type BlockedReason string

const (
    BlockedNone            BlockedReason = ""
    BlockedOverlayEmpty    BlockedReason = "overlay_empty"
    BlockedIdleTooShort    BlockedReason = "idle_too_short"
    BlockedEditTxActive    BlockedReason = "edit_tx_active"
    BlockedOverlayTxActive BlockedReason = "overlay_tx_active"
    BlockedLSPPending      BlockedReason = "lsp_pending"
    BlockedRankRepairing   BlockedReason = "rank_repairing"
)

type GateConfig struct {
    CompactAfterIdle    time.Duration
    LSPCompactionMaxWait time.Duration
}

    coalescerAccess CoalescerAccessor
    overlayAccess   OverlayTxAccessor
    overlayRowAccess OverlayRowAccessor   // gate consumes ONLY .OverlayHasPendingRows (in-memory); never .OverlayRowCount
    lspAccess       LSPQueueAccessor
    schedAccess     SchedulerAccessor
    kernelAccess    KernelEditAccessor
    cfg             GateConfig
    now             func() time.Time
}
