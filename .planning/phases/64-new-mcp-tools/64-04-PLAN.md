    1) Run(ctx, ws, mode, maxMs):
       - key := ws.RepoRoot() + "|" + mode
       - Compute deadline := min(time.Duration(maxMs)*time.Millisecond, r.timeout). If maxMs less-or-equal 0, deadline = r.timeout (default 120s per CONTEXT.md D-01).
       - callCtx, cancel := context.WithTimeout(ctx, deadline); defer cancel()
       - Capture per-call startedAt := time.Now() BEFORE singleflight so DurationMs reflects this caller's wait time.
       - ch := r.sf.DoChan(key, func() (any, error) { ... }). The DoChan callback derives bgCtx, bgCancel := context.WithCancel(context.Background()) — NOT request ctx (D-04 background continuation). Stores bgCancel in inFlight[ws.RepoRoot()] for shutdown cancellation. Calls r.buildFn(bgCtx, ws, mode, state). On return, deletes the inFlight entry and returns the IndexResult.
       - select { case v := chan-receive: ... case ctx-done callCtx.Done: ... }.
         - On chan-receive: cast v.Val.(IndexResult); set DurationMs = time.Since(startedAt).Milliseconds(); set Status = IndexStatusCommitted (or Failed on err); return.
         - On callCtx.Done: read inFlight[ws.RepoRoot()] for in-progress state (atomics filesIndexed/filesReused/snapshotID); return IndexResult{Partial:true, Status:IndexStatusBuilding, SnapshotID: st.snapshotID, FilesIndexed: st.filesIndexed.Load(), FilesReused: st.filesReused.Load(), Freshness: FreshnessStale, DurationMs: deadline.Milliseconds()}, nil.

    2) ResolveAuto(ctx, ws):
       - latest, err := r.store.LatestCommittedSnapshot(ctx, ws.RepoID()). If err != nil OR latest == 0 -> "full". Else -> "incremental".

         snapshotID    uint64
         startedAt     time.Time
         mode          string
         filesIndexed  atomic.Int64
         filesReused   atomic.Int64
         cancel        context.CancelFunc
         done          chan struct{}

    4) NewIndexRunner(store, buildFn, timeout) returns &IndexRunner{...}. Default timeout = 120 * time.Second when zero.
