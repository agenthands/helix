Three files (plus the test-only export and a sibling test file), three concerns,
one wave:

1. The new E2E test file at `internal/daemon/integ_lookup_e2e_test.go` is in the
   daemon package because that's where `integSemanticLookup` lives and is the
   only place where it can be constructed without an export-only-for-test
   surface. Keeping it package-internal also means we exercise the real
   `integLookupAccessor()` path that production goes through. The test is
   skipped today; later plans flip it on.

2. The companion `internal/daemon/integ_lookup_export_for_test.go` (BL-1 / WR-6
   / BL-A fix) is a `_test.go`-suffixed file in `package daemon` exposing
   BOTH `NewIntegSemanticLookupForTest` (bare adapter) AND
   `NewE2EIntegLookupForTest` (fully-populated harness). This is the
   standard Go convention for exposing package-private types to external
   test packages: `_test.go` files are EXCLUDED from production builds by
   the compiler — no build tag is needed, no production leakage occurs.
   Cross-package consumers (e.g.,
   `internal/skill/semantic/integration_test.go` in 65-12 Task 4 AND
   `internal/kernel/symbols/blast_radius_strangler_test.go` in 65-12
   Task 2 BL-1 ConfidenceLadder) import the constructors; the standard
   build never sees them.

   BL-A: shipping `NewE2EIntegLookupForTest` here in 65-09 — not as a
   conditional "extend from 65-12" fallback — guarantees 65-12 Task 2 has
   one concrete cross-package call to make and zero conditional language in
   its action body.

3. The new `internal/skill/semantic/integration_test.go` E2E tests
   (`TestE2E_StranglerFig_ProductionAdapter_SourceSemantic` and
   `BlastRadiusConfidence`) are the higher-level regressions — they drive a

   wire-side envelope. These are the tests the verifier called out as missing.
   They MUST land in this wave (skipped) so 65-12 can flip a single t.Skipf
   line off to prove goal SC #1 + #2.

4. CR-02 fix is a 6-line stdlib swap in a kernel/health file unrelated to
   the daemon-side stubs. Splitting it into its own plan would inflate the
   plan count for no quality gain. It bundles here because (a) it's a TDD
   RED-GREEN trivial loop and (b) it does not touch any file the other
   gap-closure plans modify, so it cannot conflict.

No boundary breach: the new daemon test file imports `internal/semantic/integ`,
`internal/semantic/store`, `internal/semantic/retrieval` — all permitted from
the daemon package (only `internal/kernel` is forbidden by the lint
analyzer). The kernel/health test file imports `internal/errors` (already
used elsewhere in kernel/health). Both stay inside their allowed boundaries.
</rationale>

    // harness. The caller receives:
    //   lookup    — *integSemanticLookup wrapping a real *Store + retrieval
    //   ws        — the workspace key the harness committed under
    //   store     — the real *semanticstore.Store (defer cleanup closes it)
    //   syms      — symbolsByStableKey: keyed by either canonical labels
    //               (BL-A: "confirmed_edge_from", "confirmed_edge_to",
    //               "refuted_edge_from", "refuted_edge_to", "confirmed_edge",

    //
    // Fixture content (BL-2 option 1, complete in this helper):
    //   - 3 files × 5 symbols each = 15 symbols (Facts via CommitSnapshot)
    //   - 15 ScoreRows (status="exact", projection="call_graph", varying scores)
    //   - >= 5 EdgeRows in projection="call_graph"; the EdgeRow set includes
    //     exactly one "confirmable" edge (from confirmed_edge_from →
    //     confirmed_edge_to) and one "refutable" edge (from refuted_edge_from
    //     → refuted_edge_to). 65-12's fake LSP probe uses these edge IDs to
    //     decide confirm vs refute.
    func newE2EIntegLookup(t *testing.T) (
        lookup *integSemanticLookup,
        ws workspace.WorkspaceKey,
        store *semanticstore.Store,
        syms map[string]FixtureSymbolMeta,
        cleanup func(),
    ) {
        t.Helper()
        wsDir := t.TempDir()
        ws = workspace.WorkspaceKey{RepoRoot: wsDir, RepoHash: "fixture-repo"}

        // Open real *semanticstore.Store.
        cfg := semantic.Config{
            Enabled: true,
            Store: semantic.StoreConfig{
                Kind:        "duckdb",
                Path:        filepath.Join(wsDir, ".helix", "semantic.duckdb"),
                MemoryLimit: "256MiB",
                Threads:     2,
            },
        }
        var err error
        store, err = semanticstore.Open(context.Background(), cfg)
        if err != nil {
            t.Fatalf("semanticstore.Open: %v", err)
        }

        // Open real *retrieval.Engine for the bleve-using paths.
        engine, err := retrieval.New(filepath.Join(wsDir, ".helix", "semantic.bleve"))
        if err != nil {
            t.Fatalf("retrieval.New: %v", err)
        }

        // Build Facts fixture (3 files × 5 symbols = 15 symbols, including
        // the 4 canonical edge-end symbols).
        syms = make(map[string]FixtureSymbolMeta, 21)
        facts := makeFullFixtureFacts(syms)

        // Commit snapshot.
        snapID, err := commitFixtureSnapshot(context.Background(), store, ws.RepoHash, facts)
        if err != nil {
            t.Fatalf("commitFixtureSnapshot: %v", err)
        }
        if snapID == 0 {
            t.Fatalf("commitFixtureSnapshot returned zero snapshot id")
        }

        // Stamp ScoreRows for every fixture symbol AND the >= 5 EdgeRows
        // including the canonical confirmable + refutable pair. The function
        // populates syms["confirmed_edge"] / syms["refuted_edge"] with the
        // EdgeIDs the writer assigned.
        if err := stampFixtureScoresAndEdges(context.Background(), store, ws.RepoHash, snapID, syms); err != nil {
            t.Fatalf("stampFixtureScoresAndEdges: %v", err)
        }

        // Construct the *integSemanticLookup directly.
        lookup = &integSemanticLookup{
            store:     store,
