<!-- Visibility closed enum per OI-02 (RESEARCH lines 760-779): -->
```go
type Visibility string
const (
    VisPublic    Visibility = "public"
    VisExported  Visibility = "exported"
    VisProtected Visibility = "protected"
    VisPackage   Visibility = "package"
    VisPrivate   Visibility = "private"
    VisUnknown   Visibility = "unknown"
)
func (v Visibility) IsPublicLike() bool {
    return v == VisPublic || v == VisExported || v == VisProtected
}
```

<!-- Per-language Visibility data source (internal/semantic/extract/fact.go line 98 — VERIFIED): -->
The Fact struct's `Visibility string` field is populated by per-language extractors. ParseVisibility(raw string) maps to closed enum:
- "exported" → VisExported (Go uppercase, JS/TS export)
- "public" → VisPublic (Java public, C# public)
- "protected" → VisProtected (Java protected, C# protected, etc.)
- "package" → VisPackage (Java package-private, Go lowercase)
- "private" → VisPrivate (TS private, Java private, Python leading underscore)
- "" or anything else → VisUnknown
