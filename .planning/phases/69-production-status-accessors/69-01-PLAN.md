```go
func (s *Store) CountStaleScoreRows(ctx context.Context, repoID, projection string) (stale, total int, err error) {
    if s == nil || s.db == nil {
        return 0, 0, errors.New("CountStaleScoreRows: nil store")
    }
    const q = `SELECT COALESCE(SUM(CASE WHEN status='stale' THEN 1 ELSE 0 END),0), COUNT(*)
               FROM semantic_graph_scores WHERE repo_id=? AND score_name=?`
    if err := s.db.QueryRowContext(ctx, q, repoID, projection).Scan(&stale, &total); err != nil {
        if errors.Is(err, sql.ErrNoRows) { return 0, 0, nil }
        return 0, 0, fmt.Errorf("CountStaleScoreRows(%q,%q): %w", repoID, projection, err)
    }
    return stale, total, nil
}
```

**ClusterStatusRow shape (REVISED — supports stale-state derivation per revision feedback):**

```go
type ClusterStatusRow struct {
    GraphVersion       uint64 // the gv the caller asked about
    ActualGraphVersion uint64 // the gv whose rows we actually returned (== GraphVersion when IsCurrent, else highest prior gv with rows)
    IsCurrent          bool   // true when rows for the requested gv were found; false on fallback-to-prior
    ComputedAt         int64  // unix ms from MAX(computed_at) of returned rows; 0 when zero-value
    MemberCount        int    // COUNT(*) over semantic_cluster_members for ActualGraphVersion
    ClusterCount       int    // COUNT(DISTINCT cluster_id) for ActualGraphVersion
}
```

Empty / no-rows case → zero value of the struct (IsCurrent=false, ActualGraphVersion=0, etc.), nil error. The adapter (Plan 69-05) distinguishes:
- ClusterCount > 0 && IsCurrent → `"current"`
- ClusterCount > 0 && !IsCurrent → `"stale"` (Reason=`graph_version-lag`)
- ClusterCount == 0 → `"unknown"` (Reason=`no-cluster-rows`)

**SQL strategy (two-step, both read-only):**

Step 1 — primary lookup (requested gv):
```sql
SELECT
    COALESCE(MAX(EXTRACT(EPOCH FROM c.computed_at) * 1000), 0)::BIGINT,
    COUNT(DISTINCT c.cluster_id),
    (SELECT COUNT(*) FROM semantic_cluster_members m WHERE m.repo_id=? AND m.graph_version=?)
FROM semantic_clusters c
WHERE c.repo_id=? AND c.graph_version=?
```

If cluster_count > 0 → return with IsCurrent=true, ActualGraphVersion=requested gv.

Step 2 — fallback (only if step 1 returned zero rows): find the highest prior graph_version with cluster rows for this repo, then repeat the aggregation:
```sql
SELECT MAX(graph_version) FROM semantic_clusters WHERE repo_id=? AND graph_version < ?
```
If MAX returns NULL → zero-value struct, nil error (no rows at all).
Otherwise repeat the step-1 aggregation against the resolved older gv, return IsCurrent=false, ActualGraphVersion=<older gv>.

Both queries are pure SELECTs → D-09 compliant. Two queries on the fallback path is acceptable — fallback is the cold path; current-gv hits return in one round trip.
