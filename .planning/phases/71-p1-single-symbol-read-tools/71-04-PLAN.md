<objective>
Ship `find_related_symbols` — the second of the three Phase 71 P1 MCP tools. Given one seed symbol, return up to `k` ranked sibling symbols via PersonalizedPageRank-from-seeds + RRF fusion (`retrieval.Fuse`) + post-fuse cluster co-membership boost. Honors `paths` as a strict-subset filter on results; seed itself is unconstrained. Mode tier read+ enforced at handler entry; read-only.

Purpose: Closes P1TOOL-02. Agents asking "what else should I look at near this symbol" get a deterministic, ranked answer reusing the same fusion entrypoint that powers `get_semantic_context`.

Output: One new handler file + tests + one-line register.go extension.
</objective>
