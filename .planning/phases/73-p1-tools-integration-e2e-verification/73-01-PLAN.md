<objective>
Make the 6 P1 MCP tools visible to the profile-filter resolution path and
enforce the `review+` mode tier for `get_change_impact_graph` at the
`tools/list` boundary.

Purpose: `SemanticSkill.Tools()` (skill.go:325-352) currently returns ONLY the
4 P0 tools. `skill.ResolveTools` — the path `ProfileFilterMiddleware` uses to
build `tools/list` — operates on the `Tools()` ToolProvider surface, so the 6
P1 tools (registered directly via `RegisterAll`) are invisible to profile
filtering. SC#1's golden test (Plan 73-02) would assert visibility of tools the
resolver never sees. Additionally, the read/edit mode YAMLs only exclude
`index_semantic_graph`; `get_change_impact_graph` (review+ tier) is NOT
excluded there, so it would leak into read/edit `tools/list`. Both gaps must
close before SC#1 is verifiable.

Output: a 10-entry `Tools()` list and read/edit mode YAMLs that exclude the one
review+ P1 tool.
</objective>
