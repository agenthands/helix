all 6 P1 tools via a static in-tree consistency gate and a shared real-store
E2E suite.

tests reuse it. SC#4 explicitly demands a real `*Store` — the in-memory
`populated_graph_fixture_test.go` mock does NOT satisfy it (D-02a).

(test-only `Handle*ForTest` exports), `p1_e2e_external_test.go` (shared builder
+ 6 per-tool closed-enum envelope tests).
