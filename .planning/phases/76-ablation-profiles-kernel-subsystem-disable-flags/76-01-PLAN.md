<objective>
Add the two kernel subsystem-disable flags to `kernel.KernelConfig` (both
`DisableLSPSubsystem` and `DisableStructuredEditSubsystem` — defining both here
so Plan 76-04 can consume `LSPSubsystemDisabled()` without re-touching
kernel.go), expose `LSPSubsystemDisabled()` / `StructuredEditDisabled()`
accessors, and wire the ABLATE-07 runtime guard: the four structured-edit tool
handlers return a typed `serr.Unsupported` error under the flag, and
`replace_in_file` falls through to exact-match-only (no fuzzy cascade) under the
flag (D-04, D-05, D-06).

Purpose: This is the kernel foundation. The accessors defined here are the
contract that Plan 76-04 (no_lsp daemon wiring) and the structured-edit guard
both build against — interface-first so no downstream scavenger hunt. The
runtime `Unsupported` guard is the back-channel backstop the `vet-ablation-leakage`
analyzer (Plan 76-03) cannot cover at compile time (D-08).

Output: extended `KernelConfig` + accessors; guarded structured-edit handlers;
guarded `replace_in_file`; two new RED-first test files; a documented
`subsystem_disabled:` message convention on `internal/errors/kinds.go`.
</objective>
