<objective>
Wire the end-to-end single-cell spine: drive the scripted edit through the helix forwarder over the
per-cell Unix socket, kill the daemon, PID-gated-tap `daemon.log`, run `verify`, synthesize the CC
leg (Plan 02), `trace.Merge` into a 2-leg trace, build + validate the `result.v2.json` (Plan 02),
write durable artifacts (Plan 01 sandbox paths), and clean up scratch (preserve-on-failure, D-08).
This is the BENCH-04 spine — a generalization of `daemon_tap_integration_test.go` to one cell plus
the synth CC leg and the result builder — and it carries the three Nyquist smoke assertions.

Purpose: This plan is the heart of the phase. It composes Plans 01+02 into a runnable cell and
proves the three observability assertions (2-leg trace, zero PID cross-talk, schema-valid result)
that an exit-code-only smoke would alias. It is subprocess/integration glue, so it is standard
`type: execute` (RESEARCH: better verified by integration tests than RED/GREEN unit cycles).

Output: `bench/runtime/drive.go`, `bench/runtime/cell.go` (+ unit cell_test.go), and the two
integration tests (`daemon_tap_integration_test.go`, `cross_cell_test.go`).
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| agent (forwarder stdio) -> daemon (Unix socket) | scripted/claude tool calls cross into the daemon; untrusted in the general bench case |
| daemon.log -> tap -> merged trace | foreign-PID lines in a shared-host log could leak into a cell's trace |
| scripted edit / verify -> cloned repo working copy | patch + go test mutate the ephemeral repo |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-77-06 | Spoofing | foreign-PID log injection into trace | mitigate | `TapDaemonLog(daemonPID)` PID gate (tap.go:71, T-67-04) with the per-cell captured PID; cross_cell_test asserts `RejectedForeignPid==0` (criterion #4) |
| T-77-07 | Tampering | patch writes outside the repo root | mitigate | pass `RepoRoot` (and `PatchPaths` when applicable) to `Merge` so the path-prefix invariant (merge.go:124, T-67-02) holds |
| T-77-08 | Tampering | task/benchmark/mode path-traversal in cell key | mitigate | validateTaskID-style reject before joining `<run_id>/<task>/<mode>` (V5; runner.go:65 pattern) |
| T-77-09 | Info disclosure | dev credentials leaking into the daemon env | mitigate | inherited env allowlist in `StartDaemon` (sandbox.go:247) via the embed — do not bypass |
| T-77-SC | Tampering | npm/pip/cargo installs | accept | N/A — zero new packages this phase (RESEARCH audit: none) |
</threat_model>
