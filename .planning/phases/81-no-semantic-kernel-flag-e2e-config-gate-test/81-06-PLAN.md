<objective>
Close GAP 1 (BLOCKER, WR-02 from 81-VERIFICATION.md): the no_semantic zero-reads
runtime assertion (criterion #2, ABLATE-06's "runtime assertion logs and fails"
clause) is VACUOUS end-to-end. The `helix_semantic_store_reads_total` value is
emitted only inside the daemon's graceful `d.shutdown()` path
(internal/daemon/shutdown.go:60-62), reached only after `g.Wait()` returns
(daemon.go:1276) on SIGTERM/SIGINT. But the bench tears the daemon down via
`DaemonHandle.Kill()` → `syscall.Kill(-pid, SIGKILL)` (sandbox.go:203-204),
called directly at cell.go:535. SIGKILL is untrappable → `shutdown()` never runs
→ the line is never written. `scrapeSemanticReadsTotal` then treats the missing
line as `count=0, no error` (cell.go:101-103), so `assertNoSemanticReads` passes
UNCONDITIONALLY on every real run — the gate can never observe a real read.

This plan makes the gate have teeth on a real run via a robust combination of the
verifier's remediation hints (81-VERIFICATION.md:33-36):
  (a) GRACEFUL teardown FIRST — add `DaemonHandle.Stop` (SIGTERM + bounded wait)
      and call it in RunCell before the existing `Kill` fallback, so `shutdown()`
      actually runs and flushes the reads-total line on a real bench run; AND
  (b) FAIL-CLOSED scrape — on the no_semantic arm a MISSING counter line is a
      HARD FAILURE (the proof never ran), not a silent count=0; this kills the
      root fail-open anti-pattern (cell.go:101-103, flagged 81-VERIFICATION.md:127);
      AND
  (c) a REAL-DAEMON integration test that drives a daemon through the actual
      teardown path and asserts the line is present in daemon.log (replacing the
      synthetic-os.WriteFile-only coverage).

Honors D-04 (build-but-block: store stays BUILT — this plan does NOT touch store
construction; it only fixes emission + scrape) and D-05 (the trace-tap-style
counter assertion is the verification mechanism; Path A daemon-log emission, the
mechanism Plan 81-05 chose, is preserved — this plan makes it actually fire).

Purpose: turn the load-bearing dynamic guarantee of Phase 81 from vacuous into
real, so ABLATE-06's runtime-acceptance clause holds.
Output: a graceful-stop handle method, a fail-closed scrape/assert, and a
real-daemon emission integration test.
</objective>
