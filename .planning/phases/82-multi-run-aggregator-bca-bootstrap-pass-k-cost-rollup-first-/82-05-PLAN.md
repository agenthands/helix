<objective>
Implement the loader + N-enforcement gate in `bench/aggregator/load.go` (STATS-01 consumer half;
the producer half — ExpandMatrix emitting N cells — is Plan 01). It globs the durable
`<runDir>/<task>/<mode>/<run_index>/result.v2.json` tree, decodes each row preserving the full
document AND a nullable-pointer metrics subset (never fabricating 0 — Pitfall 4), counts VALID
rows per (task,mode) where valid = exists + decodes + `runtime.Validate==nil`, and FAILS CLOSED:
if any cell has fewer than `expectedN` valid rows it returns a hard error naming every deficient
cell and the aggregator writes NO reports (D-05). expectedN is the caller's `--runs`/manifest
value, NEVER `len(glob)` (Pitfall 3 — disk count hides a partial matrix).

Purpose: this is the gate that keeps the leaderboard honest about run coverage; Plan 06's
orchestrator calls Load first and aborts before rendering on any deficiency. TDD because the
fail-closed semantics are the STATS-01 acceptance.
Output: `bench/aggregator/load.go` and `load_test.go`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| task/mode/run_index dir names → glob | run dir is locally produced; segments already V5-validated at write time, but the loader must not traverse outside runDir |
| partial/garbage result.v2.json → valid-row count | a malformed or schema-invalid file must not be counted as a valid run |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-82-05-01 | Tampering (data integrity) | counting on-disk files as N -> partial matrix passes the gate (Pitfall 3) | mitigate | expectedN is the function arg (from --runs/manifest); valid-row = decode + runtime.Validate==nil; invalid-file-counts-as-deficient test locks it |
| T-82-05-02 | Information Disclosure | path traversal via task/mode/run_index segments when globbing | mitigate | Glob is rooted at runDir via filepath.Join; segments were V5-validated by validateRunIndexSegment/validatePathSegment at write time; loader only joins under runDir, never accepts caller-supplied raw paths |
| T-82-05-03 | Tampering | fabricating 0 for nil metrics (Pitfall 4) | mitigate | rowMetrics uses *bool/*int/*float64; nil stays nil; nil-preservation test asserts TokensInput==nil not 0 |
| T-82-05-SC | Tampering | npm/pip/cargo installs | accept | No installs; stdlib + existing bench/runtime only |
</threat_model>
