<objective>
Wire the Wave-2 primitives into the pure aggregator orchestrator and the two markdown reports. This
plan delivers: (1) `aggregate.go` — `Aggregate(runDir, cfg)` that calls `Load` (Plan 05), performs
the two-level reduction (Level 1: reduce each (task,mode)'s N runs to one per-task scalar — mean for
continuous, success-rate for boolean, `PassAtK` for pass@k, mean-USD for cost; Level 2: bootstrap the
per-task vector across tasks via `BCaInterval`), and renders both reports — writing NOTHING when Load
returns a deficiency (D-01/D-05); (2) `report.go` — `leaderboard.md` (mode x benchmark rows, every
metric as `value [lo,hi]`, sorted task_success desc, null-CI -> em-dash, STATS-04 overlap gate) and
`cost_quality.md` (cost_per_solved_task with BCa CI + FAIR-03 >5% CV between-run variance warning),
both byte-stable (sort-before-emit, footer records seed/iterations/ci_level/runs/cost-table valid_until).

Purpose: this is where STATS-02 (CIs on every row), STATS-03 (pass@k columns), STATS-04 (overlap
honesty gate), and COST-03 (cost_quality.md) become observable artifacts. TDD via golden-file +
synthetic-fixture tests.
Output: `aggregate.go`, `report.go`, their tests, and two golden `.md` fixtures.
</objective>
