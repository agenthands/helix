`os/exec` docker/podman engine shim, the host-vs-manifest architecture-mismatch
refusal gate, and the `go.mod` docker-SDK grep gate. This is the contracts-first

amd64 SWE-bench image (Pitfall 5). The grep gate is the literal SC#1 acceptance.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host → container engine (os/exec) | Process argv crosses into the docker/podman subprocess; must be fixed-argv with a strict env allowlist (no shell, no full-env inheritance) |
| host arch ↔ image manifest arch | Mismatched arch silently emulates under qemu — an integrity/correctness boundary |
| go.mod dependency set | The docker-SDK ban is a supply-chain boundary enforced statically |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-84-01-01 | Elevation | engine.go PullByDigest os/exec | mitigate | Fixed argv (exec.CommandContext with literal "pull" + computed ref, no shell); strict env allowlist (PATH/HOME/HELIX_CACHE_DIR only); Setpgid for group-kill — copy ragserver.go:161-189 discipline |
| T-84-01-02 | Tampering | image ref pinning | mitigate | PullByDigest rejects non-64-hex digest (errBadDigest) and builds repo@sha256:&lt;hex&gt; only — never a mutable tag (CONTAINER-02 / Pitfall 2) |
| T-84-01-03 | (Integrity/correctness) | arch.go ArchGate | mitigate | Refuse host-arch ≠ manifest-arch unless BENCH_ARCH_MISMATCH_OK=1; prevents silent qemu cross-arch emulation (Pitfall 5) |
| T-84-01-04 | Tampering | go.mod supply chain | mitigate | `make verify-no-docker-sdk` grep gate fails the build if github.com/docker/docker appears in go.mod (SC#1); wired into `make vet` |
| T-84-01-SC | Tampering | go-containerregistry promote | accept | go-containerregistry v0.20.7 is already in go.sum (CNCF/Google module, k8s ecosystem, very high downloads — Package Legitimacy Audit OK); promotion to direct require introduces no new module, only a require-block move |
