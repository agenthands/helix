## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller-supplied "digest" → filesystem path | A crafted digest string must not escape the cache root via path traversal |
| cache staging → published cache dir | Unverified/half-filled bytes must never be visible at the final path (verified-then-rename) |
| host filesystem free-space → run/no-run decision | Resource-exhaustion DoS on a contributor laptop |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-84-02-01 | Tampering | cache.go ImagePath | mitigate | isHexSHA256(sha) guard returns errBadDigest BEFORE filepath.Join — a "../" or "sha256:"-prefixed key cannot escape bench-images/ (mirror ragindex T-83-01-03) |
