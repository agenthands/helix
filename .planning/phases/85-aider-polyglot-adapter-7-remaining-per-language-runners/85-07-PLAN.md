<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| remote polyglot-benchmark repo → local clone | untrusted upstream; a mutable ref could swap content under us |
| exercise name (dataset) → filesystem path | untrusted segment must never traverse the clone/cache root |
| untrusted Exercism test code → host | the test phase runs untrusted code (mitigated by the `--network=none` container path from Plan 02) |
| git subprocess ← bench env | full env must not leak to the git child |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-85-07-01 | Tampering | malicious/changed upstream dataset | mitigate | clone pinned by SHA (never branch/tag); `--depth 1` at the exact commit; `cloneArgs` fail-closes on a non-hex sha before os/exec |
| T-85-07-02 | Tampering | exercise-name path traversal into the cache/clone root | mitigate | validatePathSegment (cloned from cell.go) on every exercise name + clone dest dir (V5/V12 — reject `..`, absolute, post-Join escape) |
| T-85-07-03 | Elevation of Privilege | untrusted Exercism test code reaching the network at test time | mitigate | non-hermetic tasks flagged (SC#3); hermetic tasks run via Plan 02 `container.Run(--network=none)` |
| T-85-07-04 | Information Disclosure | full parent env leaking into the git subprocess | mitigate | `allowlistEnv()` (PATH/HOME/HELIX_CACHE_DIR only) on the git child — never os.Environ() |
| T-85-07-05 | Tampering | argv flag-smuggling via repoURL/sha into git | mitigate | fixed argv + `--` terminator + hex-sha validation; never a shell (mirror engine.go) |
</threat_model>
