<objective>
Stand up the CLI-over-daemon E2E oracle: a `//go:build !windows`, `HELIX_BIN`-gated test
suite that exercises the full dial spine (plans 90-01/02/03) as a REAL `helix` subprocess
against a live daemon, reusing the v1.12 `internal/eval/sandbox` real-subprocess harness
(RESEARCH locked constraint). This is the foundation every later v2.0 phase extends.

Three sub-tests (RESEARCH Test→Map):
1. `CLI_E2E` / `CLI_OneShot` (TEST-01, CLI-01): run a representative verb as a real
   subprocess against the live daemon; assert it returns the same tool result the MCP path
   returns (round-trip works end-to-end).
2. `CLI_WarmReuseSLO` (CLI-02): MEASURE the warm second-call round-trip p50, RECORD the SLO
   as a comfortable multiple of the observed median, and assert against the recorded value —
   NOT a hardcoded guess (RESEARCH Open-Q 1). Choose a no-LS verb (memory/health/fileops) or
   gate on LS readiness so the SLO isolates dial + IPC + dispatch (RESEARCH Pitfall 5).
3. `CLI_ParallelColdSingleDaemon` (CLI-03 real): N parallel cold callers against the SAME
   socket → exactly one daemon PID (the real-process counterpart to plan 90-01's synctest;
   synctest cannot drive real subprocesses — RESEARCH Pitfall 4).

Purpose: TEST-01 — a real-subprocess oracle proves the spine works end-to-end and gives
later phases a harness; it also provides the CLI-02 SLO measurement and the CLI-03 real-PID
assertion that the in-process synctest cannot.
Output: `internal/cli/cli_e2e_test.go` with the three gated sub-tests; the recorded SLO
value documented in the SUMMARY.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| test harness → real daemon subprocess | the oracle spawns a real daemon + CLI subprocesses in a sandbox-isolated /tmp root |
| N concurrent cold callers → daemon spawn | the real-process race the synctest could not exercise |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-90-11 | DoS | the parallel-cold test asserting the race fix actually prevents a real duplicate-daemon storm | mitigate | `CLI_ParallelColdSingleDaemon` is the real-process proof of CLI-03 (single PID under N parallel cold callers), complementing the in-process synctest algorithm test in 90-01. |
| T-90-12 | Tampering | the E2E daemon spawning an unexpected binary / leaking outside its sandbox | mitigate | Uses `internal/eval/sandbox` which roots under /tmp, applies a strict env allowlist (HOME/HELIX_LOG_LEVEL/PATH), an isolated process group, single-Wait reaping, and `Cleanup()`; `resolveHelixBin` stats the binary before use. No hand-rolled exec daemon harness. |
| T-90-13 | DoS | orphaned daemon/subprocesses from a failed test run | mitigate | Every spawned process is reaped via `defer` (`h.Kill()` / subprocess wait) and `sb.Cleanup()`; the sandbox uses its own process group so a kill reaps the tree. |
</threat_model>
