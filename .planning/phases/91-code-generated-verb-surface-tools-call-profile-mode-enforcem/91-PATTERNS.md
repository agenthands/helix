### `cmd/helix-cligen/scan.go` (utility, AST scan — the one genuinely new piece)

**Enumeration analog** (`cmd/docgen/main.go` `generateToolTable`, excerpt in RESEARCH.md:254-260): iterate `skill.ToolProviders()` → `tp.Tools()` → `tool.Name`. This yields NAMES only.

**Why a new AST scan is required:** `internal/mcp/registry.go:8-17` — `ToolDef` carries NO arg-type field:
```go
type ToolDef struct {
	Name, Description, BriefDescription, HelpText string
	RegisterFn func(server interface{}) error // arg type bound only inside generic AddTool
}
```
So names come from the registry; the name→`*Args` binding must be recovered by a `golang.org/x/tools/go/packages` load + `go/ast` walk of `AddTool(...)` call sites (the 2nd arg `&mcpsdk.Tool{Name:"..."}` gives the name; the 3rd arg func literal's last param type gives the `*Args` struct — read its `json:`/`jsonschema:` tags). Registration shape to scan: `internal/kernel/symbols/tools.go:353-378`. No in-tree analog exists for this walk — see **No Analog Found**.

### `internal/cli/verbs_gen.go` (generated route, request-response)

**Analog:** `internal/cli/verb.go:54-86` — the generated file populates exactly this `verbSpecs` map of `verbSpec{toolName, short, flags}` with `verbFlag{name, toolArg, kind, required, help}`. Target shape to emit:
```go
var verbSpecs = map[string]verbSpec{
	"search": {
		toolName: "search_in_files",
		short:    "Search the active workspace for a regex pattern",
		flags: []verbFlag{
			{name: "query", toolArg: "pattern", kind: flagString, required: true, help: "..."},
			{name: "max-results", toolArg: "max_results", kind: flagInt, required: false, help: "..."},
		},
	},
	// ... one entry per live-registry tool ...
}
```
**Critical mappings the generator must honor (from spine):**
- Flag names emitted **kebab-case**; `toolArg` carries the snake_case json key (`verb.go:39-52` `argKey()` indirection). E.g. `--max-results` → `max_results`.
- Supported kinds today are `flagString/flagInt/flagBool` only (`verb.go:25-29`). Non-scalar args (`[]guardrails.ReceiptID` at `edit/tools.go:88-93`) need a generator policy: `[]string` → new `StringSlice` kind, opaque types → `--<name>-json` flag (Pitfall 2).
- Do NOT shadow reserved root persistent flags `--socket/--json/--profile` etc. (`root.go:90-118`) — maintain a denylist (Pitfall 3).
- Sort tool names before emit for deterministic output (Pitfall 4).
- Header: `// Code generated by helix-cligen; DO NOT EDIT.`
- Flatten verbs onto ROOT with `GroupID` (6 capability groups), NOT under a `call` parent (Open Q1; `root.go:83-87` has the `AddGroup` scaffold).
