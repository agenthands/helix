Repurpose the existing PreToolUse nudge hook from a generic "use find_symbol after 5 calls" tip into a per-call ADVISORY steer: when the agent reaches for grep/sed/cat/find over a positively-identified CODE target, emit a `helix <verb>` substitution suggestion via the Claude Code `hookSpecificOutput.additionalContext` JSON channel; when the target is a README/log/config file, unparseable, or no file operand is found, fail open and say nothing (SKILL-03).

Output: modified `internal/cli/nudge.go` (`classifyBashTarget` + the steer-table message + structured `additionalContext` emission) and `internal/cli/nudge_test.go` (extended table-driven coverage). No new files, no new deps, no proto change.
