<objective>
Flip `helix setup <client>` from "register an MCP server" to "install the skill + hooks and tear down any prior MCP registration" — idempotently, across all 7 supported clients (SKILL-02). Each registrar's `Register` now: (1) tears down a prior helix MCP entry via an MCP-ONLY teardown (NOT the hook-stripping `Unregister`), (2) installs the embedded SKILL.md via `installSkill` (for Claude-family clients), (3) merges the existing idempotent hooks. The MCP forwarder dial path and all daemon tool handlers are LEFT INTACT — deleting the MCP heads is Phase 94, not here.

Purpose: complete the migration so a user who previously ran `helix setup` (MCP) and re-runs it ends with the skill+hooks and NO lingering MCP `helix` server entry — the agent surface becomes the CLI, taught by the skill, not the MCP tools/list blob.

Output: modified `internal/cli/setup_clients.go` (`teardownPriorMCP` + wired `Register`s), `internal/cli/setup.go` (orchestration + help text + optional `--no-skill`), `internal/cli/setup_test.go` (extended coverage). No new files, no new deps, no proto change.
</objective>
