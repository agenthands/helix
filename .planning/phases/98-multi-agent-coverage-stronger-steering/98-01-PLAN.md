STEER thrust: broaden the PreToolUse nudge so Bash `sed`/`cat` over a CODE file
steer to the specific `helix` verb (STEER-01), flip the Phase 97 DEFER-97-01
golden from "asserted silent" to "asserted firing" while keeping it non-vacuous,

sub-cases because `runNudge` only reaches steering when `isGrepReadTool()` is true
and its Bash arm matched only grep/find/rg/ag — leaving `bashSteerMessage`'s
correct sed/cat branches dead for Bash callers. STEER-01 is a one-class edit to the
GATE (`isGrepReadTool`), NOT the classifier or the message builder. The steering
stays advisory exit-0 / fail-open (no deny/block path — an explicit anti-feature).

Output: edited `nudge.go` (the gate), edited `nudge_test.go` (firing rows + negative
controls + flipped sub-cases), new `prime.go` (priming-matrix constant + capped
builder) + `prime_test.go`, edited `activate.go` (emit priming on SessionStart stdout).
